## 2. 致命的リスク（即時対応必須）

### CR-001: ビジネスモデル文書と規約の重大な乖離

**影響度:** 致命的 | **発生可能性:** 確実 | **既存CLOレビュー:** 未検出

**問題の概要:**

利用規約ドラフト（v0.1）と最新のビジネスモデル文書（`.claude/BUSINESS.md` v2026-02-05）の間に、料金体系・決済フロー・キャンセルポリシーにおいて重大な乖離が存在する。ビジネスモデル文書は規約作成後に更新されており、規約が現在の事業設計を反映していない。

**乖離の詳細:**

| 項目                   | 利用規約ドラフト（第5条） | BUSINESS.md（最新）                           | 乖離          |
| ---------------------- | ------------------------- | --------------------------------------------- | ------------- |
| プラットフォーム手数料 | 12%                       | 15%                                           | 3ポイントの差 |
| 追加清掃費             | 記載なし                  | 8,000円（固定）                               | 完全欠落      |
| 申込金                 | 記載なし                  | 20,000円（固定、非返金）                      | 完全欠落      |
| デポジット             | 記載なし                  | 引越し費用の30%（最低30,000円、最高50,000円） | 完全欠落      |
| 残額支払い             | 記載なし                  | 引越し費用の70%                               | 完全欠落      |
| 紹介フィー             | 記載なし                  | 3,000円/成約（sumitsugi手数料から支出）       | 完全欠落      |

**決済フローの乖離:**

規約では「次の住人が引越し費用を一括で支払う」構成だが、BUSINESS.mdでは3段階の支払いフローが設計されている。

```
BUSINESS.md の決済フロー:
  1. 申込金 ¥20,000（内見後、即時前の住人へ送金、非返金）
  2. デポジット 30%（賃貸契約締結後、エスクロー保管）
  3. 残額 70%（引き継ぎ日確定時、エスクロー保管）

規約の決済フロー:
  次の住人 → 引越し費用を一括支払い → エスクロー → 分配
```

**キャンセルポリシーの乖離:**

| 項目                       | 利用規約ドラフト（第8条）         | BUSINESS.md                   |
| -------------------------- | --------------------------------- | ----------------------------- |
| 次の住人都合のキャンセル料 | 12%（プラットフォーム手数料相当） | 20%（トラブル対応セクション） |
| 申込金の返金               | 記載なし                          | 非返金                        |
| デポジットの取扱い         | 記載なし                          | キャンセルポリシーに基づく    |

**リスク:**

- ユーザーが規約に記載された料金と実際に請求される金額が異なる場合、消費者契約法第4条（不実告知）に該当する可能性
- 規約に記載のない料金（申込金、追加清掃費）を徴収する場合、消費者保護の観点から問題
- 訴訟時に規約とビジネスモデルの乖離が不利に作用する

**修正提案:**

1. **即座に実行:** BUSINESS.mdの最新仕様に基づいて規約ドラフトを全面改訂
2. 第5条（利用料金・手数料）を以下の項目を含むように改訂:
   - プラットフォーム手数料: 15%
   - 申込金: 20,000円（固定、非返金の旨を明記）
   - デポジット: 引越し費用の30%（最低30,000円、最高50,000円）
   - 残額: 引越し費用の70%
   - 追加清掃費: 8,000円（固定）
   - 大家協力金: 引越し費用の1%（最低3,000円）
3. 第6条（決済・エスクロー）に3段階の決済フローを明記
4. 第8条（キャンセルポリシー）を各段階に対応したポリシーに改訂

### CR-002: 資金決済法違反の可能性（CLO R-001の深化）

**影響度:** 致命的 | **発生可能性:** 中 | **既存CLOレビュー:** R-001（表現修正のみ指摘）

**CLO R-001の指摘を超える追加リスク:**

CLOレビューでは「当社がエスクロー保管」という表現の修正を提案しているが、以下の追加リスクが存在する。

**(a) 2026年改正資金決済法との関係**

2026年施行の改正資金決済法では、クロスボーダー収納代行の4類型適用除外が規定されている。sumitsugiは国内取引だが、以下の点で規制対象となる可能性がある。

- **「債務消滅時点」の明確化義務:** 改正府令案では「買主から入金を受けた時点で買主の支払債務が消滅する」ことを法的に明確に規定する必要がある。規約ドラフトにはこの記載がない
- **エスクロー期間の長期化リスク:** BUSINESS.mdによれば、デポジット支払いから引き継ぎ完了まで最大1-2週間のエスクロー期間が発生する。規約ドラフトの「24-48時間」とは大幅に異なる

**(b) 金融庁のグレーゾーン解消制度の活用**

エスクローサービス専用のガイドラインが不在であり、ローンチ前にグレーゾーン解消制度（ノーアクションレター）を活用して、資金移動業該当性の有無を事前照会することが推奨される。

**修正提案:**

1. 規約第6条に以下を追加:

```
6.X 債務消滅時点
次の住人が本サービスを通じて引越し費用の全部または一部を支払った時点で、
当該支払いに係る次の住人の支払債務は消滅するものとします。
当社は、決済代行業者（Stripe）を通じて、引き継ぎ完了を確認後に
前の住人および関係者への分配を指示します。
```

2. エスクロー期間の実態に合わせた記載（デポジット段階から引き継ぎ完了までの全期間を明記）
3. 外部弁護士への相談時に、金融庁グレーゾーン解消制度の利用可否を確認

**外部弁護士への確認事項:**

1. BUSINESS.mdに記載の3段階決済フロー（申込金→デポジット→残額）において、各段階のエスクロー期間は資金決済法上問題ないか
2. Stripe Connectの利用であっても、デポジット段階からの長期エスクロー（最大1-2週間）は資金移動業に該当しないか
3. 金融庁グレーゾーン解消制度の利用を推奨するか
4. 「債務消滅時点」の規約への記載方法について助言を求める

## 3. 高リスク（外部弁護士確認必須）

### HR-001: 宅建業法違反の可能性（CLO R-002の深化）

**影響度:** 高 | **発生可能性:** 低〜中 | **既存CLOレビュー:** R-002

**CLO R-002の指摘を超える追加リスク:**

CLOレビューでは「残置物の引き継ぎ」と「賃貸契約」の線引きの不明確さを指摘しているが、BUSINESS.mdの以下の記載がリスクを高めている。

**(a) 提携不動産会社との連携フロー**

BUSINESS.mdには「マッチング成立後、提携不動産会社が賃貸借契約を締結」と記載されている。sumitsugiが特定の不動産会社と「提携」し、マッチング後に当該不動産会社を紹介するフローは、宅建業法上の「媒介の媒介」に該当する可能性がある。

**(b) 大家協力金の法的性質**

大家協力金（引越し費用の1%、最低3,000円）は、見方によっては「大家がsumitsugiの仲介に協力することへの対価」であり、宅建業法上の報酬に類似する。

**(c) 申込金20,000円の性質**

BUSINESS.mdでは申込金20,000円が「前の住人の機会損失補償」と説明されているが、これは不動産取引における手付金類似の性質を持ち、宅建業法との関連が生じる可能性がある。

**修正提案:**

1. 規約第3条に以下の明確な宣言を追加:

```
3.X 本サービスの法的位置づけ
本サービスは、宅地建物取引業法に定める宅地建物取引業に該当しません。
本サービスは、退去者と入居者の間における動産（家具・インテリア等）の
売買契約を円滑にするためのプラットフォームを提供するものであり、
賃貸借契約の媒介・代理は一切行いません。
賃貸借契約は、ユーザーと大家・管理会社が直接締結するものとし、
当社はこれに関与しません。
```

2. 「提携不動産会社」という表現を規約・サービス上で使用しない（BUSINESS.mdの表現を修正）
3. 大家協力金の性質を「プラットフォーム利用に対する管理サポート費」として明確化

**外部弁護士への確認事項:**

1. sumitsugiの全フロー（マッチング→申込金→賃貸契約→デポジット→引き継ぎ）を一体としてみた場合、宅建業法上の媒介に該当するか
2. 申込金20,000円（非返金）は宅建業法上の手付金に該当するか
3. 大家協力金は宅建業法上の報酬規制の対象か
4. マッチング後に不動産会社を紹介するフローは、「媒介の媒介」として宅建業法の規制対象か

### HR-002: 消費者契約法違反の可能性（CLO R-003の深化）

**影響度:** 高 | **発生可能性:** 中 | **既存CLOレビュー:** R-003

**CLO R-003の指摘を超える追加リスク:**

**(a) 申込金20,000円の非返金規定**

BUSINESS.mdでは申込金20,000円が「非返金」と記載されている。これは消費者契約法第9条第1号（平均的な損害額を超えるキャンセル料の無効）に抵触する可能性がある。

- 内見直後の段階では、前の住人の実損は限定的
- 20,000円が「平均的な損害額」として妥当かの算定根拠が不明
- 特に賃貸審査に落ちた場合の取扱いが不明確

**(b) キャンセル料の算定根拠の欠如**

規約ドラフトでは「キャンセル料: プラットフォーム手数料相当額（12%）」と記載されているが、BUSINESS.mdでは20%とされている。いずれの場合も、以下の算定根拠が示されていない。

- 前の住人への補償額の算定
- 再募集にかかるコスト
- システム手数料
- 機会損失の定量化

消費者契約法第9条第1号は「平均的な損害額」を超えるキャンセル料を無効とするため、算定根拠の文書化は必須。

**(c) 48時間自動承認の問題**

第6条6.3の「引き継ぎ予定日から48時間経過した時（自動承認）」は、次の住人がアプリを確認できない事情（旅行中、体調不良等）がある場合に不利益となる。消費者契約法第10条（信義則に反する不当条項）に該当する可能性がある。

**修正提案:**

1. キャンセル料の算定根拠を規約に明記（少なくとも内部文書として整備）:

```
キャンセル料の算定根拠:
- 前の住人への機会損失補償: 推定X円
  （再掲載期間中の家賃相当額、家具保管費用等）
- システム手数料: 推定Y円
  （決済処理費用、通知費用等）
- 再マッチングコスト: 推定Z円
合計: 引越し費用の約X%相当
```

2. 自動承認期間を72時間以上に延長し、期間延長の申請手続きを設ける
3. 申込金については「賃貸審査不通過時の返金規定」を追加

**外部弁護士への確認事項:**

1. 申込金20,000円（非返金）は消費者契約法第9条第1号に抵触するか
2. キャンセル料12%（または15%/20%）は「平均的な損害額」として妥当か。算定根拠として何が必要か
3. 48時間の自動承認は消費者契約法第10条に抵触するか
4. 賃貸審査不通過時に申込金を返金しない場合、法的問題はあるか

### HR-003: 決済フロー全体の規約への反映不足

**影響度:** 高 | **発生可能性:** 確実 | **既存CLOレビュー:** 未検出

**問題の概要:**

BUSINESS.mdに詳述されている以下の決済要素が規約に一切記載されていない。

1. **申込金（20,000円）の取扱い:**
   - 支払いタイミング（内見後、賃貸審査申し込み時）
   - 即時送金（エスクロー不使用）の旨
   - 非返金の条件と例外

2. **デポジット（30%）の取扱い:**
   - 支払いタイミング（賃貸契約締結後）
   - エスクロー保管の条件
   - 最低額（30,000円）・最高額（50,000円）

3. **残額（70%）の取扱い:**
   - 支払いタイミング（引き継ぎ日確定時）
   - 自動請求の仕組み

4. **引越し費用の内訳:**
   - 追加清掃費（8,000円固定）
   - 前の住人への支払い
   - 大家協力金
   - プラットフォーム手数料

5. **Stripe Connect Accountの作成義務:**
   - 前の住人・大家が本人確認を完了する必要がある旨
   - 本人確認の範囲と方法

**リスク:**

- 規約に記載のない料金の請求は、消費者保護法制全般に違反する可能性
- 特商法における「支払い方法・時期」の表示義務違反
- ユーザーとの紛争時に規約が根拠として機能しない

**修正提案:**

第5条および第6条を全面改訂し、上記全項目を網羅的に記載する。

### HR-004: 電子署名・電子契約の法的要件不足（CLO R-005の深化）

**影響度:** 高 | **発生可能性:** 中 | **既存CLOレビュー:** R-005

**CLO R-005の指摘を超える追加リスク:**

**(a) 残置物同意書の法的効力**

規約第7条7.2では「残置物同意書は、引き継ぎ内容を証明する資料として利用されます」と記載されているが、電子署名法上の要件を満たさない場合、法的証拠力が大幅に低下する。

2026年の法改正動向を踏まえると、以下の対応が必要:

- 電子署名法に基づく署名方式（当事者署名型 or 事業者署名型）の選択と明記
- タイムスタンプの付与方法
- 改ざん検知の仕組み
- 訴訟時の証拠提出方法（認証局の陳述書等）

**(b) 同意書の「承認」方法**

規約では「双方が承認した時点で、残置物同意書が自動生成されます」と記載されているが、「承認」の方法（電子署名、チェックボックス、ボタンクリック等）が不明確。

**修正提案:**

```
第7条に以下を追加:

7.X 残置物同意書の承認方法
残置物同意書は、本サービス上で前の住人および次の住人がそれぞれ
承認ボタンをクリックすることにより成立します。
当社は、承認の日時、承認者のアカウント情報、承認時のIPアドレスを記録し、
残置物同意書の成立を証する記録として保管します。

7.Y 残置物同意書の法的位置づけ
残置物同意書は、引き継ぎ対象の残置物リスト、状態、及び双方の合意内容を
記録した参考資料であり、民法上の売買契約書としての効力を有する
ことを意図するものではありません。
ただし、紛争発生時には、双方の合意内容を示す証拠資料として
利用されることがあります。
```

**外部弁護士への確認事項:**

1. sumitsugiの残置物同意書に法的効力を持たせるために必要な電子署名の方式は何か
2. チェックボックス同意（いわゆる「クリックラップ」）で十分か、電子署名法に基づく署名が必要か
3. 2026年7月導入予定の商業登記電子証明書リモート署名方式はsumitsugiに活用可能か

### HR-005: 規約変更手続きの不備

**影響度:** 高 | **発生可能性:** 中 | **既存CLOレビュー:** 未検出

**問題の概要:**

規約第14条は以下の通り規定している:

> 1. 当社は、必要に応じて本規約を変更することができます。
> 2. 規約変更の際は、変更内容および変更日を本サービス上で告知します。
> 3. 変更後もユーザーが本サービスを利用した場合、変更後の規約に同意したものとみなされます。

**リスク:**

- 民法第548条の4（定型約款の変更）に基づき、以下の要件を満たさない変更は無効:
  - 変更が利用者の一般の利益に適合する場合
  - 変更が契約をした目的に反せず、かつ、変更の必要性、変更後の内容の相当性、定型約款の変更をすることがある旨の定めの有無等に照らして合理的なものである場合
- 「利用した場合に同意したとみなす」だけでは、上記の合理性要件を満たさない可能性
- 変更の事前通知期間が未定義
- ユーザーへの個別通知（メール等）の義務が未規定

**修正提案:**

```
第14条（規約の変更）

1. 当社は、以下のいずれかに該当する場合、本規約を変更することができます:
   (1) 変更がユーザーの一般の利益に適合する場合
   (2) 変更が本サービスの利用目的に反せず、変更の必要性、
       変更後の内容の相当性その他の事情に照らして合理的な場合

2. 当社は、規約を変更する場合、変更後の規約の内容及び効力発生日を、
   効力発生日の少なくとも30日前までに、本サービス上での掲示及び
   ユーザーへの電子メール通知により告知します。

3. 前項の定めにかかわらず、ユーザーの権利を制限し又は義務を加重する
   変更については、ユーザーの個別の同意を得るものとします。

4. 効力発生日以降にユーザーが本サービスを利用した場合、変更後の規約に
   同意したものとみなします。ユーザーが変更に同意しない場合は、
   効力発生日までに退会手続きを行うことができます。
```

### MR-001: 免責条項の過度な広さ（CLO R-004の深化）

**影響度:** 中 | **発生可能性:** 中 | **既存CLOレビュー:** R-004

**追加指摘:**

CLOレビューでは「一切の責任を負いません」の修正を提案しているが、追加で以下の問題がある。

**(a) 損害賠償上限の妥当性**

第10条10.3で「プラットフォーム手数料相当額を上限」としているが、引越し費用100,000円の場合、上限はわずか15,000円（15%の場合）。次の住人が家具の重大な欠陥により健康被害を受けた場合など、この上限は消費者契約法第8条（事業者の損害賠償責任を免除する条項の無効）に抵触する可能性がある。

**(b) プラットフォーム事業者としての安全配慮義務**

2026年の消費者保護法制の動向として、C2C取引であってもプラットフォーム事業者に「信頼基盤としての機能」が期待される方向にある。完全な免責は将来的に認められなくなる可能性。

**修正提案:**

```
第10条10.2を以下に修正:

当社は、故意または重過失がある場合を除き、以下の場合について責任を負いません:
（各項目）

ただし、当社に故意または重大な過失がある場合は、この限りではありません。

第10条10.3を以下に修正:

当社がユーザーに対して負う損害賠償責任は、当社に故意または重大な過失がある
場合を除き、当該取引における引越し費用相当額を上限とします。
```

### MR-002: 紛争解決条項の不十分さ

**影響度:** 中 | **発生可能性:** 中 | **既存CLOレビュー:** R-008（表現の曖昧さとして部分的に指摘）

**問題の概要:**

第13条の紛争解決条項は以下の問題を抱えている:

1. **13.2「当社が紛争の仲裁を行うことができます」の問題:**
   - 法的な「仲裁」は仲裁法に基づく手続きであり、当社が行うことは不適切
   - 「調停」「あっせん」など適切な用語を使用すべき
   - 仲裁合意は消費者契約では原則無効（仲裁法附則第4条「暫定措置」は消費者仲裁合意について将来紛争に関する仲裁合意を無効とする規定）

2. **具体的な紛争解決プロセスの欠如:**
   - 異議申し立ての受付方法
   - 調査期間の目安
   - 調査結果の通知方法
   - 不服がある場合の次のステップ

**修正提案:**

```
第13条（紛争解決）

13.1 協議
本サービスに関連して紛争が生じた場合、ユーザーと当社は誠実に協議するものとします。

13.2 当社による調停
ユーザー間の紛争について、当事者の申出に基づき、当社が調停（あっせん）を
行うことがあります。ただし、当社の調停には法的拘束力はなく、
当事者は調停結果に拘束されません。

13.3 異議申し立て
ユーザーは、取引に関する異議を引き継ぎ完了から48時間以内に、
当社所定の方法により申し立てることができます。
当社は、異議申し立てを受領後、速やかに調査を行い、
14営業日以内に調査結果を通知します。

13.4 管轄裁判所
本規約に関する訴訟については、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
```
