## 概要

メルカリはC2C（個人間取引）フリマプラットフォームとして、日本最大のサービスを運営している。利用規約は全24条で構成され、プラットフォーム事業者としての責任範囲を明確に限定する一方、消費者契約法との整合性について法的に指摘されている箇所も複数存在する。

sumitsugiとメルカリは「プラットフォーム型C2C取引」という共通の構造を持つが、sumitsugiの特殊性（残置物の引き継ぎ、エスクロー、大家協力金、物理的な物件に紐づく取引）を踏まえた上で参考にすべき点を整理する。

## 1. 免責事項（Liability Disclaimers）

### 1.1 メルカリの免責構造

#### 第1条（本サービスの内容及び弊社の役割）

メルカリは冒頭で自社の立場を明確に定義している：

> 本サービスは、オンラインフリーマーケットサービスであり、ユーザー間の物品の売買の場・機会を提供するものです。

さらに重要な一文として：

> 本規約中に別段の定めがある場合を除き、売買契約の取消し、解約、解除、返品、返金、保証など取引の遂行には一切関与しません。

この「場の提供者」としての宣言は、プラットフォーム免責の基礎となっている。

#### 第22条（非保証及び免責）

> 弊社は、本サービスの内容・品質・水準、本サービスの安定的な提供、本サービスの利用に伴う結果等については、一切保証しません。

さらに第2項では：

> 故意・過失の有無にかかわらず、弊社は、当該損害について一切責任を負わないものとします。

**法的指摘:** この包括的免責は消費者契約法第8条（事業者の損害賠償責任を全部免除する条項の無効）および第10条に抵触する可能性が指摘されている。

#### 第23条（損害賠償の上限）

消費者契約法の適用を受ける場合の制限として：

> 弊社の責任は、弊社の過失による債務不履行又は不法行為によりユーザーに生じた損害のうち現実に発生した直接かつ通常の損害に限り、かつ、当該ユーザーから受領した代金の累積総額を上限とします。

### 1.2 sumitsugiとの比較

| 項目             | メルカリ                                 | sumitsugi（現ドラフト）            |
| ---------------- | ---------------------------------------- | ---------------------------------- |
| 免責の基本姿勢   | 「場の提供者」として取引に一切関与しない | 同様の姿勢（第10条）               |
| 損害賠償上限     | ユーザーから受領した代金の累積総額       | プラットフォーム手数料相当額       |
| サービス品質保証 | 一切保証しない                           | 明記なし                           |
| 不可抗力免責     | 明記あり                                 | 天災・事故を列挙（第10条2項4号）   |
| システム障害     | 免責                                     | Stripe障害のみ言及（第10条2項5号） |

## 2. 禁止事項（Prohibited Activities）

### 2.1 メルカリの禁止事項体系

メルカリは禁止事項を4つの原則カテゴリーに分類している：

#### A. 「安全であること」を損なう行為（第8条関連）

1. 許可・免許なく規制商品を出品する行為
2. 出品者自身や親族の商品を購入する行為（自作自演）
3. マネーロンダリングの疑いがある行為
4. 第三者への取引代行
5. 個人情報を含む出品・投稿
6. 違法行為の助長
7. 勧誘活動

#### B. 「信頼できること」を損なう行為

8. 虚偽情報の記載
9. 他者画像の無断使用
10. 手元にない商品の出品（無在庫転売）
11. メルカリ以外の決済方法への誘導
12. 取引中商品の再出品
13. 購入後の値上げ・送料上乗せ要求
14. 出品者の自己都合キャンセル
15. 故意の未払い
16. 受取評価の放棄
17. 虚偽の通報・報告
18. 外部サービスへの誘導

#### C. 「人道的であること」を損なう行為

19. 迷惑行為・嫌がらせ
20. わいせつ・性的・低俗な投稿
21. 差別・憎悪の助長
22. 公序良俗違反

#### D. 運営方針に基づく禁止行為

23. 独自ルールの設定（「ノークレームノーリターン」等）
24. キャンセル料・迷惑料の請求
25. その他メルカリが不適切と判断する行為

### 2.2 禁止出品物（第9条関連）

メルカリが定める出品禁止物のうち、**家具・インテリア・家電に関連する項目**は以下の通り：

| カテゴリー | 禁止品目                                             | sumitsugi関連度              |
| ---------- | ---------------------------------------------------- | ---------------------------- |
| 安全規制品 | PSマーク表示なし製品（乳児用ベッド、特定電気製品等） | **高** -- 家電・照明器具     |
| 危険物     | 膨張・破損バッテリー搭載機器                         | **中** -- 電子機器付家具     |
| 危険物     | アスベスト含有製品                                   | **高** -- 古い建材・家具     |
| 安全規制品 | リコール対象製品                                     | **高** -- 全般               |
| 法令違反   | 盗品                                                 | **高** -- 残置物の所有権確認 |
| その他     | 現金・金券類                                         | **低**                       |
| 食品       | 開封済み食品・期限切れ食品                           | **低**                       |

### 2.3 メルカリの禁止事項の特徴

1. **ガイドラインへの委任**: 規約本文では抽象的に定め、具体的な禁止リストはガイドラインに委任している。これにより規約変更なしで禁止品目を柔軟に更新できる。
2. **4原則カテゴリー**: 「安全」「信頼」「人道」「運営」の4軸で整理されており、ユーザーにとって理解しやすい。
3. **プラットフォーム外取引の禁止**: メルカリ以外の決済方法への誘導を明確に禁止し、手数料回避を防止している。

## 3. 紛争解決（Dispute Resolution）

### 3.1 メルカリの紛争解決フレームワーク

#### 第21条第4項～第5項（トラブルの解決）

メルカリの基本方針は：

> ユーザーは各自の費用及び責任で解決するものとし、弊社は一切の責任を負わないものとします。

ただし、2025年7月より「全額補償サポートプログラム」を導入し、実質的にトラブル解決への関与を強化している。

#### 全額補償サポートプログラム（2025年7月1日開始）

**補償内容:**

- 出品者: 販売利益の全額補償
- 購入者: 支払い代金の全額補償（割引クーポン適用分を除く）
- 金額上限: なし

**5つの適用条件（すべて必須）:**

1. アプリでかんたん本人確認（eKYC）を実施済み
2. 配送方法に「メルカリ便」を利用
3. 配達完了日翌日から14日以内に事務局へ連絡
4. 出品者/購入者ガイドラインを遵守
5. 過去取引含め利用規約を遵守

**補償対象外:**

- 梱包資材費や各種手数料
- メルカリShopsの取引
- 他の保険（メルカード ゴールド等）で補償される場合

**メルカリの方針転換:**

> これまで、トラブルが発生した際、お客さま同士でのトラブル解決を基本としてきたが、今後は積極的に関与する。

#### 第24条第7項（管轄裁判所）

> 東京簡易裁判所又は東京地方裁判所を第一審の専属的合意管轄裁判所とします。

### 3.2 紛争解決の段階構造

メルカリの紛争解決は以下の段階で進行する：

```
Step 1: ユーザー間での直接解決
    ↓ （解決しない場合）
Step 2: メルカリ事務局への問い合わせ
    ↓ （全額補償サポートプログラムの条件を満たす場合）
Step 3: 事務局による調査・補償判断
    ↓ （補償承認の場合）
Step 4: 商品回収センターへの送付 → 補償金の支払い
    ↓ （解決しない場合）
Step 5: 東京地方裁判所での訴訟
```

### 3.3 不正利用への補償

不正利用（アカウント乗っ取り等）が確認された場合：

- 不正利用発生日から60日以内の申請が必要
- 警察への相談・届出の記録が必須
- メルペイ利用規約第19条に基づく対応

## 4. 手数料・決済（Fees & Payment）

### 4.1 メルカリの手数料体系

#### 第13条（利用料等）

| 手数料項目                   | 金額・料率               | 負担者 |
| ---------------------------- | ------------------------ | ------ |
| 販売手数料                   | 販売価格の**10%**        | 出品者 |
| 振込手数料                   | 一律**200円**            | 出品者 |
| お急ぎ振込手数料             | 追加**200円**            | 出品者 |
| 登録・アプリ利用料           | 無料                     | --     |
| 出品料                       | 無料                     | --     |
| 購入手数料（クレカ等）       | 無料                     | --     |
| 購入手数料（コンビニ払い等） | 100円～880円（金額帯別） | 購入者 |

### 4.2 決済・代理受領スキーム

#### 第11条第6項第2号

メルカリは「代理受領」スキームを採用している：

> 出品者は弊社に対して、購入者から支払われる商品代金を代理受領する権限を付与するものとします。

このスキームの法的意義：

- **資金移動業の登録回避**: 「エスクロー」ではなく「代理受領」と位置づけることで、資金決済法上の資金移動業者登録を回避
- **決済事業者への権限委任**: メルカリが指定する決済事業者・収納代行業者にも代理受領権限を付与可能
- **債権譲渡**: 決済事業者との加盟店契約により必要な場合、商品代金債権をメルカリに譲渡することに同意する形式

#### 売上金の管理（第15条）

- 取引完了から**180日以内**に引出申請が必要
- 180日経過後、メルカリは売上金を登録口座に自動振込
- 振込が正常に完了しない場合、支払請求権を放棄したとみなすことができる

**法的指摘:** 売上金失効条項は消費者契約法第10条違反の可能性が高いとされている。

### 4.3 sumitsugiとの比較

| 項目           | メルカリ                 | sumitsugi（現ドラフト）       |
| -------------- | ------------------------ | ----------------------------- |
| 手数料率       | 販売価格の10%            | 引越し費用の12%               |
| 手数料負担者   | 出品者                   | 前の住人（出品者相当）        |
| 購入者負担     | 支払方法により0円～880円 | なし                          |
| 決済スキーム   | 代理受領                 | エスクロー（Stripe）          |
| 決済基盤       | 自社（メルペイ）         | Stripe                        |
| 売上金有効期限 | 180日                    | 規定なし                      |
| 振込手数料     | 200円                    | 規定なし                      |
| 追加分配先     | なし                     | 大家協力金（1%、最低3,000円） |

## 5. 個人情報保護（Privacy）

### 5.1 メルカリの個人情報取り扱い

メルカリは利用規約本文では個人情報の詳細を定めず、別途「プライバシーポリシー」で規定する形を取っている。

#### 規約上の関連条項

- **第4条（登録情報）**: 正確な情報の提供義務、虚偽情報の登録禁止
- **第8条（禁止行為）**: 個人情報を含む出品・投稿の禁止、評価への個人情報記載の禁止
- **第24条（連絡手段）**: ユーザーからの連絡は問い合わせフォーム限定（電話・来訪不可）

#### 2025年10月プライバシーポリシー改定

メルカリは2025年10月31日付でプライバシーポリシーを改定し、データの取り扱い範囲を更新している。

### 5.2 本人確認（eKYC）

メルカリは2025年の全額補償サポートプログラム導入に合わせ、eKYC（かんたん本人確認）の実施を補償適用の必須条件としている。これにより、実質的にeKYCの普及を促進している。

## 6. その他の重要条項

### 6.1 規約変更（第3条）

> ユーザーが本サービスを利用した場合又はアカウント削除の手続をとらなかった場合には、同意をしたとみなされる。

> 弊社は、改定、変更によりユーザーに生じたすべての損害について、一切の責任を負いません。

**法的指摘:** 「みなし同意」条項は消費者契約法第10条に抵触する可能性がある。

### 6.2 アカウント停止（第5条）

メルカリは**事前通知なし**にアカウント停止が可能で、かつ**理由説明義務を負わない**と規定している。

### 6.3 反社会的勢力の排除（第4条3項5号）

登録拒否事由として以下を明記：

- 暴力団員
- 暴力団員でなくなってから5年を経過しない者
- 反社会的勢力等と何らかの関係を有している者

### 6.4 知的財産権

メルカリは知的財産権侵害品の出品を禁止しており、「商標権や著作権を侵害する商品販売」「ブランド名の無断使用」「権利のない画像や説明文の転載」を禁止行為として列挙している。

### 6.5 連絡手段の制限（第24条）

> ユーザーが弊社に通知、連絡又は問い合わせをする必要が生じた場合、本サービスのお問い合わせフォームを利用するものとし、電話や来訪を行うことはできないものとします。

**法的指摘:** 特定商取引法の趣旨に反するとの指摘あり。

## 7. sumitsugiへの示唆

### 7.1 免責事項に関する提言

#### A. 「場の提供者」宣言の強化（優先度: 高）

sumitsugiドラフト第10条の免責条項は基本的な構造を備えているが、メルカリ第1条のように**冒頭で「場の提供者」としての立場を明確に宣言**することを推奨する。

**現状（第3条3項）:**

> 当社は、賃貸契約の仲介を行うものではなく、残置物の引き継ぎおよび決済代行のみを提供します。

**改善案:**

- 宅建業法との切り分けをより明確にするため、「当社は残置物の引き継ぎの場・機会を提供するものであり、引き継ぎの当事者とはなりません」という文言を追加
- 残置物の品質・状態に対する非保証を第3条に前倒しで明記

#### B. 損害賠償上限の見直し（優先度: 高）

sumitsugiドラフトでは損害賠償上限を「プラットフォーム手数料相当額」としているが、メルカリは「受領した代金の累積総額」を上限としている。

**検討事項:**

- sumitsugiの手数料12%を上限とすると、15万円の取引で上限は1.8万円にしかならず、消費者契約法の観点から過度に低いと判断される可能性がある
- メルカリ同様「受領した手数料の累積総額」または「当該取引の引越し費用相当額」を上限とすることを検討

#### C. サービス品質の非保証（優先度: 中）

メルカリ第22条を参考に、以下の非保証条項を明記すべき：

- サービスの可用性・安定性の非保証
- 通信環境によるサービス品質の非保証
- 利用結果の非保証

### 7.2 禁止事項に関する提言

#### A. 残置物固有の禁止品目の明記（優先度: 高）

メルカリの禁止品目リストを参考に、sumitsugiの残置物引き継ぎに特化した禁止品目を追加すべき：

1. **PSマーク表示のない特定電気製品**（照明器具、電気温水器等）
2. **リコール対象製品**（経済産業省のリコール情報をチェック）
3. **アスベスト含有の疑いがある製品**（古い建材・断熱材）
4. **所有権が不明確な残置物**（大家所有物との区別）
5. **賃貸契約上の撤去義務がある設備**（原状回復対象物）
6. **建築基準法に抵触する改造設備**（DIY改造等）

#### B. ガイドラインへの委任方式の採用（優先度: 中）

メルカリのように、禁止品目の詳細リストを規約本文ではなく「ガイドライン」に委任する方式を検討する。これにより：

- 規約変更の手続きなしで禁止品目を柔軟に更新可能
- 規約本文をシンプルに保てる
- 季節や市場動向に応じた迅速な対応が可能

#### C. プラットフォーム外取引の禁止（優先度: 高）

メルカリ同様、sumitsugiを介さない直接取引の禁止を強化すべき。現状のドラフト第9条2号には「本サービスを経由せずに直接取引を行う行為」があるが、より具体的に：

- SNSやメッセージアプリでの直接連絡先交換の禁止
- sumitsugi外での決済の禁止
- 大家・管理会社を通じた手数料回避の禁止

### 7.3 紛争解決に関する提言

#### A. 段階的紛争解決フローの明記（優先度: 高）

sumitsugiドラフト第13条の紛争解決は「協議→仲裁→裁判」の3段階だが、メルカリの全額補償サポートプログラムを参考に、より詳細なフローを構築すべき：

```
Step 1: 引き継ぎ完了前 → 残置物同意書に基づく当事者間協議
Step 2: 引き継ぎ完了後48時間以内 → 異議申し立て（既にドラフトに存在）
Step 3: 異議申し立て後 → sumitsugi事務局による調査・仲裁
Step 4: 仲裁不成立 → 第三者ADR（裁判外紛争解決）
Step 5: 訴訟 → 東京地方裁判所
```

#### B. 証拠保全の仕組み（優先度: 高）

メルカリの全額補償プログラムでは「画像添付」を条件としている。sumitsugiでは残置物同意書に加えて：

- 引き継ぎ時の写真・動画の保存義務
- 残置物の状態記録の保存期間の明記
- 紛争発生時の証拠提出手順の規定

#### C. 補償プログラムの検討（優先度: 中 -- Phase 2以降）

メルカリは2025年に全額補償を導入した。sumitsugiもスケールに応じて：

- 一定金額以下の取引に対する簡易補償
- eKYC実施ユーザーへの優遇
- 残置物同意書の完備を補償条件とする

### 7.4 決済・エスクローに関する提言

#### A. 「代理受領」への用語変更の検討（優先度: 高）

**最重要の法的示唆。** メルカリは「エスクロー」という用語を規約上使用せず、「代理受領」スキームを採用している。これは資金決済法上の資金移動業者登録を回避するためである。

sumitsugiドラフト第6条では「エスクロー」という用語を使用しているが：

- 「エスクロー」は法的に資金移動業に該当する可能性がある
- 資金移動業者の登録には最低1,000万円の供託義務、本人確認義務等の負担が発生
- 無登録での実施は最大3年の懲役または300万円の罰金

**改善案:**

- Stripeの決済代行機能を活用し、「代理受領」または「決済代行」としてのスキーム構築を検討
- 利用規約上も「エスクロー」ではなく「決済代行」「代理受領」と表記
- 実態として資金の一時保管期間を最小化（24-48時間の現行設計は維持可能だが、法的整理が必要）

**外部弁護士への確認必須事項。**

#### B. 売上金の有効期限と振込手数料（優先度: 中）

メルカリは売上金に180日の有効期限と200円の振込手数料を設けている。sumitsugiでは：

- 引き継ぎ完了後の分配タイミングは規定あり（第6条3項）
- 振込手数料の負担者を明記すべき（Stripe Connect Accountの場合の手数料体系）
- 分配が正常に完了しない場合の取り扱いを規定すべき

### 7.5 個人情報保護に関する提言

#### A. eKYC（本人確認）の導入（優先度: 高）

メルカリが全額補償の条件としてeKYCを必須化したことは重要な先例である。sumitsugiでは残置物の引き継ぎという性質上、より厳格な本人確認が求められる：

- 前の住人: 物件の居住者であることの確認（賃貸契約書等）
- 次の住人: 入居予定者であることの確認
- 大家: 物件所有者であることの確認

#### B. 取引履歴の保存期間（優先度: 中）

紛争解決のために、以下のデータの保存期間を明記すべき：

- 残置物同意書: 最低5年（民法の消滅時効に合わせて）
- 取引履歴: 最低7年（税務上の保存義務に合わせて）
- チャット・メッセージ履歴: 最低1年

### 7.6 規約変更に関する提言

#### A. 通知方法の明確化（優先度: 中）

メルカリの「みなし同意」方式は消費者契約法上の問題が指摘されている。sumitsugiでは：

- 重要な変更（手数料率、免責範囲等）は個別通知（メール）を必須とする
- 変更後の同意取得を明示的に行う（ログイン時の同意画面等）
- 変更の事前告知期間を設ける（最低30日前）

### 7.7 その他の提言

#### A. 連絡手段の多様化（優先度: 低）

メルカリはフォーム限定で電話対応なしとしているが、特商法の観点で指摘されている。sumitsugiでは：

- メールでの問い合わせ窓口
- FAQ・ヘルプセンターの整備
- 将来的にはチャットサポートの導入を検討

#### B. 反社条項の具体化（優先度: 中）

sumitsugiドラフト第16条の反社排除条項は基本的だが、メルカリを参考に「暴力団員でなくなってから5年を経過しない者」等の具体的な定義を追加すべき。
