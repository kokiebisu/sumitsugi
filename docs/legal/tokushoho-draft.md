## サービス内容

**サービス名:** tsumugi（つむぎ）

**サービス概要:**
賃貸物件の退去時における残置物（家具・インテリア等）の引き継ぎを円滑にするためのマッチングプラットフォームを提供します。

**提供サービス:**

- 物件情報および残置物の掲載
- 前の住人（売り手）と次の住人（買い手）のマッチング
- 残置物同意書の生成
- 引越し費用の決済代行およびエスクロー機能
- 大家・管理会社への通知機能

**注意事項:**

- 当社は賃貸契約の仲介を行うものではありません
- 当社はプラットフォームを提供するのみであり、残置物の品質・状態について保証しません

## 利用料金

### プラットフォーム手数料

| 対象                   | 料金                                           |
| ---------------------- | ---------------------------------------------- |
| **前の住人（売り手）** | 引越し費用の12%                                |
| **次の住人（買い手）** | 無料（引越し費用のみ支払）                     |
| **大家・管理会社**     | 協力金として引越し費用の1%（最低¥3,000）を受領 |

### 料金例

**引越し費用 ¥150,000 の場合:**

| 項目                          | 金額                      |
| ----------------------------- | ------------------------- |
| 次の住人の支払額              | ¥150,000                  |
| プラットフォーム手数料（12%） | ¥18,000                   |
| 大家協力金（1%）              | ¥1,500 → ¥3,000（最低額） |
| 前の住人の受取額              | ¥129,000                  |

**内訳:**

- 次の住人が支払う: ¥150,000
- プラットフォーム手数料: ¥18,000
- 大家協力金: ¥3,000
- 前の住人が受け取る: ¥150,000 - ¥18,000 - ¥3,000 = ¥129,000

### 決済手数料

決済代行業者（Stripe Inc.）の決済手数料（約3.6%）は、当社が負担します。ユーザーへの転嫁はありません。

## 商品の引き渡し時期

**引き継ぎ予定日:**

- 前の住人の退去日と同日、または退去日以降
- 双方の合意により決定

**引き渡し方法:**

- 現地（物件）での対面引き渡し
- 立ち会いは前の住人、次の住人、大家・管理会社（任意）

**遅延の場合:**
前の住人または次の住人の都合により引き渡しが遅延する場合、当事者間で協議の上、新しい引き継ぎ予定日を設定してください。

## 特定商取引法の適用について

本サービスは、賃貸物件の退去時における残置物の引き継ぎを仲介するプラットフォームであり、以下の理由から特定商取引法の対象外と考えられます：

1. **通信販売には該当しない:**
   - 当社は残置物を販売するものではなく、マッチングプラットフォームを提供
   - 実際の取引は前の住人（個人）と次の住人（個人）の間で行われる

2. **事業者間取引ではない:**
   - 前の住人は事業者ではなく、個人（退去者）
   - 次の住人は消費者（入居者）

ただし、念のため特定商取引法に準じた表記を行っています。

**注意:** 特定商取引法の適用可否については、外部弁護士に確認する必要があります。
