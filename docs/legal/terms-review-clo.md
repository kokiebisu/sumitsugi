## 1. 致命的リスク（要即時対応）

### 🔴 R-001: 資金決済法違反の可能性

**該当条項:** 第6条（決済・エスクロー）

**リスク内容:**

- Stripe Connectを利用しても、「エスクロー保管」という表現が資金移動業に該当する可能性
- 資金移動業ライセンスなしで営業すると、3年以下の懲役または300万円以下の罰金（資金決済法第102条）

**問題箇所:**

> 次の住人が支払った引越し費用は、引き継ぎ完了まで当社がエスクロー保管します。

**指摘:**

- 「当社がエスクロー保管」という表現が誤解を招く
- 実際には「Stripeがエスクロー保管」であり、「当社はStripeに分配指示を出すのみ」

**修正案:**

```
次の住人が支払った引越し費用は、決済代行業者（Stripe）が引き継ぎ完了まで保管します。
当社は、引き継ぎ完了を確認後、Stripeに対して分配指示を行います。
```

**外部弁護士への確認事項:**

1. Stripe Connectを使用する場合、資金移動業ライセンスは不要か？
2. 「エスクロー」という用語の使用自体に問題はないか？
3. sumitsugiの法的地位（決済代行 vs 資金移動業）は何か？

**優先度:** 🔴 最優先（ローンチ前に必ず確認）

## 2. 中リスク（外部弁護士確認推奨）

### 🟡 R-002: 宅建業法違反の可能性

**該当条項:** 第3条（サービスの内容）、第5条（利用料金・手数料）

**リスク内容:**

- 「残置物の引き継ぎ」が宅建業法上の「不動産の取引」に該当する可能性
- 宅建業法違反の場合、3年以下の懲役または300万円以下の罰金（宅建業法第79条）

**問題箇所:**

> 当社は、賃貸契約の仲介を行うものではなく、残置物の引き継ぎおよび決済代行のみを提供します。

**指摘:**

- 「残置物の引き継ぎ」と「賃貸契約」の線引きが不明確
- 大家・管理会社が関与している点が宅建業法の適用を招く可能性

**修正案:**

```
第3条に以下を追加：
「本サービスは、宅地建物取引業法に定める宅地建物取引業に該当せず、
賃貸借契約の媒介・代理は一切行いません。
本サービスは、退去者と入居者の間における動産（家具・インテリア等）の
売買を円滑にするためのプラットフォームです。」
```

**外部弁護士への確認事項:**

1. 残置物の引き継ぎは宅建業法の適用対象か？
2. 大家・管理会社が関与する場合、宅建業法の適用を受けるか？
3. プラットフォーム手数料12%は宅建業法の仲介手数料規制の対象か？

**優先度:** 🟡 高（ローンチ前に確認推奨）

### 🟡 R-003: キャンセルポリシーの有効性

**該当条項:** 第8条（キャンセルポリシー）

**リスク内容:**

- 消費者契約法により、過度に消費者に不利な条項は無効となる可能性
- 「次の住人都合のキャンセルでデポジット没収」が消費者契約法第10条に抵触する可能性

**問題箇所:**

> 次の住人都合: キャンセル料: プラットフォーム手数料相当額（12%）

**指摘:**

- キャンセル料12%が「平均的な損害額」を超えている場合、無効となる可能性（消費者契約法第9条）
- 実際の損害（前の住人への補償、再募集コスト）を算定できていない

**修正案（外部弁護士確認後）:**

```
キャンセル料の算定根拠を明記：
- 前の住人への補償: X円
- 再募集コスト: Y円
- システム手数料: Z円
合計: 引越し費用の12%相当
```

**外部弁護士への確認事項:**

1. キャンセル料12%は「平均的な損害額」として妥当か？
2. 消費者契約法第9条に抵触しないか？
3. 引き継ぎ完了後の「原則返金なし」は有効か？

**優先度:** 🟡 中（ローンチ前に確認推奨）

### 🟡 R-004: 免責条項の過度な広さ

**該当条項:** 第10条（プラットフォーム事業者の責任範囲）

**リスク内容:**

- 免責条項が過度に広い場合、消費者契約法第8条により無効となる可能性
- 「一切の責任を負いません」という表現が問題視される可能性

**問題箇所:**

> 当社は、以下の場合について一切の責任を負いません：

**指摘:**

- 「一切の責任を負わない」は過度に広い
- 故意・重過失による損害まで免責できない（民法第708条、消費者契約法第8条）

**修正案:**

```
当社は、故意または重過失がある場合を除き、以下の場合について責任を負いません：
```

**外部弁護士への確認事項:**

1. 免責条項の範囲は適切か？
2. 消費者契約法第8条に抵触しないか？
3. 損害賠償の上限設定（プラットフォーム手数料相当額）は有効か？

**優先度:** 🟡 中（ローンチ前に確認推奨）

### 🟡 R-005: 残置物同意書の法的効力

**該当条項:** 第7条（残置物同意書）

**リスク内容:**

- 残置物同意書の法的効力が不明確
- 電子署名法に基づく適切な署名方法を採用していない場合、証拠力が弱い

**問題箇所:**

> 残置物同意書は、引き継ぎ内容を証明する資料として利用されます。

**指摘:**

- 「証明する資料」という表現が法的効力を過大評価している可能性
- 電子署名の方法（本人確認、タイムスタンプ等）が明記されていない

**修正案:**

```
第7条に以下を追加：
「残置物同意書は、引き継ぎ内容を記録した参考資料です。
法的効力については、紛争の内容や証拠の状況により異なります。」
```

**外部弁護士への確認事項:**

1. 残置物同意書に法的効力を持たせるには、どのような要件が必要か？
2. 電子署名法に基づく適切な署名方法は？
3. トラブル時の証拠能力を高めるには？

**優先度:** 🟡 中（ローンチ後に改善可）
