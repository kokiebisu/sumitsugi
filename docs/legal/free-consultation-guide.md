### 3.3 ビジネスモデル概要（1ページサマリー）

以下のテンプレートを印刷またはPDF化して持参：

```
【サービス名】tsumugi（紡ぎ）

【事業内容】
賃貸物件の退去時に、前の住人が残した家具・インテリアを次の入居者に引き継ぐ
プラットフォームを提供。引越し費用の決済代行およびエスクロー機能を持つ。

【対象ユーザー】
- 前の住人（売り手）: 退去時に家具を次の住人に譲る
- 次の住人（買い手）: 入居時に家具を前の住人から引き継ぐ
- 大家・管理会社: 残置物の処分コスト削減

【収益モデル】
- プラットフォーム手数料: 引越し費用の12%（前の住人負担）
- 大家協力金: 引越し費用の1%（最低¥3,000）

【決済フロー】
次の住人 → Stripe（決済代行） → エスクロー保管 → 引き継ぎ完了後、
前の住人・大家に自動分配

【技術スタック】
- Stripe Connect（決済・エスクロー）
- Next.js（Webアプリ）
- Supabase（データベース）

【法務確認事項】
1. Stripe Connectを使用する場合、資金移動業ライセンスは必要か？
2. 残置物の引き継ぎは宅建業法の適用対象か？
3. このビジネスモデルで致命的な法的リスクはあるか？
```

## 6. 相談後のアクション

### 6.1 即座に実行

1. 相談内容をチームに共有（CEO、CLO、CFO）
2. 致命的リスクがあれば、ビジネスモデルを修正
3. 利用規約の修正（弁護士の指摘を反映）

### 6.2 追加相談が必要な場合

**想定ケース:**
- 文章相談では回答が不明確
- 利用規約の詳細レビューが必要
- 継続的な法務アドバイザリーが必要

**追加コスト:**
- 電話相談（30分）: ¥15,000-25,000
- 利用規約レビュー（文章）: ¥10,000-20,000
- 利用規約レビュー（対面）: ¥30,000-50,000

**総コスト見積:**
- 最小: ¥3,000-10,000（文章相談のみ）
- 推奨: ¥20,000-30,000（文章相談 + 規約レビュー）
- 最大: ¥40,000-60,000（文章相談 + 電話相談 + 規約レビュー）

**削減効果:** 当初見積¥40,000-70,000 → ¥10,000-30,000

## 7. よくある質問

### Q1: 文章相談で十分な回答が得られるか？

A: 基本的な法的質問（資金決済法、宅建業法の適用可否等）には十分対応可能。
   複雑な議論が必要な場合は、追加で電話相談に切り替え。

### Q2: 文章相談で回答が不明確だった場合は？

A: 追加で電話相談（¥15,000-25,000）を依頼可能。
   それでも予算内（¥40,000-60,000）に収まる。

### Q3: 弁護士の質は信頼できるか？

A: 弁護士ドットコムは過去の回答事例、評価、専門分野で絞り込み可能。
   評価が高く、Fintech/不動産法務専門の弁護士を選べば信頼性は高い。

### Q4: 相談内容は秘密保持されるか？

A: 弁護士には守秘義務があり、相談内容は秘密保持される。
