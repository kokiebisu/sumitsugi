## 2. 変動費（取引ベース）

### 2.1 Stripe 決済手数料

| 項目                           | 料率/金額          | 備考                                |
| ------------------------------ | ------------------ | ----------------------------------- |
| カード決済手数料               | 3.6%               | 日本国内カード                      |
| 1件あたり固定費                | （料率に含まれる） | 日本では別途固定費なし              |
| JCTカード（消費税加算後）      | 実質約3.96%        | Stripe手数料に消費税10%が加算される |
| Connect アプリケーションフィー | 追加費用なし       | プラットフォーム手数料徴収機能      |

**注:** Stripe Japan の決済手数料は3.6%（Visa/Mastercard/AMEX/JCB共通）。2023年10月以降、Stripe手数料に対して消費税10%が加算されるため、実効レートは約3.96%。

### 2.2 Stripe 振込（Payout）手数料

| 項目                 | 料率/金額 | 備考                                |
| -------------------- | --------- | ----------------------------------- |
| 国内銀行振込         | ¥0        | 日本国内口座への振込は無料          |
| 自動振込スケジュール | -         | 週次/月次選択可（日次は日本未対応） |

### 2.3 取引あたりのコスト分析

**引越し費用 ¥100,000 の場合（BUSINESS.md準拠）:**

| 項目                       | 金額        | 備考                   |
| -------------------------- | ----------- | ---------------------- |
| 引越し費用（次の住人支払） | ¥100,000    | 決済総額               |
| Stripe決済手数料（3.6%）   | -¥3,600     | tsumugi負担            |
| JCT加算分（+10%）          | -¥360       | Stripe手数料への消費税 |
| **Stripe合計コスト**       | **-¥3,960** |                        |

**補足:** 分配の正確な内訳（BUSINESS.md準拠）:

| 宛先         | 金額     |
| ------------ | -------- |
| 前の住人     | ¥74,000  |
| tsumugi(15%) | ¥15,000  |
| 清掃費       | ¥8,000   |
| 大家協力金   | ¥3,000   |
| **合計**     | ¥100,000 |

**tsumugiの実質収益:**

- プラットフォーム手数料: ¥15,000
- Stripe手数料: -¥3,960（¥100,000 x 3.96%）
- 紹介フィー（Phase A）: -¥3,000
- **純収益: ¥8,040/件**（¥100,000の場合）

### 2.4 引越し費用別シミュレーション

**注:** 大家協力金・清掃費は引越し費用から分配されるが、tsumugiの手数料15%とは別枠のため、tsumugi収益からは差し引かない。紹介フィー¥3,000のみtsumugi手数料から支出。

## 5. 6ヶ月予算との整合性

### 改定予算（¥147,000-167,000）との比較

| 項目                     | 予算             | 本リスト試算     | 差分                    |
| ------------------------ | ---------------- | ---------------- | ----------------------- |
| 法務コスト               | ¥40,000-70,000   | ¥40,000-70,000   | ±¥0                     |
| ドメイン（6ヶ月）        | ¥3,000           | ¥1,500-2,520     | -¥480〜-¥1,500          |
| インフラ（6ヶ月）        | ¥0               | ¥0-18,000        | +¥0〜+¥18,000           |
| Claude Code Max（6ヶ月） | ¥96,000          | ¥180,000         | **+¥84,000**            |
| 予備費                   | ¥20,000          | ¥20,000          | ±¥0                     |
| **合計**                 | ¥147,000-167,000 | ¥241,500-290,520 | **+¥94,500〜+¥123,520** |

### 重要な発見

1. **Claude Code Max のコスト認識に乖離がある可能性**
   - ダッシュボード記載: ¥96,000/月
   - 公式価格: $200/月 = 約¥30,000/月
   - ¥96,000/月が正しい場合、6ヶ月で¥576,000となり予算を大幅に超過
   - $200/月の場合でも6ヶ月で¥180,000（予算の大部分を占める）
   - **要確認: 実際の支払額を確認し、予算を再計算すべき**

2. **Vercel商用移行のタイミング**
   - 初回取引発生時にHobby→Pro移行が必要（商用利用規約）
   - 追加コスト: ¥3,000/月

3. **インフラコストは極めて低い**
   - Claude Code Max を除けば、月額¥250-¥3,420
   - 無料プランの活用が有効に機能している
