## 長期ビジョン: 暮らしの世界観エコシステム（座談会#12）

> 座談会#12（2026-02-07）にて議論。MVPスコープ外の将来構想。
> ヒアリングから得た洞察：レンタル家具では「暮らしの世界観」は再現できない。
> sumitsugiの本質的差別化は「空間まるごとの引き継ぎ」にある。

### V-1. 世界観 ≠ 家具だけ

**発見:** 暮らしの世界観の半分以上は家具以外で構成される。

- フロアタイル、観葉植物、照明、壁面装飾、こだわりの道具（コーヒーマシン等）
- レンタル家具＝パーツの一時貸し / ホームステージング＝見せかけの空間演出
- **sumitsugi＝本物の暮らしの引き継ぎ（モノ＋世界観＋ストーリー）**

**将来的な方向:** 引き継ぎ対象カテゴリを家具以外にも拡張（キッチン用品、植物、照明、床材、壁面装飾）

### V-2. コアセットモデル

**発見:** 「暮らし一式を残す」はほとんどの前の住人にとってハードルが高い（プロ統計: 思い入れのある小物の80%は持っていかれる）。出品ハードルの高さは供給減に直結する。

**解決策: コア＆パーソナルの分離**

| レイヤー                     | 内容                                                                     | 引き継ぎ       |
| ---------------------------- | ------------------------------------------------------------------------ | -------------- |
| **コア（空間の骨格）**       | 部屋の世界観を定義する5〜6点（ソファ、テーブル、ラグ、カーテン、照明等） | **残す**       |
| **パーソナル（個人の記憶）** | その人自身のアイデンティティに紐づくアイテム                             | **持ち出しOK** |

- 前の住人が出品時に「世界観の主役」を選んでコアセットを定義
- パーソナルアイテムが抜けた場所は「穴」ではなく「余白」として次の住人の自由に
- **「リセットしたい」と「引き継ぎたい」は矛盾しない** — sumitsugiがあるから安心してリセットできる

**ペルソナの声:**

> 🎨 レイ: 「抜けた穴じゃなくて**余白**になる」
> 🔄 トモヤ: 「**主役を5つ選んでください**って聞かれたら、むしろ楽しかった」

### V-3. 引き継ぎノート＋期間限定チャット

**発見:** コアセットで世界観の骨格を引き継いでも、「余白」をどう埋めるか分からない次の住人がいる。

| 機能               | 内容                                                                                                     | 期間                              |
| ------------------ | -------------------------------------------------------------------------------------------------------- | --------------------------------- |
| **引き継ぎノート** | 前の住人が書く「この部屋の暮らし方ガイド」（インテリア余白アドバイス、暮らしの知恵、生活情報、実用情報） | 永続（物件ページに残る）          |
| **相談チャット**   | 余白の埋め方、使い方の質問                                                                               | 引き継ぎ後1ヶ月限定（希望者のみ） |

**ペルソナの声:**

> 🏠 ユキ: 「前の住人から次の住人への**手紙**みたいな」
> 🔄 トモヤ: 「それってまさに**暮らしを紡ぐ**。sumitsugiそのもの」

### V-4. レコメンドフィー（ビジネスモデルの新しい柱）

**発見:** 前の住人が余白の埋め方を提案→次の住人が購入→売上の一部を還元。「相談料」（直接課金）は心理的ハードルが高いが、「おすすめ経由の購入→還元」なら三方よし。

**分配イメージ:**

```
次の住人が商品を購入
  ├→ EC事業者: 90%
  └→ レコメンドフィー: 10%
       ├→ 前の住人: 7%
       └→ sumitsugi:  3%（プラットフォーム収益）
```

**収益モデルの進化:**

| 収益源                 | タイミング               | 性質                                                                                              |
| ---------------------- | ------------------------ | ------------------------------------------------------------------------------------------------- |
| 引き継ぎ手数料         | 引き継ぎ成立時           | 一回限り（MVP）                                                                                   |
| レコメンドフィー       | おすすめ経由購入時       | **継続的**（将来）                                                                                |
| プロ連携フィー         | コーディネーター提案経由 | 継続的（さらに将来）                                                                              |
| IC相談マッチング手数料 | IC相談成立時             | **継続的**（Phase 2、[座談会#20](./meetings/2026-02-27-product-meeting-20-product-direction.md)） |

### V-5. 暮らしのキュレーター経済圏

**発見:** 引き継ぎを繰り返すほど「クライアント」（過去に自分の空間に住んだ人）が蓄積され、レコメンドフィーがストック型収入になる。やがて「暮らしのキュレーター」を本業にする人が出現しうる。

**エコシステム:**

- 引き継ぎN回目 → 累計N人のクライアント → レコメンドフィー × N（ストック型）
- 引き継ぎ回数・おすすめ購入率・住人満足度がポートフォリオとして蓄積
- 次の住人は物件スペックではなく「誰が暮らしを作ったか」で部屋を選ぶ時代
- Airbnbスーパーホストの「定住版」— ホストより深くて長い関係

**三者のメリット:**

| プレイヤー   | メリット                                                       |
| ------------ | -------------------------------------------------------------- |
| キュレーター | 引き継ぐほどクライアント増、ストック型収入、ポートフォリオ蓄積 |
| 次の住人     | 実績あるキュレーターの空間を「指名」で選べる安心感             |
| sumitsugi    | 良質な供給の安定確保＋レコメンドフィーの継続収益               |
