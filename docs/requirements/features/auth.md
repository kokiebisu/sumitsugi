## 認証方式（技術会議#13で確定）

- **MVP:** Magic Link認証のみ（Better-auth + Resend）
- **Post-MVP:** Google OAuth追加を検討（ログイン離脱率20%超が判断基準）
- **根拠:** ペルソナの本質的ニーズ「パスワード不要の手軽さ」はMagic Linkで解決済み。OAuth consent screen審査・プライバシーポリシー更新の隠れコストを回避
