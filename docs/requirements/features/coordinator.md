# コーディネーター連携

> 旧 REQUIREMENTS.md §5.10 | Feature IDs: F-901〜F-903 | DESIGN_DOC参照: — | 最終更新: 2026-02-07

---

インテリアコーディネーターが関与した物件の差別化と、プロの空間を手軽に体験できる仕組み。

| ID    | 機能名                         | 説明                                                     | 優先度 |
| ----- | ------------------------------ | -------------------------------------------------------- | ------ |
| F-901 | コーディネーター・クレジット   | リスティングに「○○さんがコーディネート」を表示           | P2     |
| F-902 | プロがコーディネート・バッジ   | プロ関与物件に専用バッジを表示（物件カード・詳細ページ） | P2     |
| F-903 | コーディネーター・プロフィール | コーディネーターの実績・ポートフォリオへのリンク         | P2     |
