# コーディネーター連携

> 旧 REQUIREMENTS.md §5.10 | Feature IDs: F-901〜F-903 | DESIGN_DOC参照: — | 最終更新: 2026-02-27

---

インテリアコーディネーターが関与した物件の差別化と、プロの空間を手軽に体験できる仕組み。

> **座談会#20（2026-02-27）:** F-901〜F-903は「IC相談マッチング機能」の一部として再位置づけ。写真ファーストUXでICとユーザーをマッチングし、ICが価格設定（5,000〜10,000円/回目安）、プラットフォーム手数料20-30%。詳細は[座談会#20議事録](../meetings/2026-02-27-product-meeting-20-product-direction.md)および[future.md](../future.md)参照。
