# 緊急退去対策

> 旧 REQUIREMENTS.md §5.6 | Feature IDs: F-501〜F-511 | DESIGN_DOC参照: T-4 | 最終更新: 2026-02-07

---

退去日までに次の住人が見つからない場合のリスクを軽減するための機能群。
「セーフティネットを後から張る」より「最初から期待値を調整し、正直に伝える」アプローチを採用。

## 出品ルール・期待値調整

| ID    | 機能名               | 説明                                                             | 優先度 |
| ----- | -------------------- | ---------------------------------------------------------------- | ------ |
| F-501 | 退去日フィールド     | リスティング作成/編集時に `moveOutDate` を必須入力               | P0     |
| F-502 | 最低猶予期間チェック | 退去1ヶ月未満は出品不可（エラー表示）、1-2ヶ月は警告モーダル表示 | P0     |
