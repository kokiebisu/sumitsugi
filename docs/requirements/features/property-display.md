# 物件表示機能

> 旧 REQUIREMENTS.md §5.1 | Feature IDs: F-001〜F-006 | DESIGN_DOC参照: — | 最終更新: 2026-02-07

---

| ID    | 機能名                   | 説明                                                   | 優先度 |
| ----- | ------------------------ | ------------------------------------------------------ | ------ |
| F-001 | 物件一覧表示             | 公開中の物件をグリッド形式で表示                       | 高     |
| F-002 | 物件詳細表示             | 物件の詳細情報を表示                                   | 高     |
| F-004 | 画像ギャラリー           | 物件の写真をカルーセル形式で表示                       | 高     |
| F-005 | テイスト検索・フィルター | 雰囲気（北欧風・ミニマル等）・エリア・価格帯で絞り込み | 高     |
| F-006 | 暮らしストーリー表示     | 前の住人のコンセプト・暮らし方を物件詳細に表示         | 高     |
