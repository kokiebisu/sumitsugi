# 物件登録・管理機能

> 旧 REQUIREMENTS.md §5.2 | Feature IDs: F-101〜F-105 | DESIGN_DOC参照: T-4, T-6 | 最終更新: 2026-02-07

---

| ID    | 機能名                   | 説明                         | 優先度 |
| ----- | ------------------------ | ---------------------------- | ------ |
| F-101 | 物件新規登録             | 前の住人が物件情報を登録     | 高     |
| F-102 | 物件編集                 | 登録済み物件情報の編集       | 高     |
| F-103 | 物件プレビュー           | 公開前の物件プレビュー       | 中     |
| F-104 | ステータス管理           | 下書き/公開の切り替え        | 高     |
| F-105 | 物件一覧（前の住人向け） | 自身が登録した物件の一覧表示 | 高     |

> **フォーム設計方針（座談会#4: 急ぎ型向けスピード出品フロー）：**
>
> ケンジ（急ぎ型）のように転勤で時間がない前の住人でも3〜5分で出品完了できるよう、必須/任意フィールドを明確に分離する。
>
> - **必須フィールド（出品に最低限必要）：** タイトル、部屋の写真（1枚以上）、家具リスト、退去予定日（未定も可）、管理会社名、引越し理由（moveOutReason）
> - **任意フィールド（後から追加可能）：** コンセプト、暮らしの説明、テイスト、動画ツアー、FAQ、契約期間
> - 任意フィールドは「あとで追加」セクションとして折りたたみ表示
