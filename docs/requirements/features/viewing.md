# 内見負担軽減

> 旧 REQUIREMENTS.md §5.9 | Feature IDs: F-801〜F-804 | DESIGN_DOC参照: T-5 | 最終更新: 2026-02-07

---

前の住人の内見対応負担を軽減し、本気度の高い次の住人とのマッチングを促進する機能群。
「とりあえず見たいだけ」の層をフィルタリングし、本気の1〜2回で決まる内見体験を目指す。

## 事前情報提供

| ID    | 機能名             | 説明                                                                         | 優先度 |
| ----- | ------------------ | ---------------------------------------------------------------------------- | ------ |
| F-801 | FAQ機能            | 前の住人がよくある質問と回答を事前登録。同じ質問への重複対応を削減           | 高     |
| F-802 | 動画ツアー（任意） | 部屋の雰囲気を伝える動画アップロード。「とりあえず見たい」層のフィルタリング | P2     |

## マッチング品質向上

| ID    | 機能名                     | 説明                                                                    | 優先度 |
| ----- | -------------------------- | ----------------------------------------------------------------------- | ------ |
| F-803 | 内見希望者プロフィール表示 | 問い合わせ者の自己紹介・興味を持った理由を前の住人に表示                | 高     |
| F-804 | 内見承認制                 | 前の住人が内見希望を承認/辞退できる仕組み（問い合わせステータスと連動） | 高     |
