# 引き継ぎフロー可視化

> 旧 REQUIREMENTS.md §5.7 | Feature IDs: F-701〜F-713 | DESIGN_DOC参照: — | 最終更新: 2026-02-07

---

ユーザーが引き継ぎの全体像と現在地を把握できるようにするための機能群。
前の住人・次の住人双方が「次に何をすればいいか」を常に理解できる状態を目指す。

## 全体像の可視化

| ID    | 機能名             | 説明                                                                                           | 優先度  |
| ----- | ------------------ | ---------------------------------------------------------------------------------------------- | ------- |
| F-701 | 使い方ガイドページ | 引き継ぎの全体フロー（9ステップ）を図解で説明するページ。前の住人向け・次の住人向けの2パターン | **MVP** |
| F-702 | 費用の仕組み説明   | 引越し費用の構成・支払いタイミング・エスクローの安心感を分かりやすく図解                       | 高      |
| F-703 | 所要期間の目安表示 | 「問い合わせ〜入居まで約3〜6週間」のような目安をフローに併記                                   | 中      |

## 進捗の可視化

| ID    | 機能名                 | 説明                                                                                                  | 優先度 |
| ----- | ---------------------- | ----------------------------------------------------------------------------------------------------- | ------ |
| F-711 | ステップインジケーター | 問い合わせ後、現在どのステップにいるかを視覚的に表示（前の住人・次の住人双方に）                      | 高     |
| F-712 | 次のアクション案内     | 各ステップで「次にやること」を明示。例：「内見日程を返信してください」                                | 高     |
| F-713 | 支払いタイムライン     | 支払い（MVP: 2段階 申込金→残額一括）をいつ・なぜ・いくら払うか視覚表示。Post-MVPで3段階化検討時に更新 | 高     |
