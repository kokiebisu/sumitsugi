# プロダクトミーティング #6: リマインド通知チャネル

**日時:** 2026-02-07
**議題:** F-205 / F-206 の配信チャネル・スケジュール・文面設計
**参加ペルソナ:** 🏠 ユキ、⏰ ケンジ、🔄 トモヤ、🎨 レイ

---

## 背景

F-205（承認リマインド通知）とF-206（承認期限切れ自動処理）のタイミング（7日・14日・21日・30日）は決まっていたが、**配信チャネル**（メール？SMS？LINE？プッシュ通知？）と**文面の具体設計**が未定義だった。

---

## 議論のハイライト

### チャネル選定

**全員合意: メールのみ（MVPではSMS/LINE/プッシュ通知は不要）**

> 🏠 ユキ: 「メールが一番確実。LINEの通知は友達のメッセージに埋もれちゃうし、アプリのプッシュ通知は切っちゃう」
> 🎨 レイ: 「メールは『あとで見よう』ってスルーされやすい。だから**件名のインパクト**が大事」

### SMS併用の検討と却下

> ⏰ ケンジ: 「メールだけで大丈夫ですか？SMSも併用した方がいいんじゃないですか？SMSなら絶対に気づく」
> 📋 佐藤さん（前回参加時の証言に基づく）/🔄 トモヤ: 「MVPでSMS連携ってコスト的にどうなの？」

→ SMSは却下。代わりに**メールの回数と件名の緊迫感を段階的に上げる**ことで対応。

### 27日目の最終通知追加（新規決定）

> ⏰ ケンジ: 「21日から30日の間が**9日間も空いてる**のが不安。27日目に最終通知が入れば、さすがに気づく」

→ 既存の7日・14日・21日に加えて**27日目に最終通知**を追加（4段階に拡張）。

### 文面の状況別出し分け（トモヤの提案）

> 🔄 トモヤ: 「管理会社に相談済みなのに催促されてもどうしようもない。**的外れなリマインドが一番嫌われる**。状況に応じた文面の出し分けは絶対やるべき」
> 🎨 レイ: 「さすが二度目の人。『もうやったのに催促してくるな』って思われたら信頼を失う」

→ `managementConsultedAt` の有無で文面を出し分けることを決定。

### CTAボタンの重要性

> 🔄 トモヤ: 「リマインドメールが来ても、『で、何すればいいんだっけ？』ってなると後回しにしちゃう。**1クリックで更新画面に飛べるCTAボタン**が必要」
> 🏠 ユキ: 「ボタン1つで更新画面に飛べるなら、その場でやっちゃうと思う」

### 自動非公開後の再公開パス（ケンジの提案）

> ⏰ ケンジ: 「非公開になった後のリカバリー手段も明記してほしい。承認ステータスを更新すれば再公開できるんですよね？」
> 🏠 ユキ: 「再公開できるなら安心。30日で削除されるわけじゃなくて、一時停止みたいなものだったら、そこまで怖くない」

→ F-206の自動非公開は**一時停止**であり、削除ではない。再公開パスを明確化。

---

## 決定事項

### 配信チャネル

**メールのみ（MVP）。** SMS/LINE/プッシュ通知はPhase 2以降で検討。

### リマインドスケジュール（4段階）

| 日数   | 種別       | 件名トーン | 未相談の場合                                                | 相談済みの場合                                   |
| ------ | ---------- | ---------- | ----------------------------------------------------------- | ------------------------------------------------ |
| 7日目  | リマインド | 穏やか     | 「管理会社へのご相談はお済みですか？」                      | 「管理会社からの返答はありましたか？」           |
| 14日目 | リマインド | やや強め   | 「承認ステータスの更新をお忘れなく」                        | 「返答があれば承認ステータスを更新してください」 |
| 21日目 | 警告       | 緊迫       | 「あと9日で自動非公開になります」                           | 「あと9日で自動非公開になります」                |
| 27日目 | 最終通知   | 最終警告   | 「3日以内に更新がない場合、リスティングが非公開になります」 | 同左                                             |

### メール要件

- 全メールに**CTAボタン**「承認ステータスを更新する → [リンク]」を配置
- `managementConsultedAt` の有無で**文面を出し分け**（7日目・14日目）
- 件名に**残日数**を含める（21日目以降：「あと○日」）

### F-206 自動非公開の仕様明確化

- 非公開は**一時停止**であり、削除ではない
- 非公開化時のメール: 「リスティングが非公開になりました。承認ステータスを更新すれば再公開できます → [更新リンク]」
- 承認ステータス更新 → 再公開可能

### 出し分けロジック

```
if (managementConsultedAt == null) {
  // 未相談パターン: 管理会社への相談を促す
} else {
  // 相談済みパターン: 返答確認・ステータス更新を促す
}
```
