# プロダクトミーティング #14-5: 緊急退去対策（F-501〜F-511）

**日時:** 2026-02-09
**参加ペルソナ:** ⏰ ケンジ、🏠 ユキ、🧳 ソウタ、🌱 ハル
**ファシリテーター:** 👤 CPO

## 背景

`docs/requirements/features/move-out-safety.md` の機能仕様について、ペルソナ座談会で決定根拠を検証・記録する。

---

## 議論

👤 **CPO:** ケンジさん、来月末退去ですよね。何が一番心配ですか？

⏰ **ケンジ:** 「一番怖いのは**退去日までに次の住人が見つからないこと**。その場合、結局粗大ゴミに出さなきゃいけない。出品したはいいけどマッチングしなかった時の**プランB**がないと、怖くて出品できない。**F-501の退去日フィールドは当然必須**。これがないとスケジュールが立たない」

🏠 **ユキ:** 「ケンジさんの言う通り、退去日は必須ですよね。**F-502の最低猶予期間チェック**も納得。退去1ヶ月未満で出品されても、内見→契約→引き継ぎは物理的に間に合わない。ただ、**1ヶ月未満でも出品したい人はいる**んじゃない？0円で『引き取ってくれる人を探す』みたいな使い方もあるかも」

⏰ **ケンジ:** 「ユキさん、それはまさに俺のパターン。**タダでもいいから持ってって**って場合、1ヶ月未満でも出品したいよね。でもエラーで出品不可は厳しい。**警告は出すけど出品自体はできる**方がいいんじゃない？」

🧳 **ソウタ:** 「ケンジさんの状況は分かるけど、**次の住人側からすると1ヶ月未満は危険**なんだよ。賃貸契約の手続きに2〜3週間かかるのに、残り3週間で全部やるのはお互いに無理。**出品不可じゃなくて、『引き継ぎではなく引き取り希望』として別カテゴリにするのはどう？** マッチングの期待値が全然違うから」

🌱 **ハル:** 「ソウタさん、それ賢いですね。引き継ぎと引き取りは分けた方がいい。あと、**段階的通知（F-503〜F-506）**ってMVPで要りますか？最初は運営が手動で声かければいいし。自動通知の文面って、間違えるとプレッシャーになりそう」

⏰ **ケンジ:** 「ハルくん、**1ヶ月前の通知（F-504）だけはMVPでも欲しい**。処分の手配って2〜3週間前から始めないと間に合わない。2ヶ月前とか2週間前は後でいいけど、**1ヶ月前の『処分も並行して検討を』は現実的で正直なアドバイス**」

🏠 **ユキ:** 「ケンジさんに同意。sumitsugiは**『絶対引き継げます！』って嘘をつかない**方がいい。1ヶ月前に正直に『並行して処分も考えましょう』って言ってくれるサービスの方が信頼できる」

---

## 決定事項

| 機能                                | 決定                   | 根拠                                                                               |
| ----------------------------------- | ---------------------- | ---------------------------------------------------------------------------------- |
| **F-501 退去日フィールド**          | MVP必須（P0）          | スケジュール管理の基盤（ケンジ）                                                   |
| **F-502 最低猶予期間チェック**      | MVP必須（P0）          | 1ヶ月未満は出品不可、1-2ヶ月は警告。「引き取り別カテゴリ」は将来検討（ソウタ提案） |
| **F-503 退去日アラート（2ヶ月前）** | Post-MVP               | 手動対応で代替                                                                     |
| **F-504 退去日アラート（1ヶ月前）** | Post-MVP（優先度高い） | 処分手配に2-3週間必要（ケンジ）。正直なアドバイスが信頼に（ユキ）                  |
| **F-505〜F-506**                    | Post-MVP               | 段階的通知は実運用後                                                               |
| **F-507〜F-511**                    | Post-MVP〜P2           | 物件数拡大後に順次実装                                                             |
