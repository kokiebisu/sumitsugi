## 議論のハイライト

### F-611: 残置物引き継ぎ相談資料

**佐藤さん（受け取り手）の核心要求:**

> 📋 佐藤さん: 「私が見るのは**最初の30秒で『何をすればいいか』が分かるかどうか**」

管理会社のアクション手順（①確認 ②転送 ③連絡）を**冒頭に配置**すること。

**田中オーナー（最終判断者）の核心要求:**

> 🏢 田中オーナー: 「聞いたことないサービスの名前がデカデカと書いてあると、それだけで怪しいなって思っちゃう」

sumitsugiブランディングは控えめに。タイトルは「残置物引き継ぎのご相談」。メリット（空室短縮）とリスク対応（原状回復・責任）をセットで明記。

**リュウ・ユキ（送り手）の核心要求:**

> 🌏 リュウ: 「PDFが**全部代わりに説明してくれる**のが本当にありがたい。でも難しい不動産用語が並んでたら、自分が何を送ってるのかも分からなくなる」

PDFが代弁者として機能し、口頭説明が不要であること。平易な日本語で書くこと。

**ケンジ（速度重視）の制約:**

> ⏰ ケンジ: 「A4で3枚以内に収まりますよね？5枚とかになったら佐藤さん読まないですよ」
> 📋 佐藤さん: 「…まあ正直、その通りです（笑）。3枚がギリギリ」

### メール送付テンプレートの必要性（新規発見）

> 🌏 リュウ: 「PDFだけ添付して送ればいいとしても、メール本文に何て書けばいいか分からない」
> 🏠 ユキ: 「リュウさん、それ私も欲しい！テンプレがコピペできたら最高」

→ F-611の付随ツールとして**メール送付テンプレート**を提供することを決定。

### F-612: 署名方式の決定（DocuSign不要）

**議論の核心：** 電子署名（DocuSign等）をMVPから入れるべきか？

**結論：MVPでは紙の手書き署名。DocuSignは不要。**

根拠：

1. **ユーザー受容性** — 田中オーナー: 「DocuSignって何ですか？リンクが来たらフィッシングだと思っちゃう」。不動産業界の大家の8割が電子署名に不慣れ
2. **速度改善効果なし** — 佐藤さん: 「電子署名にしたからって返事が早くなるわけじゃない。ツールの問題じゃなくて、決断の問題」。ボトルネックは署名ツールではなくオーナーの判断時間
3. **代替手段で十分** — ケンジ: 「写真撮って送るだけでOKなら、それでいいんじゃないですか？」。田中オーナー: 「写真ならスマホのカメラだけでいい」。印刷→署名→スマホ写真→メール返送で2〜3日で回収可能
4. **開発工数** — DocuSign API連携の開発工数がMVP段階では過剰
5. **将来検討** — Phase B+で提携管理会社が増えた段階で電子署名オプションを検討

## 決定事項

### 設計原則（全ペルソナ合意）

- **結論ファースト**: 管理会社のアクション手順を最初に配置
- **sumitsugiブランディングは控えめ**: ロゴは小さく。タイトルは「残置物引き継ぎのご相談」
- **A4で3枚以内**: 管理会社は長い書類を読まない
- **平易な日本語**: 前の住人自身が内容を理解できるレベル

### F-611: 残置物引き継ぎ相談資料（A4 3枚以内）

```
[ヘッダー]
  タイトル: 「残置物引き継ぎのご相談」
  sumitsugiロゴ: 小さく控えめに配置

[セクション1: 管理会社様へのお願い]  ← 最初に配置
  ① 本資料の内容をご確認ください
  ② オーナー様へ転送をお願いいたします
  ③ 結果を下記メールアドレスにご連絡ください
  連絡先: [前の住人のメールアドレス]

[セクション2: 概要]
  物件名 / 入居者名 / 退去予定日
  サービス説明（1文）: 「入居者同士で家具・インテリアを引き継ぐサービスです」
  内見について: 「退去までの間、引き継ぎ希望者への内見を実施予定です」

[セクション3: 家具・インテリアリスト]（暫定）
  品名 / 写真 / 状態 / 購入時期（分かれば）

[セクション4: オーナー様のメリット]
  ・空室期間の短縮（家具付き物件は入居が決まりやすい傾向）
  ・原状回復コストの削減（家具搬出・処分が不要）
  ・入居者満足度の向上

[セクション5: リスク対応・条件]
  ・原状回復の条件
  ・家具所有権の移転説明（引き継ぎ完了時に次の入居者へ移転）
  ・責任の所在

[セクション6: 補足FAQ]（2〜3問）
  Q: これは何のサービスですか？
  Q: オーナーに費用はかかりますか？
  Q: トラブル時はどうなりますか？
```

```
ご確認のほど、よろしくお願いいたします。

```

### F-612: 残置物同意書（A4 2枚以内）

```
[ヘッダー]
  タイトル: 「残置物引き継ぎ同意書」

[セクション1: 物件情報]
  物件名 / 住所 / 現入居者名 / 次の入居者名

[セクション2: 確定家具リスト]
  品名 / 写真 / 状態

[セクション3: 同意事項]（箇条書き・明確に）
  ・上記家具の次の入居者への引き継ぎを承認します
  ・家具の所有権は引き継ぎ完了時に次の入居者に移転します
  ・原状回復条件: [具体的な条件]
  ・退去時の引き継ぎ対象外の家具は現入居者が搬出します

[セクション4: 署名欄]
  日付:          /  オーナー名（自署）:
  返送方法（いずれかで）:
    メール: [アドレス]  /  FAX: [番号]  /  郵送: [住所]
  ※ 署名後、写真を撮ってメール送信でも可
```

署名方式: **紙の手書き署名（MVPではDocuSign不要）**

### F-616: 仲介向け物件シート（A4 2枚以内）

```
[ヘッダー]
  タイトル: 「家具付き物件のご案内」

[セクション1: 物件写真]（大きく・魅力的に）
[セクション2: 物件概要]（住所・間取り・家賃・退去予定日）
[セクション3: 家具付き情報]（リスト＋写真）
[セクション4: 大家承認状況]（承認済み/未承認を明記）
[セクション5: 契約フロー説明]（通常の賃貸契約+家具引き継ぎ）
[セクション6: sumitsugi連絡先]
```
