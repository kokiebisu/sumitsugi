## 背景

`docs/requirements/features/property-display.md` の機能仕様について、ペルソナ座談会で決定根拠を検証・記録する。

## 議論

👤 **CPO:** 最初のテーマは物件表示です。一覧表示、詳細表示、画像ギャラリー、テイスト検索、暮らしストーリー表示の5つ。ハルさん、初めてtsumugiを開いた時、何が見たいですか？

🌱 **ハル:** 「正直、部屋を探す時って**写真がすべて**なんですよね。SUUMOとかでも、写真が少ない物件はスルーしちゃう。tsumugiの場合は家具付きだから、**家具と部屋が一緒に写ってる写真**が絶対必要。あと、一覧でグリッド表示っていうのは直感的でいいと思います。Instagramみたいに雰囲気で選べる感じ」

🧳 **ソウタ:** 「ハルくんの言う通り、写真は大事。でも俺はもっとシンプルでいい。**価格・エリア・入居可能日**がパッと見えれば十分。テイスト検索？悪くないけど、最初は物件数少ないでしょ？フィルターかけたら結果0件、みたいなのは萎える。**物件数が少ないうちは全件表示でいいんじゃない？** フィルターは飾りになる」

🍵 **ノリコ:** 「ソウタさんの言う『物件数少ないうちは全件表示』、それは確かにそうね。でも私は**テイスト検索はあった方がいい**わ。『北欧風』とか『ナチュラル』で探したい。年齢的にミニマルとかモダンは若い人向けだし、自分に合うテイストで絞りたい。ただ、操作が分かりやすくないと困る。カテゴリが多すぎると迷うから、**5〜6個のテイストに絞ってほしい**」

🌏 **リュウ:** 「ノリコさんの意見に賛成です。テイスト名は**写真と一緒**に見せてほしい。『北欧風』って言われても、日本語は分かるけど具体的なイメージが湧かない時がある。**サムネイル付きのテイストタグ**なら、言語に関係なく直感的に選べます。あと、F-006の暮らしストーリーは、前の住人がどんな風に暮らしていたか分かるのですごくありがたい。日本の暮らし方を知る手がかりになります」

🌱 **ハル:** 「リュウさんの『サムネイル付きテイストタグ』、それめっちゃいいですね！僕もテイストの名前だけだとピンとこないことあるし。で、**F-006の暮らしストーリー**って、これがtsumugiの一番の特徴じゃないですか？SUUMOには間取りと設備しか載ってないけど、tsumugiは**『こういう暮らしをしてました』**が見える。これがないと普通の物件サイトと変わらない」

🏠 **ユキ:** 「ハルさん、ありがとう。出品する側としても、暮らしストーリーは**書きたい**です。3年間この部屋でどう過ごしてきたか、どんな気持ちでインテリアを選んだか。それが伝われば、この暮らしを大事にしてくれる人が来てくれると思う。ただ、**書くのが大変にならないように**してほしい。必須じゃなくて任意にしてほしいかな」

## 決定事項

| 機能                           | 決定                | 根拠                                                                                                                           |
| ------------------------------ | ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **F-001 物件一覧（グリッド）** | MVP必須             | 写真中心の直感的なUI。Instagram的な雰囲気で選べる体験（ハル）                                                                  |
| **F-002 物件詳細**             | MVP必須             | 写真+家具情報+暮らしストーリーの三位一体が必要                                                                                 |
| **F-004 画像ギャラリー**       | MVP必須             | 「写真がすべて」（ハル）。家具と部屋が一緒に写っている写真が必須                                                               |
| **F-005 テイスト検索**         | MVP（条件付き）     | ノリコ・リュウは必要、ソウタは物件数少ない時は不要。サムネイル付きテイストタグで直感的に（リュウ提案）。5〜6個に絞る（ノリコ） |
| **F-006 暮らしストーリー**     | MVP必須（任意項目） | tsumugiの最大の差別化ポイント（ハル）。前の住人も書きたい（ユキ）が、任意であるべき                                            |
