# プロダクトミーティング #14-8: 内見負担軽減（F-801〜F-804）

**日時:** 2026-02-09
**参加ペルソナ:** 🏠 ユキ、🌱 ハル、🏢 田中オーナー、📋 佐藤さん
**ファシリテーター:** 👤 CPO

---

## 背景

`docs/requirements/features/viewing.md` の機能仕様について、ペルソナ座談会で決定根拠を検証・記録する。

---

## 議論

👤 **CPO:** ユキさん、内見対応で一番大変なことは？

🏠 **ユキ:** 「**同じ質問に何度も答えること**。『家賃いくらですか？』『管理費は？』『ペットOK？』...リスティングに書いてあるのに。**FAQ機能（F-801）は絶対欲しい**。でもMVPの段階では問い合わせ件数も少ないから、リスティング詳細ページの情報充実で代替できるかも」

🌱 **ハル:** 「ユキさんの負担は理解します。でも、**内見に行く前にプロフィールが見える（F-803）**のは僕にとっても安心。ユキさんにとっても、誰が来るか分かる方がいいですよね。F-804の内見承認制は...問い合わせフォームのステータス管理と連動するなら、**F-201〜F-203の延長線上で対応できる**んじゃないですか？」

🏢 **田中オーナー:** 「内見で知らない人が物件に入るのは気になるけど、**住んでいる入居者が自分の判断で人を招くのは自由**です。問い合わせ経由で本人確認ができてれば問題ない。ただ、**承認制（F-804）は大家としても安心感がある**。入居者が自分の判断で『この人には見せたい/見せたくない』を選べるのは合理的」

📋 **佐藤さん:** 「内見の立ち会いとかは勘弁してほしいですけど、**前の住人が対応するなら管理会社は関与不要**。それでいい。FAQ機能もリスティングの情報充実も、うちの仕事は増えないので問題なし」

---

## 決定事項

| 機能                             | 決定     | 根拠                                                                           |
| -------------------------------- | -------- | ------------------------------------------------------------------------------ |
| **F-801 FAQ機能**                | Post-MVP | リスティング情報充実と問い合わせフォームで代替可能（ユキ）                     |
| **F-802 動画ツアー**             | Phase 2  | フィルタリング効果は高いが開発コスト大                                         |
| **F-803 内見希望者プロフィール** | 高優先度 | 双方の安心感（ハル、ユキ）。問い合わせフォーム項目として実装可能               |
| **F-804 内見承認制**             | Post-MVP | F-203と連動。大家も支持（田中オーナー）だがMVPでは問い合わせフォーム経由で代替 |
