# プロダクトミーティング #14-4: 認証・アカウント（F-301〜F-402）

**日時:** 2026-02-09
**参加ペルソナ:** 🌱 ハル、🍵 ノリコ、🌏 リュウ、🏠 ユキ
**ファシリテーター:** 👤 CPO

---

## 背景

`docs/requirements/features/auth.md` と `docs/requirements/features/account.md` の機能仕様について、ペルソナ座談会で決定根拠を検証・記録する。

---

## 議論

👤 **CPO:** 認証とアカウント機能、基本的なものですが気になる点はありますか？

🍵 **ノリコ:** 「サインアップとログインは当たり前だけど、**複雑なパスワード要件は勘弁してほしい**わ。大文字小文字数字記号...覚えられない。Googleログインとかで入れると助かる。あと、プロフィール表示（F-401）ってどの程度の情報？名前と写真くらい？年齢とか出るの？」

🌏 **リュウ:** 「ノリコさんに同意です。**Googleログインは必須**だと思います。日本のサービスって独自のログインが多くて、毎回パスワード作るのが面倒。あと、セラー化（F-304）って自動で切り替わるんですね。最初は物件を見る側で入って、出品したくなったら自動でセラーになる。**シンプルでいい**」

🌱 **ハル:** 「リュウさんの言う通り、セラー化の自動切り替えはストレスフリーですよね。プロフィール編集（F-402）は、**次の住人として問い合わせする時に自己紹介になる**から、ある程度は書ける方がいい。ユキさんに『どんな人が来るか分かる』って安心してもらえるように」

🏠 **ユキ:** 「ハルさん、その通り。**問い合わせ者のプロフィールが見えるのは安心**につながります。名前と自己紹介くらいは見たい。写真はなくてもいいけど、あると嬉しい」

---

## 決定事項

| 機能                       | 決定     | 根拠                                                                                 |
| -------------------------- | -------- | ------------------------------------------------------------------------------------ |
| **F-301 サインアップ**     | MVP必須  | ソーシャルログイン推奨（ノリコ「パスワード覚えられない」、リュウ「毎回作るの面倒」） |
| **F-302 ログイン**         | MVP必須  | 同上                                                                                 |
| **F-303 ログアウト**       | MVP必須  | 基本機能                                                                             |
| **F-304 セラー化**         | MVP必須  | 自動切り替えがシンプル（リュウ）                                                     |
| **F-401 プロフィール表示** | 中優先度 | 問い合わせ者の信頼度判断に寄与（ユキ）                                               |
| **F-402 プロフィール編集** | 中優先度 | 次の住人の自己紹介として機能（ハル）                                                 |
