## 背景

プロダクトオーナーから以下の問題提起:

1. 「誰でももっと気軽に部屋を綺麗にできたらいいな」 — 引越し時だけでなく、普段からインテリアを改善したい需要
2. 「インテリアコーディネーターとの距離を感じる」 — ICに頼むのに心理的ハードルがある。これをsumitsugiで解消したい

## テーマ1: ICとの心理的距離をどう縮めるか

👤 CPO: 今日のテーマは「プロダクトの方向性」です。大株主から「誰でも気軽に部屋を綺麗にしたい」「ICとの心理的距離を縮めたい」という2つの課題が出ています。マリさん、プロとして率直にどう思いますか？

🪑 マリ: これ、まさに私が日々感じている課題です。美容院には月1で行くのに、部屋のことはDIYで済ませようとする。「インテリアコーディネーター」って聞くと「高そう」「敷居が高い」って思われちゃう。実際は1万円くらいから相談できるのに。

🌱 ハル: マリさんの言う通りです。正直、ICに相談するって発想がそもそもなかったです。「自分でやるしかない」と思い込んでた。でも美容院みたいに気軽に相談できるなら、使いたいですね。

💐 ミナ: 私は「前髪カット」のインテリア版があったらいいなって思ってます。全部お任せじゃなくて、「このコーナーだけどうしたらいい？」みたいな小さい相談。

🪑 マリ: ミナさんのその発想、すごくいい。フルコーディネートじゃなくて「ワンポイント相談」。5,000円〜10,000円くらいで、写真見せて「この雰囲気にするにはどうすれば？」って聞ける。

🧳 ソウタ: 正直、僕はICに興味ないです。「安くて早い」が優先。でも、写真見て「この部屋の家具リスト教えて」くらいなら使うかも。500円とかなら。

🎨 レイ: ソウタさん、価値を分からない人に安売りするのは嫌だな...。でも入口を広くするのは大事かも。安い相談で入って、本気の人はフルコーディネートに進む、みたいな段階があれば。

🍵 ノリコ: 私は質重視だから、プロに相談したい気持ちは強いです。でも「どのICが自分に合うか分からない」のが不安。ポートフォリオが見られて、実際の部屋の写真があれば安心。

🌏 リュウ: 外国人としては、ICに相談する以前に「どこで家具を買えばいいか」すら分からない。写真を見せて「これと同じものを買いたい」って言えるサービスがあったら最高です。

プロダクトオーナーの要望で、Coordinate（既にサービス終了）、Hello Interior、その他の競合について深掘り分析を実施。

→ sumitsugiが「写真ファーストのIC相談マッチング」で参入できるポジション。

## テーマ2での議論

🪑 マリ: 市場を見ると、「写真から入る」IC相談って確かにない。ココナラだと「和モダンの部屋にしたいです」ってテキストで書かないといけない。sumitsugiなら写真タップで「この部屋みたいにしたい」って言える。

🌱 ハル: それめちゃくちゃいいです！テキストで説明するの苦手だし、そもそもインテリアの語彙がない。写真見せて「これ！」って言えるなら使います。

🧳 ソウタ: ココナラのIC出品者、1,168件も売れてるのか。市場はあるってことだな。でも、sumitsugiがやる理由は？引き継ぎと何の関係が？

🏠 ユキ: ソウタさん、それは私が答えます。sumitsugiに出品した写真が、そのまま「こんな部屋にしたい」のサンプルになるんです。引き継ぎ写真＝ショーケース。新しく写真を集める必要がない。

🎨 レイ: ユキさんの言う通り！私が作った部屋の写真が、「この雰囲気にするにはどうすれば？」の起点になる。コンテンツが自然に回る仕組み。これはRoomClipにもココナラにもない。

🍵 ノリコ: Modsyが潰れたのは怖いですね。広告費で無理した結果でしょう？sumitsugiは引き継ぎ写真が自然にコンテンツになるから、広告費ゼロでも回るってことですか？

🪑 マリ: ノリコさん、そうです。引き継ぎリスティング→写真蓄積→IC相談の起点、というフライホイールが回る。これが一番の差別化。

🌏 リュウ: 市場検証のデータとして、RoomClipの600万枚超の写真は「部屋を見たい」需要の証拠。ココナラの1,168件販売は「相談したい」需要の証拠。両方をつなげるのがsumitsugi。

## テーマ3: プロダクトビジョンの結論

👤 CPO: 議論をまとめます。「sumitsugiのコンセプトは変わるのか？」

全員の議論を経て、以下の結論に至りました:

### コンセプトは変えない、拡張する

**「暮らしを継ぐ」の「継ぐ」を拡張** — 家具だけでなく、プロの知識・センスも継ぐ。

### 2本柱のプロダクトモデル

| 柱                      | 体験                                           | 収益              |
| ----------------------- | ---------------------------------------------- | ----------------- |
| 🏠 **この部屋に住む**   | 従来の引き継ぎ（家具・暮らしを丸ごと引き継ぐ） | 引き継ぎ手数料15% |
| 🎨 **この雰囲気にする** | IC相談マッチング（写真を起点にプロに相談）     | IC相談料の20-30%  |

### 差別化ポイント

- **写真ファーストUX**: ココナラはテキスト起点、sumitsugiは写真タップ起点
- **コンテンツフライホイール**: 引き継ぎ写真が自然にIC相談のショーケースになる
- **手頃 × ブランド中立**: Hello Interiorの1/3〜1/6の価格帯（5,000〜10,000円/回）

### リスクと対策

| リスク                                    | 対策                                                  |
| ----------------------------------------- | ----------------------------------------------------- |
| Modsy型の失敗（マーケコスト）             | 引き継ぎ写真が自然にショーケースになるため広告不要    |
| IC品質のばらつき                          | レビュー制度、ポートフォリオ必須                      |
| 既存MVPとの整合性                         | Phase 2で最小限から検証（IC写真追加＋簡易相談フロー） |
| Laurel & Wolf型の失敗（フルフィルメント） | 提案のみモデル（家具購入はユーザー自身）              |

### 市場検証の根拠

- ココナラIC出品者: 1,168件販売 = 2,300万円超の市場が存在
- RoomClip: 600万枚超の写真 = 「部屋を見たい」需要は膨大
- Havenly（米国）: 成長中、家具ブランドの買収も実施 = ビジネスモデルは成立
- Modsy/Laurel & Wolf: 失敗の教訓 = マーケコスト過大とフルフィルメントを避ける

### 実装フェーズ

| フェーズ             | 内容                                                               |
| -------------------- | ------------------------------------------------------------------ |
| Phase 1（現在のMVP） | 変更なし。引き継ぎ機能に集中                                       |
| Phase 2              | IC写真ポートフォリオ追加、簡易IC相談フロー、ICアカウント・承認機能 |
| Phase 3              | ユーザー写真アップロード、IC検索・マッチング、レビュー制度         |

## CPO 最終まとめ

今日の議論で、sumitsugiの方向性が明確になりました:

1. **コンセプトは変えない** — 「暮らしを継ぐ」を拡張し、家具だけでなくプロの知識・センスも「継ぐ」対象に
2. **2本柱** — 「この部屋に住む」（引き継ぎ）＋「この雰囲気にする」（IC相談）
3. **差別化** — 写真ファーストUX、引き継ぎ写真→ショーケースのフライホイール
4. **リスク対策** — Modsy/Laurel & Wolf の失敗を学び、提案のみモデル＋コンテンツフライホイールで広告費を抑制
5. **既存MVPに変更なし** — IC相談機能はPhase 2で最小限から検証

**次のステップ:**

- 既存MVPの引き継ぎ機能は予定通り進める
- Phase 2のロードマップにIC相談マッチング機能を追加
- コーディネーター連携（F-901〜F-903）の位置づけを「IC相談マッチング」の一部として再整理
