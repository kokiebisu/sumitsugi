# プロダクトミーティング #9: 出品者向け値付けガイダンス

**日時:** 2026-02-07
**議題:** 出品者向けの値付け目安表示・新品価格入力の負荷軽減・ブランド表示
**参加ペルソナ:** 🏠 ユキ、🎨 レイ、🔄 トモヤ、🌱 ハル、🧳 ソウタ

---

## 背景

出品フォームに「希望価格」欄はあるが、値付けの手がかりが一切ない状態。出品者が「いくらに設定すべきか」迷って出品を止めるリスクがある。次の住人にも「この価格が適正か」を判断する比較情報がない。

---

## 議論のハイライト

### 値付け目安レンジ

**核心の対立: レイ vs ソウタ**

ソウタ（買い手・合理派）は「新品の30〜40%」といった明確な目安を要求。レイ（売り手・クリエイター型）は「下限を出すと市場全体の価格が下がる」と懸念。

> 🔄 トモヤ: 「目安レンジが『ない』方がもっと怖い。基準がないと出品者ごとにバラバラで、買い手は混乱する。レンジがあった方が高品質物件の価格が正当化される」

→ **妥協点:** 目安は「参考値」であり「推奨」ではないという文言にする。出品者はレンジ外も自由に設定可能。

### 新品価格入力の負荷問題

> 🏠 ユキ: 「3年前の購入価格、大きい家具は覚えてるけど小物は覚えてない」
> 🔄 トモヤ: 「sumitsugiで引き継いだ家具だから、新品価格がそもそも分からない」

→ **解決策:** カテゴリ選択（必須）でデフォルト新品価格を自動セット。ブランド名や手動入力（任意）で上書き可能。

### ブランド表示とバッジ

> 🎨 レイ: 「私の家具がIKEAと同じ扱いをされるのが嫌。ブランド名があれば価格が正当化される」
> 🧳 ソウタ: 「ブランド名が入ってるなら自分で検索して確認できる。自己申告の『ヴィンテージ』バッジだけでは信用できない」

→ **MVP:** 家具ごとにブランド名テキスト表示。バッジ（デザイナーズ/ヴィンテージ）はPhase 2（ブランドDB照合で信憑性を担保してから）。

### 写真タグ機能のアイデア（未決定・インスピレーション）

ZOZOのWEARのように部屋写真に家具タグを付けるアイデアが出た。正式決定ではないが、技術ミーティングで工数を確認:

- **Level 1:** 家具↔写真のインデックス紐づけ → 0.5〜1日
- **Level 2:** 写真上ピンUI（タップでポップアップ）→ 3〜5日（出品フォームと同時実装の場合）
- **Level 3:** WEARフルスペック → 2〜3週間（MVP不要）

**CTO推奨:** データモデルにpin座標フィールドを設計段階で含めておく（0コスト）。UI実装は出品フォーム実装時に判断。

---

## 決定事項

### 1. 値付け目安レンジの表示（MVP）

使用年数 × 新品合計価格から目安レンジを自動表示。

**減価テーブル:**

| 使用年数 | 目安レンジ（新品合計比） |
| -------- | ------------------------ |
| 1年以内  | 35〜50%                  |
| 1〜3年   | 25〜40%                  |
| 3〜5年   | 15〜30%                  |
| 5年以上  | 10〜20%                  |

**表示文言:** 「同じようなセットの出品者は、このくらいの範囲で設定しています（参考値）」
出品者はレンジ外の価格も自由に設定可能。

### 2. 新品価格入力の負荷軽減（MVP）

カテゴリベースのデフォルト推定 + 任意の上書き。

**カテゴリ別デフォルト新品価格:**

| カテゴリ           | デフォルト新品価格 |
| ------------------ | ------------------ |
| ソファ             | ¥50,000            |
| ダイニングテーブル | ¥30,000            |
| ベッドフレーム     | ¥40,000            |
| デスク             | ¥25,000            |
| 収納棚             | ¥15,000            |
| チェア             | ¥10,000            |
| 照明               | ¥8,000             |
| ラグ               | ¥10,000            |
| その他             | ¥5,000             |

### 3. 次の住人向け比較表示（MVP）

- 物件詳細に「新品で揃えた場合: 約○万円」を表示
- 割引率の表示（「新品の○%の価格で引き継ぎ」）

### 4. ブランド表示（MVP）/ バッジ（Phase 2）

- MVP: 家具ごとにブランド名入力（任意・自由テキスト）→ 物件詳細で表示
- Phase 2: デザイナーズ/ヴィンテージバッジ（ブランドDBとの照合）

### 5. 写真タグ（アイデアメモ・未決定）

- データモデルにpin座標フィールドを設計段階で含める（0コスト）
- UI実装の判断は出品フォーム実装時
