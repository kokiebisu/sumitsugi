## 背景

## 議論

👤 **CPO:** B2B連携の議題です。佐藤さん、tsumugiから承認依頼が来たらどう感じますか？

📋 **佐藤さん:** 「正直に言うと、**知らないサービスから突然連絡が来ても対応しません**。でも、**入居者から『退去にあたって残置物を残したい』って相談が来る**なら、それは通常業務の範囲。PDF（F-611）が分かりやすければ、大家に転送するだけ。**手間は7分くらい**なら許容範囲」

🏘️ **高橋さん:** 「佐藤さんの言う通り、**前の住人経由のアプローチは賢い**ですね。うちは小規模だからこういう差別化に前向きだけど、佐藤さんの会社みたいに500戸管理してたら、新しいことやる余裕ないでしょう。**PDFの品質が全て**だと思います。読むだけで判断できるクオリティじゃないと、問い合わせの電話が来て余計な仕事が増える」

🏢 **田中オーナー:** 「管理会社からPDFが転送されてきて、**書面で内容が分かる**なら検討はします。でも口頭で『新しいサービスがあって...』って言われても、『は？何それ』ってなる。**F-612の同意書テンプレート**は必須。手書きサインで正式承認できる形式なら安心」

📊 **中村オーナー:** 「田中さんとは違って、僕はデータで判断したい。**空室期間が何日短縮されるか**、そのデータがあれば即OKだけど、MVPの段階ではデータないでしょ？だから最初は**『空室短縮の可能性があります』という説明+実績ゼロでもロジカルに説明されたPDF**で十分。データは後から付いてくる」

🤝 **鈴木エージェント:** 「仲介としては、お客さんが契約したいって言えば普通に手続きします。**F-616の仲介向け物件シートは今すぐは要らない**。管理会社経由で情報もらえればいい。将来的にtsumugi物件が増えてきたら、うちからも紹介するかもしれないけど」

📱 **山田エージェント:** 「鈴木さんは受け身だけど、**私はtsumugiを営業ツールにしたい**。お客さんに『この物件、前の住人の家具付きで入居できますよ』って提案できるの、他の仲介にはない武器になる。でもMVPでは管理会社経由で十分。**F-616はPost-MVPで全然いい**」

📋 **佐藤さん:** 「山田さんみたいに積極的な人はいいけど、うちのスタッフは**FAQ（F-615）がないと質問に答えられない**。入居者から『tsumugiって何？』って聞かれた時に、『このページ見てください』で済むようにしてほしい。**FAQ静的ページはMVP必須**」

## 決定事項

| 機能                         | 決定     | 根拠                                                                     |
| ---------------------------- | -------- | ------------------------------------------------------------------------ |
| **F-611 残置物相談資料PDF**  | MVP必須  | 前の住人経由が現実的（佐藤さん）。品質が全て（高橋さん）。自己完結型必須 |
| **F-612 残置物同意書**       | MVP必須  | 手書きサインで正式承認（田中オーナー「書面なら安心」）                   |
| **F-615 管理会社FAQ**        | MVP必須  | スタッフが質問に答えられるように（佐藤さん）                             |
| **F-601 紹介フィー**         | Post-MVP | 実績なし段階でフィー不要。提携管理会社増加後                             |
| **F-613〜F-614**             | Post-MVP | 最初は人力対応                                                           |
| **F-616 仲介向け物件シート** | Post-MVP | 管理会社経由で伝達（鈴木・山田合意）                                     |
| **F-602〜F-607**             | Phase B+ | テック自動化は物件数20件以上から                                         |
