## 議論

👤 **CPO:** 次は出品する側、前の住人の体験です。ユキさん、物件を登録するとしたらどんな体験がいいですか？

🏠 **ユキ:** 「登録って正直ハードルが高いんですよね。**何を書けばいいか分からない**。写真は何枚必要？家具リストはどこまで書く？でもやると決めたからには丁寧にやりたい。プレビュー機能（F-103）は絶対欲しい。**公開前にどう見えるか確認したい**」

⏰ **ケンジ:** 「ユキさん、丁寧にやりたい気持ちは分かるけど、**俺は3分で出品したい**んだよね。来月末までに退去しないといけないのに、フォームが20項目もあったら途中で閉じちゃう。**写真3枚と家具リストと退去日、それだけでいいでしょ？** コンセプトとか暮らしの説明は後から追加でいい」

🎨 **レイ:** 「ケンジさん、3分って...。私は逆で、**もっと表現の幅が欲しい**。部屋は作品だから、写真の順番、説明文のトーン、家具一つ一つの物語。出品画面が素っ気ないと、**作品を安売りしてる感じ**がする。ただ、ケンジさんの言う『最低限で出品できる』のは大事。**必須と任意を分ける**のが落としどころじゃない？」

🔄 **トモヤ:** 「レイさんのその落としどころ、僕も賛成です。実際に前に引き継いだ時、**出品ページの情報量が少なくて困った**経験がある。家具のサイズが書いてなくて、届いてみたら思ったより大きかった。だから出品する側としては、**家具の寸法は必須にしてほしい**。でもケンジさんみたいに急いでる人のために、寸法は『あとで追加』でもいいかも。ただし**内見前までには入力を促す**仕組みがあるといい」

⏰ **ケンジ:** 「トモヤさん、寸法を必須にされると地獄なんだけど...。メジャーで測る時間もないし。**写真見れば分かるでしょ？** あ、でも『あとで追加を促す』のはいいかも。時間ができたらやるし、時間なかったら内見で実物見てもらえばいい」

🏠 **ユキ:** 「ケンジさんの気持ちも分かるし、トモヤさんの経験も大事。**ステータス管理（F-104）の下書き/公開の切り替え**は絶対必要ですね。最初は下書きで情報を少しずつ追加して、準備ができたら公開。ケンジさんは最低限で即公開、私やレイは下書きでじっくり。**両方に対応できる**」

---

## 決定事項

| 機能                               | 決定     | 根拠                                                                  |
| ---------------------------------- | -------- | --------------------------------------------------------------------- |
| **F-101 物件新規登録**             | MVP必須  | 必須/任意フィールド分離で丁寧派（ユキ・レイ）と急ぎ派（ケンジ）の両立 |
| **F-102 物件編集**                 | MVP必須  | 後から情報追加できる前提（ケンジ「最初は最低限→後から追加」）         |
| **F-103 物件プレビュー**           | 中優先度 | 公開前の確認は丁寧派に必須（ユキ）                                    |
| **F-104 ステータス管理**           | MVP必須  | 下書き/公開で丁寧派と急ぎ派を両立（ユキ提案）                         |
| **F-105 物件一覧（前の住人向け）** | MVP必須  | 自分の出品状況を把握するために必要                                    |
