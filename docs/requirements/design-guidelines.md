## デザイン原則

- Airbnb風のクリーンでモダンなUI
- ユーザー体験を最優先
- 視覚的な一貫性
- 写真を大きく使い、空間の魅力を伝える

## カラーパレット

| 用途             | 色           | コード  |
| ---------------- | ------------ | ------- |
| アクセントカラー | コーラル     | #FF5A5F |
| 背景色           | ホワイト     | #FFFFFF |
| テキスト（主）   | ダークグレー | #484848 |
| テキスト（副）   | グレー       | #767676 |

## 用語ガイドライン

UI表示において統一する用語:

| 内部用語     | UI表示   |
| ------------ | -------- |
| seller       | 前の住人 |
| buyer        | 次の住人 |
| yearsSelling | 活動歴   |

※データ構造のフィールド名（`seller`, `isSeller`, `yearsSelling`）は内部用語として使用し、UI表示では「前の住人」「次の住人」を使用する

## スペーシング

- アメニティアイコン（pill layout）：`gap-1.5`（6px）
- おすすめスポットタグ：視覚的に囲む（`border border-coral/20`）

## 大家承認バッジ

物件の信頼性を可視化し、次の住人に適切な期待値を伝えるバッジシステム:

**バッジ表示（物件カード）**:

- `approved` → 緑のチェックマーク「✓ 承認済」
- `conditional` → 黄色のマーク「条件付き承認」
- `pending` → 表示なし or グレーの「要確認」
- `rejected` → 表示しない（出品自体を非公開にすべき）

**バナー表示（物件詳細ページ上部）**:

承認済みの場合（緑色バナー `bg-green-50 border-green-200`）:

```
┌─────────────────────────────────────────────┐
│ ✓ 大家承認済み                               │
│ 入居までスムーズに進む可能性が高いです       │
└─────────────────────────────────────────────┘
```

条件付き承認の場合（青色バナー `bg-blue-50 border-blue-200`）:

```
┌─────────────────────────────────────────────┐
│ ℹ️ 大家の事前了承済み                         │
│ 家具リスト確定後に正式承認となります         │
└─────────────────────────────────────────────┘
```

未承認の場合（黄色バナー `bg-yellow-50 border-yellow-200`、`moveOutDate`と`managementConsultedAt`で分岐）:

**退去日未定（パターンC）の場合:**

```
┌─────────────────────────────────────────────┐
│ ℹ️ 退去時期は未定です                         │
│ 前の住人が退去を決定した後に                 │
│ 大家への確認手続きが始まります。             │
└─────────────────────────────────────────────┘
```

**退去日確定・管理会社未相談の場合:**

```
┌─────────────────────────────────────────────┐
│ ℹ️ 大家承認は未取得です                       │
│ 退去予定：○月○日                             │
│ 大家への確認手続きはこれからです。           │
└─────────────────────────────────────────────┘
```

**退去日確定・管理会社相談済み（返事待ち）の場合:**

```
┌─────────────────────────────────────────────┐
│ ℹ️ 大家への確認中です                         │
│ 退去予定：○月○日                             │
│ 管理会社経由で大家に確認中です。             │
└─────────────────────────────────────────────┘
```

**表示位置**:

- 物件詳細ページ: 画像ギャラリーの下、問い合わせボタンの近く
- 物件カード: タイトル付近に小さなバッジとして表示
