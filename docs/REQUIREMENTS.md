## 1. プロジェクト概要

### 1.1 プロジェクト名
**tsumugi（つむぎ）**

### 1.2 コンセプト
クリエイターの暮らしを引き継ぐプラットフォーム

### 1.3 サービス概要
単なる物件のサブリースではなく、**家具・インテリア・ライフスタイルそのもの**を引き継ぐサービス。クリエイターが自らの暮らしを次のクリエイターへ繋ぐことで、空間の価値を最大化する。

---

## 2. 目的と背景

### 2.1 課題
- 引越し時の家具・インテリアの処分問題
- クリエイターにとっての理想的な空間探しの難しさ
- 短期〜中期の住まい探しの選択肢の少なさ

### 2.2 解決策
- 家具・インテリア付きの物件をそのまま引き継げる仕組み
- クリエイターのライフスタイルを可視化し、マッチングを促進
- 1〜6ヶ月の短期〜中期契約に対応

### 2.3 目標
- クリエイター同士のコミュニティ形成
- 持続可能な暮らしの提案
- 空間の価値の最大化

## 4. ユーザー種別

### 4.1 ユーザーモデル（Airbnb風）
全ユーザーは入居希望者として登録し、ホスト登録で`isHost=true`に切り替わる統一モデル。

**User（基本属性）**:
- id: UUID形式
- email: メールアドレス
- name: 氏名
- phone: 電話番号（任意）
- avatarUrl: プロフィール画像URL（任意）
- createdAt: 作成日時
- authProvider: 認証プロバイダー（email/google/facebook/apple）
- emailVerified: メール確認済みフラグ
- isHost: ホストフラグ
- isAdmin: 管理者フラグ（任意）
- hostProfile: ホストプロフィール（isHost=trueの場合のみ）

### 4.2 クリエイター（ホスト）
物件を提供する側のユーザー。`isHost=true`のユーザー。

**HostProfile（ホストプロフィール）**:
- occupation: 職業
- bio: 自己紹介
- socialLinks: SNSリンク（Instagram, Twitter, YouTube, TikTok, Website）
- rating: 評価（1-5）
- reviewCount: レビュー数
- yearsHosting: 活動歴（年数）
- hostSince: ホスト登録日

### 4.3 入居者（ゲスト）
物件を探し、入居を希望するユーザー。`isHost=false`のユーザー。

### 4.4 管理者
プラットフォームを運営・管理するユーザー。`isAdmin=true`のユーザー。

**権限**:
- 物件の承認・却下
- 問い合わせの管理
- ホスト申請の管理


**重要：月額家賃・管理費は初期費用に含まれません**

## 11. 引き継ぎフロー

物件の引き継ぎは以下の7ステップで行われる:

1. **物件登録** - クリエイターが物件情報を登録
2. **公開** - 物件を一般公開
3. **問い合わせ** - 入居希望者からの問い合わせ受付
4. **内見調整** - 内見日程の調整
5. **内見実施** - 実際の物件見学
6. **契約** - 賃貸契約の締結、インテリア購入料の支払い
7. **引き継ぎ** - 物件・ライフスタイルの引き継ぎ完了
