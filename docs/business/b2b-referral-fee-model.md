## 1. エグゼクティブサマリー

管理会社への紹介フィーを「先行者利益モデル」として設計し、初期の物件在庫確保から安定期のデータ提供モデルへ段階的に移行する。

**基本方針:**

- 初期参入の管理会社に高い報酬を提供し、プラットフォームの物件在庫を確保
- 物件数の増加に伴いフィーを段階的に縮小し、データ提供による付加価値に転換
- 管理会社の離反を防ぐため、フィー廃止前にデータ提供の価値を十分に証明

**フィー原資:** プラットフォーム手数料（15%）からtsumugiが負担。次の住人・前の住人の受取額には影響しない。

## 2. フェーズ定義

### Phase A: 先行者優遇期（物件0〜20件）

| 項目                        | 内容                                                                                |
| --------------------------- | ----------------------------------------------------------------------------------- |
| **紹介フィー**              | **¥3,000/成約**                                                                     |
| **対象**                    | tsumugiプラットフォーム上の累計掲載物件数が20件に到達するまで                       |
| **開始条件**                | 提携管理会社が増加し、フィー支払いが合理的になった段階（座談会#14-6でPost-MVP決定） |
| **想定成約数**              | 月2〜3件                                                                            |
| **tsumugiの月額フィー支出** | ¥6,000〜¥9,000                                                                      |
| **管理会社の作業負担**      | 約30分/件（tsumugiの資料・テンプレート提供で削減）                                  |

**管理会社のメリット:**

- **高い紹介報酬**: ¥3,000/成約は管理会社にとって純利益
- **優先サポート**: tsumugiが提供するオーナー説明PDF、同意書テンプレート、残置物チェックリスト、日程案で作業負担を大幅削減
- **追加清掃費収入**: ¥8,000/件（家具クリーニングの実費カバー）が別途あり、フィーと合わせて**1件あたり¥11,000の収入**（作業30分、時給換算¥22,000相当）
- **空室期間の短縮**: 家具付き物件は即入居可能 → 空室ロスを最小化

**tsumugiのメリット:**

- **初期物件在庫の確保**: 管理会社の協力なしでは残置物引き継ぎが成立しないため、経済的インセンティブで協力を促進
- **ボトムアップ成長の加速**: 前の住人経由でPDFが届く「トロイの木馬戦略」に加え、フィーが管理会社の自発的な提携意向を後押し
- **成約データの蓄積**: Phase B以降のデータ提供モデルの基盤を構築

**収益インパクト（Phase A）:**

| 引越し費用 | tsumugi手数料(15%) | 紹介フィー | tsumugi手残り | 手残り率 |
| ---------- | ------------------ | ---------- | ------------- | -------- |
| ¥50,000    | ¥7,500             | -¥3,000    | ¥4,500        | 60.0%    |
| ¥100,000   | ¥15,000            | -¥3,000    | ¥12,000       | 80.0%    |
| ¥150,000   | ¥22,500            | -¥3,000    | ¥19,500       | 86.7%    |
| ¥200,000   | ¥30,000            | -¥3,000    | ¥27,000       | 90.0%    |

※ 平均引越し費用¥100,000の場合、Phase Aのフィー負担はtsumugi手数料の20%

### Phase B: 成長期（物件21〜50件）

| 項目                        | 内容                                  |
| --------------------------- | ------------------------------------- |
| **紹介フィー**              | **¥1,500/成約**（Phase Aから50%縮小） |
| **対象**                    | 累計掲載物件数21〜50件                |
| **想定成約数**              | 月5〜8件                              |
| **tsumugiの月額フィー支出** | ¥7,500〜¥12,000                       |
| **管理会社の作業負担**      | 約15分/件（一部テック自動化）         |

**移行条件（Phase A → B）:**

1. 累計掲載物件数が**20件**に到達
2. 提携管理会社が**3社以上**
3. 管理会社向けの基本的な自動化ツール（F-602: オーナー説明自動通知）が稼働

**Phase Bで追加提供する価値:**

- **テック自動化の開始**: 提携済み管理会社にはtsumugiから自動通知+PDF送付（前の住人の手間ゼロ）
- **API連携の検討**: 仲介会社向け物件リストAPI（F-606）の開発着手
- **簡易レポート**: 月次の成約実績レポートを管理会社に提供

**収益インパクト（Phase B）:**

| ¥50,000    | ¥7,500             | -¥1,500    | ¥6,000        | 80.0%    |
| ¥100,000   | ¥15,000            | -¥1,500    | ¥13,500       | 90.0%    |
| ¥150,000   | ¥22,500            | -¥1,500    | ¥21,000       | 93.3%    |

### Phase C: 安定期（物件50件超）

| 項目                   | 内容                       |
| ---------------------- | -------------------------- |
| **紹介フィー**         | **廃止（¥0）**             |
| **対象**               | 累計掲載物件数50件超       |
| **代替価値**           | データ提供モデルへ完全移行 |
| **管理会社の作業負担** | 約10分/件（ほぼ自動化）    |

**移行条件（Phase B → C）:**

1. 累計掲載物件数が**50件**に到達
2. 空室短縮データレポート（F-605）が稼働し、管理会社が**データの価値を実感している**
3. 提携管理会社の**月次リテンション率が90%以上**（フィーなしでも継続利用する見込み）
4. Phase B期間中に管理会社満足度アンケートを実施し、**データ提供だけでも継続利用したい**と回答した管理会社が70%以上

**Phase Cで提供するデータ:**

| データ種別             | 内容                                         | 管理会社のメリット             |
| ---------------------- | -------------------------------------------- | ------------------------------ |
| **空室短縮レポート**   | 「tsumugi経由で平均○日空室短縮」の実績データ | オーナーへの提案資料に活用     |
| **残置物トレンド**     | エリア別の残置物需要（人気家具、価格帯）     | 退去者への情報提供に活用       |
| **エリア別需要データ** | 引き継ぎ希望者の流入元・希望条件             | マーケティング・物件企画に活用 |
| **成約率分析**         | 物件条件別の成約率・所要期間                 | 物件価値向上の提案に活用       |
| **季節変動データ**     | 月別の引き継ぎ需要推移                       | 退去・入居時期の最適化に活用   |

**収益インパクト（Phase C）:**

| 引越し費用 | tsumugi手数料(15%) | 紹介フィー | tsumugi手残り | 手残り率 |
| ---------- | ------------------ | ---------- | ------------- | -------- |
| ¥50,000    | ¥7,500             | ¥0         | ¥7,500        | 100%     |
| ¥100,000   | ¥15,000            | ¥0         | ¥15,000       | 100%     |
| ¥150,000   | ¥22,500            | ¥0         | ¥22,500       | 100%     |

## 3. フェーズ移行サマリー

```
Phase A (¥3,000/成約)          Phase B (¥1,500/成約)         Phase C (フィー廃止)
   物件0-20件                     物件21-50件                   物件50件超
 ──────────────────────── → ──────────────────────── → ────────────────────────
 ・管理会社に高報酬            ・フィー50%縮小               ・データ提供モデル
 ・前の住人経由アプローチ      ・テック自動化開始            ・ほぼ完全自動化
 ・作業30分/件                 ・作業15分/件                 ・作業10分/件
 ・月額¥6k-9k支出              ・月額¥7.5k-12k支出           ・フィー支出¥0
```

**フェーズ移行の通知:**

- 移行の**3ヶ月前**に管理会社に事前通知
- 移行条件の達成状況を月次で共有
- 移行時に新フェーズの価値提供内容を説明するオンボーディングを実施

## 4. 契約テンプレート（管理会社との基本合意書骨子）

### 4.1 合意書の構成

```
管理会社向けB2B連携基本合意書

第1条（目的）
  本合意書は、tsumugi（以下「甲」）と管理会社（以下「乙」）の間における
  残置物引き継ぎサービスに関する連携条件を定めるものである。

第2条（連携内容）
  1. 甲は、乙が管理する物件において発生する残置物引き継ぎ案件について、
     以下のサポートを提供する。
     (a) 残置物引き継ぎ相談資料（PDF）の提供
     (b) 残置物同意書テンプレートの提供
     (c) 残置物チェックリストの提供
     (d) 引き継ぎ日程案の提供
  2. 乙は、上記資料に基づき通常の残置物対応業務の範囲内で対応する。

第3条（紹介フィー）
  1. 甲は、乙が管理する物件においてtsumugiを通じた引き継ぎが成約した場合、
     以下の紹介フィーを乙に支払う。
     - Phase A（累計掲載物件0-20件）: ¥3,000/成約
     - Phase B（累計掲載物件21-50件）: ¥1,500/成約
     - Phase C（累計掲載物件50件超）: フィー廃止、データ提供に移行
  2. フィーの支払いは、引き継ぎ完了後のエスクロー解放時にStripe Transferで
     乙の指定口座に送金する。
  3. フェーズの移行は、甲のプラットフォーム全体の累計掲載物件数に基づく。
     移行の3ヶ月前に乙に書面で通知する。

第4条（データ提供 - Phase C）
  1. Phase C移行後、甲は乙に以下のデータを月次で提供する。
     (a) 空室短縮実績レポート
     (b) エリア別残置物需要トレンド
     (c) 成約率・所要期間分析
  2. 提供データは統計処理済みの集計データであり、個人情報は含まない。

第5条（秘密保持）
  両者は、本合意に基づき知り得た相手方の営業秘密を第三者に開示しない。

第6条（有効期間）
  本合意書の有効期間は締結日から1年間とし、いずれかの当事者が期間満了の
  1ヶ月前までに書面で終了を通知しない限り、同条件で1年間自動更新される。

第7条（解除）
  1. いずれの当事者も、1ヶ月前の書面通知により本合意を解除できる。
  2. 合意解除時、未払いのフィーがある場合は解除後30日以内に精算する。

第8条（反社会的勢力の排除）
  両者は、自らが反社会的勢力でないことを表明し保証する。

第9条（準拠法・管轄）
  本合意書は日本法に準拠し、紛争が生じた場合は東京地方裁判所を
  第一審の専属管轄裁判所とする。
```

### 4.2 契約テンプレートの注意事項

- 上記は**骨子（叩き台）**であり、外部弁護士のレビューが必須
- CLOレビュー → 外部弁護士の最終確認 のフローで正式化
- 電子契約（DocuSign等）での締結はPhase B以降で検討
- Phase Aでは管理会社1社ごとの個別対応（テンプレートをカスタマイズ）

## 6. リスク分析

### 6.1 フィー廃止時の管理会社離反リスク

| リスク                                 | 発生確率 | 影響度 | 対策                                                                                        |
| -------------------------------------- | -------- | ------ | ------------------------------------------------------------------------------------------- |
| フィー廃止で管理会社が離脱             | **中**   | **高** | Phase B中にデータ提供の価値を十分に実証。移行前にアンケートで離脱リスクを定量評価           |
| データ提供の価値が不十分               | **中**   | **高** | Phase B後半で試験的にデータレポートを提供し、管理会社のフィードバックを反映してから正式移行 |
| 競合サービスが高フィーで管理会社を奪う | **低**   | **高** | 先行者優遇の契約条項（同エリアで1年間の排他条項の検討）+ データ提供の差別化                 |

**離反防止の具体策:**

1. **段階的移行**: ¥3,000 → ¥1,500 → ¥0の3段階で急激な変化を避ける
2. **データ価値の先行提供**: Phase B後半から無料でデータレポートを試験提供し、管理会社がデータの価値を実感してからフィーを廃止
3. **追加清掃費は継続**: フィー廃止後も追加清掃費¥8,000/件は管理会社の収入として継続。完全にゼロにはならない
4. **パートナーランク制度**: 早期参入した管理会社には「プレミアムパートナー」として優先的なデータ提供やプラットフォーム上での優先表示を付与

### 6.2 フィー水準の適切性リスク

| リスク                                         | 発生確率 | 影響度 | 対策                                                                                                   |
| ---------------------------------------------- | -------- | ------ | ------------------------------------------------------------------------------------------------------ |
| ¥3,000では管理会社のインセンティブとして不十分 | **低**   | **中** | 管理会社の実作業は30分程度。¥3,000+追加清掃費¥8,000で¥11,000/件は十分な水準。初期ヒアリングで検証      |
| tsumugiの利益率が過度に圧迫される              | **低**   | **中** | 平均引越し費用¥100,000の場合、フィー¥3,000はtsumugi手数料¥15,000の20%。月3件でも¥9,000の支出で許容範囲 |
| フィー金額の変更が管理会社との信頼を損なう     | **中**   | **中** | 契約書にフェーズ移行条件と金額を明記。サプライズを防ぐ                                                 |

### 6.3 オペレーショナルリスク

| リスク                         | 発生確率 | 影響度 | 対策                                                                      |
| ------------------------------ | -------- | ------ | ------------------------------------------------------------------------- |
| フィー送金のミス・遅延         | **低**   | **高** | Stripe Transfer自動送金。エスクロー解放と同時にフィーも自動送金される設計 |
| フェーズ移行の判定ミス         | **低**   | **中** | 物件数カウントの自動化。ダッシュボードで常時モニタリング                  |
| 管理会社のStripe Connect未登録 | **中**   | **中** | Phase Aでは銀行振込も併用可。Phase Bまでに全社Stripe Connect登録を目指す  |

## 7. 送金フロー（技術仕様）

### 7.1 フィーの送金タイミング

```
引き継ぎ完了
  ↓
双方が「完了」ボタン押下
  ↓
24-48時間の異議申し立て期間
  ↓
エスクロー解放（MVP: 管理者手動 / Post-MVP: 自動）
  ↓ 同時に以下を実行
  ├── 前の住人へ送金（Destination）
  ├── 大家へ協力金送金（Stripe Transfer）
  ├── 管理会社へ追加清掃費送金（Stripe Transfer）
  ├── 管理会社へ紹介フィー送金（Stripe Transfer）← ここ

```

## 9. 座談会での決定事項との整合性

[座談会#14-6（2026-02-09）](../requirements/meetings/2026-02-09-product-meeting-14-6-b2b.md)での決定:

> **F-601 紹介フィー: Post-MVP** — 実績なし段階でフィー不要。提携管理会社増加後。

本設計書はこの決定に準拠し、以下の前提で設計している:

1. **MVPローンチ時にはフィー支払いを開始しない** — 最初の数件は管理会社との関係構築期間
2. **フィー開始はPost-MVP** — 提携管理会社が増加し、フィー支払いが合理的になった段階で開始
3. **Phase Aの開始条件** — 最低2-3件の成約実績があり、管理会社がtsumugiの価値を理解した後
