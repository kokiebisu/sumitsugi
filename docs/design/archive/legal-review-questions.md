## 1. 資金決済法（Payment Services Act）関連

### Q1-1: 資金移動業ライセンスの要否

**質問:**
tsumugiは次のモデルで決済を行います。Stripe Connectを使用する場合、資金移動業の登録は必要でしょうか？

**tsumugiの決済フロー:**

```
次の住人
  → Stripe（決済代行業者）に支払い
  → Stripeがエスクロー保管
  → tsumugiがStripe APIで分配指示
  → Stripe Connect Accounts（前の住人・大家・管理会社）に自動送金
```

**確認ポイント:**

- tsumugiの銀行口座を経由せず、Stripeのシステム内で完結する
- tsumugiは「いつ分配するか」の指示のみ
- 資金の物理的な保管はStripeが行う

### Q1-2: エスクロー期間の制限

**質問:**
支払いから分配まで、最大で5-7日程度の期間（エスクロー期間）が発生します。これは資金決済法上問題ないでしょうか？

**エスクロー期間:**

- デポジット支払い → 引き継ぎまで: 最大1-2週間
- 残額支払い → 引き継ぎまで: 2-3日
- 引き継ぎ完了 → 分配まで: 24-48時間

### Q1-3: 供託金・履行保証金の必要性

**質問:**
Stripe Connectを利用する場合でも、tsumugiが供託金や履行保証金を預託する必要はありますか？

## 2. 不動産関連法規

### Q2-1: 宅建業法の適用可否

**質問:**
tsumugiは「暮らしの引き継ぎ」を仲介しますが、賃貸物件の仲介ではありません。宅建業法の適用対象となるでしょうか？

**tsumugiのビジネスモデル:**

- 家具・インテリアの引き継ぎを仲介
- 賃貸契約は大家・管理会社と入居者が直接締結
- tsumugiは賃貸契約の仲介を行わない
- 引越し費用（家具代金含む）の決済のみ代行

### Q2-2: 仲介手数料規制

**質問:**
tsumugiが徴収するプラットフォーム手数料（引越し費用の12%）は、宅建業法の仲介手数料規制（賃料の1ヶ月分以内）の対象となりますか？

**手数料の性質:**

- 賃貸契約の仲介手数料ではない
- 家具引き継ぎ・決済代行のプラットフォーム利用料
- 類似サービス: メルカリ（10%）、Airbnb（3-15%）

### Q2-3: 残置物同意書の法的効力

**質問:**
tsumugiが生成する「残置物同意書」（家具リスト・写真・双方の承認）は、法的にどの程度の効力を持ちますか？

**想定される用途:**

- 管理会社への提出（家具を処分しないよう通知）
- トラブル時の証拠（「約束と違う」「家具が壊れていた」）
- 電子署名の必要性

## 3. プラットフォーム責任・消費者保護

### Q3-1: プラットフォーム事業者の責任範囲

**質問:**
以下のトラブルが発生した場合、tsumugiはどこまで法的責任を負いますか？

**想定トラブル:**

1. 前の住人が「約束した家具を持ち出した」
2. 次の住人が「家具が壊れていた」とクレーム
3. 支払い後に前の住人が連絡を絶った
4. 大家が「残置物同意書を受け取っていない」と主張

**tsumugiの対応:**

- 残置物同意書で証拠を保全
- エスクロー機能で一定期間保管
- 紛争時は運営が仲裁

### Q3-2: 特定商取引法の適用

**質問:**
tsumugiのサービスは特定商取引法（特商法）の規制対象となりますか？

**確認ポイント:**

- 通信販売に該当するか
- 事業者情報の表示義務
- 返品・クーリングオフ規定

### Q3-3: 個人情報保護法

**質問:**
以下の情報を保管する際の法的義務について教えてください。

**保管する個人情報:**

- 銀行口座情報（前の住人・大家）
- 電話番号・住所
- 取引履歴
- Stripe Connect Account ID

### Q4-2: キャンセルポリシーの有効性

**質問:**
以下のキャンセルポリシーは法的に有効でしょうか？

**ポリシー案:**

```
デポジット支払い後のキャンセル:
- 次の住人都合: デポジット没収（前の住人への補償）
- 前の住人都合: デポジット全額返金
- 双方合意: デポジット全額返金

全額支払い後、引き継ぎ前:
- 緊急事態のみ返金（手数料を除く）

引き継ぎ完了後:
- 原則返金なし
- 24-48時間の異議申し立て期間あり
```
