# User Interview Documentation

> Purpose: Validate product assumptions, understand user needs, and gather insights for sumitsugi MVP

## Interview Guidelines

### Preparation (5 min before)

1. Review interviewee background
2. Prepare recording equipment (with permission)
3. Have interview script ready
4. Prepare note-taking template

### Interview Structure (15 min)

1. **Introduction (2 min)**
   - Thank them for their time
   - Explain sumitsugi concept briefly
   - Get consent for recording/notes

2. **Background Questions (3 min)**
   - Current living situation
   - Moving experience/frequency
   - Previous experience with furniture/leftover items when moving

3. **Problem Validation (5 min)**
   - Challenges faced when moving out
   - What happens to furniture/items they leave behind
   - Costs associated with disposal/moving
   - Pain points in current solutions

4. **Solution Feedback (4 min)**
   - Show sumitsugi concept
   - First impressions
   - Perceived value
   - Pricing sensitivity

5. **Wrap-up (1 min)**
   - Any additional thoughts
   - Thank them
   - Follow-up contact if needed

### Post-Interview (within 24 hours)

1. Write up detailed notes using template
2. Extract key insights and quotes
3. Update product assumptions document
4. File interview notes with anonymized ID

## Interview Notes Template

Use the template file: `TEMPLATE-interview-notes.md`

## Privacy & Ethics

- Always get explicit consent for recording
- Anonymize personal information in documentation
- Use interview IDs (e.g., INT-001, INT-002)
- Store contact info separately from interview notes
- Respect right to withdraw participation
