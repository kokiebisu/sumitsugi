# SUUMO管理会社ページ構造調査

> 調査日: 2026-02-09
> 目的: 管理会社パートナーシップ開拓のためのリサーチ（TSU-48関連）

## 概要

SUUMOには管理会社・不動産会社を探すためのページが3系統存在する。それぞれ目的とターゲットが異なり、tsumugiの管理会社パートナーシップ開拓において異なる価値を持つ。

---

## 1. SUUMO管理会社関連ページの3系統

### 1-1. 「貸す」セクション（大家向け・管理会社検索）

**最重要ページ**: tsumugiにとって最も有用な系統

| 項目           | 内容                                                    |
| -------------- | ------------------------------------------------------- |
| URL            | `https://suumo.jp/kasu/tokyo/sc_setagaya/smkz1n06.html` |
| 目的           | 物件オーナーが賃貸管理を委託する管理会社を探す          |
| ターゲット     | 大家・物件オーナー                                      |
| 世田谷区登録数 | **27社**                                                |

**URLパラメータ構造:**

```
https://suumo.jp/kasu/{都道府県}/{エリアコード}/smkz1n06.html
  ?ar=030   # 地域コード（030=関東）
  &bs=041   # 業種コード（041=賃貸管理）
  &ta=13    # 都道府県（13=東京）
  &sc=13112 # 市区町村コード（13112=世田谷区）
  &po=1     # 並び替え設定
  &pj=1     # ページ番号
```

**表示項目（各社）:**

- 会社名
- 所在地・最寄駅
- 電話番号
- 企業概要（短い説明文）
- 得意分野アイコン（4分類、後述）
- 取扱エリア

**得意分野の4分類:**

| アイコン | 分類                 | 説明                           |
| -------- | -------------------- | ------------------------------ |
| 1        | ひと部屋管理         | 区分所有マンション等の1室管理  |
| 2        | 一棟借り上げ管理     | サブリース・一棟丸ごと管理     |
| 3        | 転勤者留守宅管理     | 転勤者の自宅を一時的に賃貸管理 |
| 4        | 土地・建物の有効活用 | 遊休不動産の活用提案           |

**並び替え条件:**

- 店舗名順（昇順/降順）
- 店舗所在地順

**表示件数選択:** 30件 / 50件 / 100件

**一括問い合わせ機能:** チェックボックスで複数社を選択し、まとめて問い合わせ可能

### 1-2. 「賃貸」セクション（入居者向け・不動産会社検索）

| 項目           | 内容                                                 |
| -------------- | ---------------------------------------------------- |
| URL            | `https://suumo.jp/chintai/kaisha/tokyo/sc_setagaya/` |
| 目的           | 賃貸物件を探す人が不動産会社（仲介会社）を探す       |
| ターゲット     | 賃貸入居希望者                                       |
| 世田谷区登録数 | **206社**（全7ページ）                               |

**URLパラメータ構造:**

```
https://suumo.jp/chintai/kaisha/{都道府県}/sc_{区市名}/
  ?page=2   # ページ番号
```

**表示項目（各社）:**

- 会社名・店舗名
- 取扱物件数（例: 5491件）
- 住所・最寄駅（バス/徒歩時間）
- 営業時間・定休日
- 電話番号
- 得意エリア（複数表示）
- スタッフのメッセージ（複数名分）
- 特徴タグ（後述）

**特徴タグ一覧:**

- 駅徒歩3分以内
- 女性スタッフ
- 賃貸保証対応
- 外国語対応
- 10年以上営業
- 多店舗展開
- 保証人不要相談可
- 19時以降営業
- 年中無休

**並び替え条件:**

- 不動産会社名（昇順/降順）
- 物件数が多い/少ない順

**会社詳細ページURL構造:**

```
https://suumo.jp/chintai/kaisha/kc_030_{会社ID}/
  例: kc_030_116649002（(株)IEYA）
```

**詳細ページの表示項目:**

- 会社名・店舗写真
- 営業時間・定休日
- 電話番号
- 所在地・アクセス情報
- 免許番号
- スタッフ情報（名前、年代、業界経験年数、資格）
- スタッフコメント
- 取扱エリア
- 掲載中物件の一覧
- 特徴アイコン（駅送迎、駐車場、女性スタッフ、売買取扱等）

### 1-3. 「不動産会社」セクション（総合・全業種）

https://suumo.jp/kaisha/{都道府県}/city/              # 市区町村から探す

**表示項目（各社）:**

- 社名・店舗名
- 物件数
- 住所・最寄駅
- 営業時間・定休日

## 5. データ取得（スクレイピング）の実現可能性

### robots.txt の状況

| 項目                         | 内容                                         |
| ---------------------------- | -------------------------------------------- |
| `/kasu/`パスの制限           | **Disallow指定なし**（クロール可能）         |
| `/chintai/kaisha/`パスの制限 | **Disallow指定なし**（クロール可能）         |
| `/kaisha/`パスの制限         | **Disallow指定なし**（クロール可能）         |
| bingbot向けCrawl-delay       | 30秒                                         |
| 主な制限対象                 | `/edit/`, `/mb/`, `/sp/`（編集・モバイル系） |

### 利用規約の制限

SUUMO利用規約（リクルート社）の関連条項:

| 条項                   | 内容                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 第2条第1項             | 著作権法で定める私的利用の範囲を超える使用は事前承諾が必要   |
| 第3条第1項(7)          | **商業目的での利用は禁止**（リクルート社が認める場合を除く） |
| 第3条                  | サイト運営を妨げる行為の禁止                                 |
| スクレイピング明示規定 | なし（ただし上記条項でカバーされうる）                       |

### 判断

| 方法                  | 実現可能性     | リスク                                   |
| --------------------- | -------------- | ---------------------------------------- |
| 手動で会社情報を収集  | 高             | 低（私的利用の範囲内）                   |
| 自動スクレイピング    | 技術的には可能 | **高**（商用利用禁止条項に抵触の可能性） |
| SUUMO公式API          | 不明           | 低（公式APIの存在未確認）                |
| SUUMO B2Bサービス経由 | 要確認         | 低（正規ルート）                         |

### 推奨アプローチ

1. **Phase 1（即時）**: 「貸す」セクションの27社を**手動でリスト化**し、パートナー候補を選定
2. **Phase 1（並行）**: 各社の公式Webサイトを個別に確認し、管理戸数・サービス内容を補完
3. **Phase 2（将来）**: SUUMO B2Bサービス（`business.suumo.jp`）への問い合わせを検討

## 6. tsumugiパートナー開拓への活用方法

### アプローチ優先順位

SUUMOの情報を基に、以下の順序でアプローチを推奨:

**Tier 1: 中小管理会社（5社）** -- 意思決定が早く、新規サービスに柔軟

- iedoki、diff、TRYestate管理部、グランドコンフォート、Layout
- 世田谷区に密着しており、大家との関係が近い
- tsumugiの「残置物引き継ぎ」コンセプトに興味を持ちやすい

**Tier 2: リロケーション専門（1社）** -- tsumugiとの親和性が極めて高い

- リロケーション・ジャパン
- 転勤者の留守宅管理 → 退去時の家具処分問題をtsumugiで解決できる
- Win-Winの提案がしやすい

**Tier 3: 大手管理会社（4社）** -- ブランド力があるが意思決定が遅い

- 小田急不動産、住友不動産ステップ、大京穴吹不動産、三井のリハウス
- 実績ができてから（Phase B以降）のアプローチが現実的

### SUUMOから得られる情報の活用

| 情報              | 活用方法                                   |
| ----------------- | ------------------------------------------ |
| 会社名・連絡先    | パートナー候補リスト（TSU-48）の基礎データ |
| 得意分野（4分類） | アプローチ時の会話の切り口                 |
| 取扱エリア        | 世田谷区内の重点エリアとの一致確認         |
| SUUMO掲載の有無   | 会社の規模感・信頼性の指標                 |
