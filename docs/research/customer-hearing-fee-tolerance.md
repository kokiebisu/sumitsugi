# カスタマーヒアリング質問集：手数料許容度・価格感

> **作成日**: 2026-02-14
> **対象**: 前の住人候補・次の住人候補
> **目的**: sumitsugiの料金体系（引越し費用、プラットフォーム手数料15%、申込金¥20,000）に対するユーザーの受容度と価格感を検証

---

## ヒアリング実施ガイド

### 対象者の選定

- **前の住人候補**: 1〜3ヶ月以内に引越し予定がある一人暮らしの方（20〜40代）
- **次の住人候補**: 現在部屋探し中の方、または近々引越しを検討している方

### 実施方法

- 1対1のオンライン/対面インタビュー（30〜45分）
- リラックスした雰囲気で、正直な意見を引き出す
- 数字を聞く際は「いくらまでなら払える？」ではなく「これくらいだったら？」と具体的な金額を提示して反応を見る

---

## 質問1: 引越し費用の価格感（次の住人向け）

### 背景説明

「家具付きの部屋に引き継げるサービスがあるとします。大型家具（冷蔵庫、洗濯機、ベッド、テーブル、収納棚など）がそのまま使えて、引越しの荷物を大幅に減らせます。この場合、引越し費用としていくらまでなら払えますか？」

### 質問

1. **¥50,000だったら？**
   - [ ] 高いと感じる
   - [ ] 妥当だと感じる
   - [ ] 安いと感じる
   - [ ] その理由は？

2. **¥100,000だったら？**
   - [ ] 高いと感じる
   - [ ] 妥当だと感じる
   - [ ] 安いと感じる
   - [ ] その理由は？

3. **¥150,000だったら？**
   - [ ] 高いと感じる
   - [ ] 妥当だと感じる
   - [ ] 安いと感じる
   - [ ] その理由は？

### 深掘り質問

- 「自分で家具を揃える場合と比べてどうですか？」
- 「初期費用（敷金・礼金・仲介手数料）と比べて高いと感じますか？」
- 「この金額に含まれるもの（家具、プロ清掃、引き継ぎサポート）を考えると納得できますか？」

### 検証ポイント

- ¥50,000〜¥150,000のレンジで、どこから「高い」と感じるか
- 家具購入費（新品で¥150,000〜¥300,000相当）と比較した時の受容度
- 初期費用削減（家具代不要）のメリットが価格に見合うか

## 質問3: 申込金¥20,000の受容度（次の住人向け）

### 背景説明

「内見後、気に入った物件に申し込む際、¥20,000の申込金を支払います。これは前の住人の機会損失を補償するもので、審査が通れば引越し費用の一部になりますが、あなたの都合でキャンセルした場合は返金されません。この仕組みについてどう思いますか？」

### 質問

1. **¥20,000という金額は高いと感じますか？**
   - [ ] 高すぎる
   - [ ] やや高い
   - [ ] 妥当
   - [ ] 問題ない
   - [ ] その理由は？

2. **「キャンセル時に返金されない」というルールは厳しいと感じますか？**
   - [ ] 厳しすぎる
   - [ ] やや厳しい
   - [ ] 妥当
   - [ ] 問題ない
   - [ ] 理由は？

3. **申込金がない場合、気軽に申し込んでキャンセルする人が増えると思いますか？**
   - [ ] はい
   - [ ] いいえ
   - [ ] わからない

### 深掘り質問

- 「¥10,000だったら抵抗感は減りますか？」
- 「審査落ちの場合は返金される、というルールは安心できますか？」
- 「前の住人が他の人を断っているリスク、という説明は納得できますか？」

### 検証ポイント

- ¥20,000が「本気度フィルター」として機能する金額か
- 非返金ルールが厳しすぎないか（離脱要因にならないか）
- 前の住人の機会損失補償、という理屈が理解されるか

## 質問4: 家具価格vs新品購入の比較（次の住人向け）

### 背景説明

「新品で家具を揃えると、冷蔵庫¥60,000、洗濯機¥50,000、ベッド¥40,000、テーブル¥20,000、収納棚¥30,000...合計で¥200,000以上かかります。これが引越し費用¥100,000で全部引き継げるとしたら？」

### 質問

1. **¥100,000で家具一式が手に入るなら「安い」と感じますか？**
   - [ ] はい
   - [ ] いいえ
   - [ ] どちらでもない
   - [ ] 理由は？

2. **「中古品」であることに抵抗はありますか？**
   - [ ] かなりある
   - [ ] 少しある
   - [ ] あまりない
   - [ ] 全くない
   - [ ] 具体的には？

3. **「前の住人の暮らしを引き継ぐ」というストーリーに価値を感じますか？**
   - [ ] 強く感じる
   - [ ] 少し感じる
   - [ ] あまり感じない
   - [ ] 全く感じない

### 深掘り質問

- 「新品と中古の価格差がどれくらいあれば納得できますか？（新品の30%? 50%?）」
- 「プロ清掃済み、という保証があれば抵抗感は減りますか？」
- 「家具の状態写真や、前の住人のレビューがあれば安心できますか？」

### 検証ポイント

- 新品¥200,000 vs 引越し費用¥100,000の価値比較
- 中古品への抵抗感（特に清潔性、品質）
- 「暮らしを引き継ぐ」という体験価値の訴求力

## 質問5: 「値下げ交渉」への期待（前の住人・次の住人双方）

### 背景説明（前の住人）

「あなたが¥100,000で出品した物件に対し、次の住人候補から『¥80,000にしてもらえませんか？』と値下げ交渉が来たらどう対応しますか？」

### 背景説明（次の住人）

「気に入った物件が¥100,000で出ていますが、予算的に少し厳しい。¥80,000に値下げ交渉することは可能だと思いますか？また、そういうやりとりをしたいですか？」

### 質問

#### 前の住人向け

1. **値下げ交渉に応じますか？**
   - [ ] 応じる（いくらまで？）
   - [ ] 応じない（理由は？）
   - [ ] 状況による（どんな状況なら？）

2. **プラットフォームが「値下げ交渉禁止」というルールを設けたらどう思いますか？**
   - [ ] 賛成（出品者が守られる）
   - [ ] 反対（柔軟性がなくなる）
   - [ ] どちらでもない

#### 次の住人向け

1. **値下げ交渉をしたいと思いますか？**
   - [ ] はい
   - [ ] いいえ
   - [ ] 場合による

2. **「値下げ交渉不可」というルールがあっても利用しますか？**
   - [ ] はい
   - [ ] いいえ
   - [ ] 迷う

### 深掘り質問

- 「値下げ交渉OKだと、最初から高めに出品する人が増えると思いますか？」
- 「定価販売の方がシンプルで分かりやすいと思いますか？」
- 「『急ぎで決めたいので¥10,000引きます』という出品者の判断は尊重されるべきですか？」

### 検証ポイント

- 値下げ交渉の可否がUXに与える影響
- 「定価販売」vs「交渉可能」のどちらがsumitsugiのブランドに合うか
- 価格の透明性・公正性への期待

---

## ヒアリング後の分析観点

### 定量分析

- 各質問の選択肢ごとの回答数・割合
- 価格帯別の受容度（¥50,000 / ¥100,000 / ¥150,000）
- ペルソナ別の傾向（急ぎ型vs一般型、20代vs30代など）

### 定性分析

- 「高い」と感じる理由の共通パターン
- 「妥当」と思わせる要素（家具の価値、手間削減、ストーリー性など）
- 競合サービス（メルカリ、ジモティー、家具レンタル）との比較

### 次のアクション

- 価格設定の見直し（手数料率、申込金額）
- 訴求ポイントの調整（「家具購入費¥200,000が不要」を前面に？）
- ユーザーコミュニケーション改善（手数料の透明性、価格の妥当性説明）
