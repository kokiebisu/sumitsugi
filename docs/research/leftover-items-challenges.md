## 1. 業界全体の残置物問題の概要

### 1.1 残置物とは

残置物（ざんちぶつ）とは、賃貸物件の入居者が退去時に撤去・処分せずに残していった家具・家電・生活用品等の動産を指す。法的には退去した入居者に所有権があり、管理会社やオーナーが勝手に処分することはできない。

### 1.2 問題の規模

- **東京23区だけで年間約7.2万トン**の粗大ごみが排出されており、その大部分が家具類
- 引越しシーズン（3-4月）に集中し、自治体の粗大ごみ回収が追いつかないケースが多発
- 賃貸物件の退去時、入居者の多くが「まだ使えるが引越し先に持っていけない」家具を廃棄している
- 国民生活センターへの原状回復トラブルに関する相談は毎年高水準で推移

### 1.3 業界における残置物問題の構造

残置物問題は以下の3者の利害が複雑に絡み合う構造的課題である：

| 関係者               | 立場               | 主な課題                                           |
| -------------------- | ------------------ | -------------------------------------------------- |
| **退去する入居者**   | 残置物の所有者     | 処分費用の負担、時間的制約、もったいないという感情 |
| **管理会社**         | 物件管理の実務担当 | 法的リスク、空室期間の長期化、処分の手間とコスト   |
| **オーナー（大家）** | 物件所有者         | 収益損失（空室）、修繕費用、次の入居者募集への影響 |

## 2. 残置物処分のコスト構造

### 2.1 間取り別の撤去費用相場

| 間取り    | 想定物量 | 費用相場（業者委託） |
| --------- | -------- | -------------------- |
| 1R・1K    | 約10m3   | 3万円〜15万円        |
| 1LDK・2DK | 約20m3   | 8万円〜30万円        |
| 2LDK・3DK | 約30m3   | 15万円〜45万円       |
| 3LDK・4DK | 約40m3   | 17万円〜60万円       |
| 4LDK以上  | 50m3以上 | 20万円〜75万円以上   |

**単価目安**: 1m3あたり7,000円〜15,000円

### 2.2 費用の内訳

残置物撤去費用は以下の作業項目で構成される：

- **整理選別作業**: リサイクル品と廃棄品の分類
- **梱包・搬出作業**: 階段作業や駐車場までの距離で変動
- **運搬費用**: トラックサイズに依存（軽トラ1台: 約1〜3万円、2tトラック: 約5.5万円〜）
- **処分費用**: 最終処分場・リサイクル施設への持ち込み
- **特殊作業費**: 機械類の取り外し、エアコン撤去等

### 2.3 費用負担の実態

法的には残置物の処分費用は所有者（退去した入居者）が負担すべきだが、実際には以下のような問題が発生する：

- **前入居者と連絡が取れない場合**: オーナーが全額負担せざるを得ない
- **敷金からの充当**: 敷金で賄いきれないケースが多い（特に1R・1K物件）
- **夜逃げ・長期不在**: 法的手続きが必要となり、費用と時間が膨大に
- **孤独死の場合**: 相続人の特定・連絡に時間を要し、数年間物件が使えないことも

### 2.4 隠れたコスト：空室損失

残置物処理にかかる「直接費用」だけでなく、以下の**間接コスト**も大きい：

| コスト項目               | 影響                                                  |
| ------------------------ | ----------------------------------------------------- |
| **空室期間の長期化**     | 残置物処理に1〜4週間、その後原状回復工事に1日〜数週間 |
| **家賃損失**             | 空室期間1ヶ月 x 家賃10万円 = 10万円の逸失利益         |
| **原状回復工事の遅延**   | 残置物があると工事に着手できない                      |
| **次の入居者募集の遅延** | 写真撮影・内見ができず、募集開始が遅れる              |

**sumitsugiの観点**: 残置物の「処分」ではなく「引き継ぎ」にすることで、これらのコストを大幅に削減できる。

## 3. 管理会社・大家が直面する具体的課題

### 3.1 所有権の問題

残置物の所有権は法的に前入居者にあり、管理会社が勝手に処分した場合は**損害賠償請求のリスク**がある。

- **判例（東京高判平成3年1月19日）**: 貸主が賃料滞納を理由に契約解除された賃借人の残置物（什器）を無断で古物商に売却。裁判所は「勝手に処分した行為は違法」として103,000円の返金を命令
- 残置物が「明らかに無価値」と言えない限り、所有権放棄の意思表示がない限り処分不可

### 3.2 合意取得の困難さ

- 前入居者と連絡が取れないケースが多い（特に夜逃げ、行方不明）
- 口約束では「言った言わない」のトラブルに発展
- **書面による合意**が必須だが、退去時に書面を交わす体制が整っていない管理会社も多い

### 3.3 清掃業者による誤処分リスク

退去後の原状回復工事で、清掃業者が次の入居者に引き継ぐべき家具を誤って廃棄してしまうリスクがある。

- 管理会社から清掃業者への指示が不明確
- 「残す物」と「処分する物」のリストが共有されていない
- 引き継ぎスケジュールと清掃スケジュールの調整が困難

### 3.4 高齢者入居拒否問題

残置物問題は、高齢者の賃貸入居拒否という深刻な社会問題にも直結している。

- **65歳以上の約26.8%**が年齢を理由に入居を断られた経験がある
- 東京23区内の65歳以上一人暮らし世帯の自宅での死亡者数は2020年に**4,238人**
- 単身高齢者の死亡後、残置物処理に数年かかることがあり、オーナーはその間の賃料収入を失う
- この不安から高齢者の入居申込みを拒否するオーナーが増加

## 4. 法的枠組みと規制動向

### 4.1 民法改正（2020年4月施行）

改正民法では原状回復義務の範囲を明確化：

- **賃借人の原状回復義務**: 通常損耗・経年変化は対象外。故意・過失による損耗のみ
- **通常損耗の費用は賃料に含まれる**という考え方が法的に明確化
- 残置物については、所有権放棄の意思表示がない限り前入居者の財産

### 4.2 国土交通省「原状回復をめぐるトラブルとガイドライン」

1998年策定、2004年・2011年に改訂。原状回復の負担区分を明確化し、トラブルの未然防止を目的とする。42の判例事例を掲載。

### 4.3 国土交通省・法務省「残置物の処理等に関するモデル契約条項」（2021年6月）

高齢者の賃貸入居促進を目的に策定された画期的な制度。

**概要**:

- 単身高齢者の死亡後に、賃貸借契約の解除と残置物の処理を円滑にするためのモデル条項
- 賃借人が生前に「受任者」を指定し、死亡後の契約解除・残置物処分を委任
- **法的義務ではない**が、活用が推奨されている

**背景**:

- 高齢者単身世帯の増加に伴い、孤独死後の残置物処理への不安がオーナーの入居拒否の主因に
- モデル条項の活用により、死後の残置物処理が円滑になり、高齢者の入居が進むことが期待されている

**sumitsugiの観点**: このモデル条項の考え方は、sumitsugiの「残置物同意書」の自動生成機能と親和性が高い。

### 4.4 住宅セーフティネット法改正（2025年10月施行）

高齢者等の住宅確保要配慮者の入居を支援するための法改正。残置物問題の解決は、この法律の趣旨とも合致する。

## 5. 各管理会社の残置物に関する方針・サービス

### 5.1 業界全体の傾向

日本の賃貸管理業界は「デベロッパー系」と「独立系」に大別されるが、残置物に特化したサービスを公式HPで積極的に打ち出している管理会社はほとんどない。これは残置物が「避けたい問題」として認識されており、**解決策がまだ確立されていない**ことを示している。

### 5.2 大手管理会社の一般的対応

| 管理会社タイプ                                             | 残置物への一般的対応                     | 課題                       |
| ---------------------------------------------------------- | ---------------------------------------- | -------------------------- |
| **大手デベロッパー系**（三井不動産、東急、住友不動産など） | 原状回復の一環として処理。提携業者に委託 | 費用が高め、柔軟性に欠ける |
| **大手FC系**（エイブル、アパマンなど）                     | 各店舗・フランチャイジーの裁量に依存     | 対応にばらつき             |
| **独立系地場管理会社**                                     | ケースバイケースで対応。大家との個別交渉 | ノウハウ・リソース不足     |

### 5.3 先進的な取り組み事例

#### アミックス（管理戸数約9,500戸）

- **見守り事務委任契約サービス**: 人感知センサー「みまもりヤモリ」による日常見守り、死後事務委任契約による残置物処理代行
- 月額約3,000円で、孤独死時の残置物処理と明け渡しまでの家賃保証をカバー
- **空室率0.15%**（2024年3月期）を達成。残置物問題の不安を解消することが入居促進につながる好例

#### IKEA（家具メーカーとして参考）

- **家具買取りサービス**: 不要になった家具をIKEAが買い取り、リユース品として再販売
- 循環型経済への取り組みとして、家具の「使い捨て」から「循環」への転換を促進

#### トレジャー・ファクトリー（東証プライム上場）

- 全国300店舗以上のリユースショップ
- 法人向けに残置物の買取・搬出サービスを提供
- **Regacy（レガシー）**: 終活・生前整理の専門サービスブランド

### 5.4 世田谷区周辺の管理会社の状況

世田谷区は東京都内でも賃貸物件が多く、管理会社数も116社以上が登録されている。しかし、残置物に特化したサービスを公式に打ち出している会社は確認できなかった。

- 原状回復工事の専門業者は多数存在（リメイクワークス、こころ屋、KIARO等）
- 残置物撤去は原状回復工事の一部として処理されるのが一般的
- **残置物を「資産」として活用する視点は皆無** --- ここにsumitsugiのビジネスチャンスがある

## 6. 環境・社会的側面

### 6.1 廃棄物問題

- 日本全体の一般廃棄物排出量は年間約4,000万トン超
- 東京23区だけで年間約7.2万トンの粗大ごみ
- 家具・家電の廃棄はCO2排出の大きな要因
- 「まだ使える」家具が大量に廃棄されている現実

### 6.2 サーキュラーエコノミーとの関連

- 環境省は2022年9月に「循環経済工程表」を公表
- SDGs目標12「つくる責任 つかう責任」に直結
- リユース（再使用）の拡大は、製造・廃棄に係るCO2削減に貢献
- 自治体レベルでも粗大ごみのリユース事業が展開されている（横浜市、相模原市、坂戸市等）

### 6.3 社会的課題

- **高齢者の住居確保**: 残置物問題がオーナーの入居拒否の一因
- **単身世帯の増加**: 退去時に家具を処分する「一人暮らし」世帯が増加
- **引越し難民**: 引越しシーズンの集中で、粗大ごみ回収や業者手配が困難に

## 7. sumitsugiが解決できる課題ポイント

### 7.1 残置物を「廃棄物」から「資産」へ転換

**現状**: 残置物 = 処分すべき厄介な問題
**sumitsugi後**: 残置物 = 次の住人に引き継ぐ価値ある暮らしの一部

| 従来の残置物フロー                      | sumitsugiの引き継ぎフロー                             |
| --------------------------------------- | ----------------------------------------------------- |
| 退去 → 残置物発生 → 処分費用発生 → 廃棄 | 退去 → 家具リスト化 → 次の住人へ引き継ぎ → 価値の継承 |
| コスト: 3万円〜75万円                   | コスト: 0円（むしろ収益化）                           |
| 空室期間: 2週間〜数ヶ月                 | 空室期間: 最小化（引き継ぎと入居が連動）              |
| 環境負荷: 大量廃棄                      | 環境負荷: リユースで最小化                            |

### 7.2 管理会社の業務負担を軽減

sumitsugiが提供する仕組みにより、管理会社の残置物関連業務を大幅に削減：

| 管理会社の従来業務              | sumitsugiによる改善                             |
| ------------------------------- | ----------------------------------------------- |
| 前入居者への連絡・交渉          | sumitsugiプラットフォーム上でマッチング完了済み |
| 残置物の確認・リスト化          | 前の住人が写真付きリストを登録済み              |
| 処分業者の手配・立ち合い        | 処分不要（家具は次の住人が引き継ぎ）            |
| 所有権放棄の書面取得            | 残置物同意書を自動生成・デジタル署名            |
| 清掃業者への「残す/捨てる」指示 | sumitsugiのチェックリストを転送するだけ         |

### 7.3 オーナーへのメリット

- **空室期間の短縮**: 残置物処理の待ち時間がゼロに
- **処分費用の削減**: オーナー負担の残置物撤去費用が不要
- **物件の付加価値向上**: 「家具付きですぐ入居できる」物件として訴求
- **大家協力金の収入**: sumitsugiの引越し費用から協力金（1%、最低3,000円）を受け取れる

### 7.4 退去する入居者（前の住人）へのメリット

- **処分費用の節約**: 1K物件でも3〜15万円の処分費用が不要
- **収益化の可能性**: 家具に値段をつけて次の住人に譲渡できる
- **「もったいない」の解消**: まだ使える家具を捨てなくてよい心理的メリット
- **退去時の手間削減**: 粗大ごみの申し込み・搬出が不要

### 7.5 次の住人へのメリット

- **初期費用の削減**: 家具・家電の購入費用を節約
- **引越しの手軽さ**: 大型家具の搬入が不要
- **前の住人のリアルな生活情報**: 住み心地や近隣情報を直接聞ける

### 7.6 社会・環境へのメリット

- **廃棄物削減**: 家具のリユースによるCO2排出削減
- **サーキュラーエコノミーの実践**: SDGs目標12に貢献
- **高齢者の住居確保**: 残置物問題の不安を軽減し、入居促進に寄与

## 8. パートナーシップ提案時の活用ポイント

### 8.1 管理会社への提案における訴求ポイント

#### ポイント1: コスト削減の定量的メリット

```

従来の残置物処理コスト:
  撤去費用: 3万〜15万円（平均8万円）
  空室期間: 2〜4週間 → 家賃損失: 5万〜10万円
  原状回復工事の遅延: 追加1〜2週間 → 家賃損失: 2.5万〜5万円

sumitsugi活用時:
  撤去費用: 0円
  空室期間短縮: 引き継ぎと入居が連動
  管理会社の作業時間: 約30分（Phase A） → 約2,500円
  大家協力金収入: +3,000円以上
  合計削減効果: 約15万〜30万円/件
```

#### ポイント2: 作業負担の削減

#### ポイント3: 法的リスクの軽減

- 残置物同意書の自動生成により、「所有権放棄の書面取得」が確実に
- 写真付きリストで「言った言わない」トラブルを防止
- 清掃業者への明確な指示書（残す物/処分する物のチェックリスト）

#### ポイント4: 環境配慮・SDGsへの貢献

管理会社のCSR活動として、残置物のリユース促進をアピールできる。

| 「法的な問題はないのか？」               | 家具譲渡は動産の個人間売買であり宅建業法の対象外。残置物同意書で所有権移転を明確化           |

| 「オーナーへの説明はどうすればよいか？」 | オーナー説明PDFを提供。空室期間短縮・処分費削減のメリットを定量的に提示                      |
| 「清掃業者との調整は？」                 | sumitsugiのチェックリスト（残す物/処分する物）を転送するだけ。既存の清掃フローに追加依頼     |
| 「トラブル時の責任は？」                 | 合意書で責任所在を明確化。sumitsugiはプラットフォーム提供者として仲介サポート                |

### 8.4 提案のステップ

1. **初回アプローチ**: 残置物処理にかかる年間コストをヒアリング → 削減効果を試算
2. **資料提供**: オーナー説明PDF、残置物同意書テンプレート、清掃チェックリストを共有
3. **パイロット案件**: 1件の退去案件でsumitsugiの仕組みを試行
4. **効果検証**: 空室期間・コスト・入居者満足度を比較
5. **正式提携**: 成功事例をもとに継続的なパートナーシップを構築

## まとめ

残置物問題は、賃貸業界において**コスト・法的リスク・環境負荷・社会的課題**が複合的に絡み合う構造的問題である。現状では「処分」が唯一の解決策とされているが、sumitsugiは**「処分」から「引き継ぎ」へのパラダイムシフト**を提案する。

sumitsugiの価値提案は以下の3点に集約される：

1. **経済的価値**: 残置物処分コスト（平均8〜30万円/件）の削減と、空室期間短縮による家賃収入の保全
2. **実務的価値**: 管理会社の残置物関連業務（90分/件）の大幅削減と、法的リスクの軽減
3. **社会的価値**: 廃棄物削減によるSDGs貢献と、高齢者の住居確保問題の緩和

これらの価値を定量的に示しながら管理会社にアプローチすることで、sumitsugiの協力パートナーとしての管理会社獲得が期待できる。
