## CMOレビュー（マーケティング視点）

### 総合評価: B+（良好・修正で大幅向上の余地あり）

応募資料としての基本構造は整っている。sumitsugiのコンセプト説明、課題定義、テーマ整合性の論理展開は明確。ただし、**審査員の心を動かす「感情的フック」が弱い**点と、**競合との差別化が不十分**な点に改善の余地がある。

---

### 1. ナラティブの強さ

#### 強み

- 「引越しを引き継ぎに変える」というリフレーミングは秀逸。日常体験を新しい角度から捉え直しており、共感を呼びやすい
- 「暮らしを、紡ぐ。」のタグラインはサービス名「sumitsugi」と一貫性がある
- セクション2「解決する社会課題」の論理構造（問題 → 原因 → 解決策）は明確

#### 改善点

- **冒頭に具体的なストーリーがない。** 資料は概念説明から入っているが、審査員が最初に読むのはプロジェクト概要。ここに「引越しで泣く泣くソファを処分した山田さん。3ヶ月後、同じ部屋に越してきた鈴木さんは全く同じサイズのソファをAmazonで注文した——」のような具体エピソードを冒頭に置くと、一気に引き込まれる
- **「前の住人」「次の住人」という用語が初出で説明不足。** 一般的でない表現のため、初見で違和感を持つ審査員がいる可能性がある。最初に「退去する住人（以下、前の住人）」のように明示的に定義すべき
- **数字の裏付けが一部弱い。** 「年間約700万件の引越し」は出典があるが、「大型家具の廃棄量」に具体的な数値がない。環境省のデータ等で補強すると説得力が増す

#### 具体的修正提案

```markdown
## 1. プロジェクト概要

### ある引越しの風景

> 「3年間愛用したダイニングテーブルを、粗大ごみに出すしかなかった」——
> 退去する住人の声です。一方、同じ部屋に入居する次の住人は、
> 同じサイズのテーブルを新品で購入します。
> 年間約700万件の引越しで、この「もったいない」が繰り返されています。

### sumitsugiとは

sumitsugiは、退去する住人（以下「前の住人」）の暮らしを、
次に入居する住人（以下「次の住人」）へ引き継ぐプラットフォームです。
```

### 2. ターゲット適合性（柏の葉審査員・三井不動産への訴求力）

#### 強み

- セクション5「柏の葉スマートシティとの親和性」で、4つの具体的理由を挙げている点は良い
- 「三井不動産管理物件での実証」に言及している点は、審査員（三井不動産関係者）への直接的なアピールになる
- KOIL・UDCKなど柏の葉固有の施設名を出しており、エリアへの理解をアピールできている

#### 改善点

- **三井不動産の課題に直接言及していない。** 三井不動産レジデンシャルの管理物件で実際に起きている残置物問題や空室率の課題に触れると、「この人たちは我々の課題を理解している」と感じてもらえる
- **柏の葉エリアの具体的なデータが不足。** 柏の葉の住民数、転入出率、賃貸物件数などの具体的データがあると説得力が大幅に上がる
- **「スマートシティとの連携」が抽象的。** 「住民の入れ替わりデータを活用した地域サービス最適化」は何を意味するか不明確。具体例を出すべき
- **共創パートナーとしてsumitsugiに何を求めるかが不明確。** 審査員が「具体的に何を一緒にやるのか」をイメージできるよう、「三井不動産に期待すること」を明示すべき

#### 具体的修正提案

セクション5に以下を追加:

```markdown
### 三井不動産との共創で実現したいこと

1. **管理物件2-3件での実証実験:** 退去予定の住人にsumitsugiを案内し、
   引き継ぎ成立率・住人満足度・空室期間への影響を計測
2. **管理業務フローへの組み込み検証:** 退去連絡→sumitsugi案内→
   引き継ぎ→清掃→入居の一連のフローが管理現場で成立するか検証
3. **データに基づくサービス改善:** 柏の葉の住民属性・物件特性に
   合わせたUI/UXの最適化
```

### 3. 競合との差別化

#### 強み

- 「同じ物件の前後の住人をマッチング」という独自の切り口は明確
- 配送不要の家具引き継ぎは、メルカリ等の既存サービスとの決定的な差別化点

#### 改善点

- **競合分析セクションが存在しない。** 審査基準に「事業計画の妥当性」がある以上、競合との比較は必須。メルカリ、ジモティー、家具レンタル（CLAS、subsclife等）との違いを明示すべき
- **「なぜ今まで誰もやっていないのか」への回答が弱い。** セクション2.2で原因を挙げているが、「sumitsugiだけが解決できる理由」（不動産テックとC2Cの融合、管理会社連携）をもっと強調すべき

#### 具体的修正提案

新しいセクションとして「競合比較」を追加:

```markdown
## 競合サービスとの差別化

| サービス       | アプローチ     | sumitsugiとの違い                        |
| -------------- | -------------- | ---------------------------------------- |
| メルカリ       | C2C家具売買    | 配送必要、サイズ不一致リスク             |
| ジモティー     | 地域型C2C      | 配送/引取必要、物件との紐付けなし        |
| CLAS/subsclife | 家具レンタル   | 月額課金モデル、退去時の引き継ぎ概念なし |
| sumitsugi      | 物件内引き継ぎ | 配送ゼロ、サイズ完全一致、管理会社連携   |
```

### 4. ビジュアル・デザイン提案

#### 改善点

- **現状はテキストのみのMarkdownドキュメント。** 最終提出時にはビジュアル化が必須
- **MVPのスクリーンショットが含まれていない。** 既に動作するプロダクトがあるのは大きな強み。物件詳細ページ、ホームページのスクリーンショットを資料に入れるべき
- **ビフォーアフターの図解がない。** 「従来の退去フロー vs sumitsugiのフロー」を図で示すと一目で価値が伝わる

#### 具体的修正提案

- Gamma等のツールでビジュアルスライドを生成（既にgamma-buyer.txt, gamma-seller.txt がある）
- MVPスクリーンショットを3-4枚挿入（ホーム、物件詳細、使い方ガイド、管理会社向けFAQ）
- フロー図の追加: 従来フロー（退去→廃棄→空室→入居→購入）vs sumitsugiフロー（退去→引き継ぎ→入居）

### CMO総合コメント

資料の骨格は十分。情報量も適切。しかし、このままでは「よく整理された計画書」であり、「心が動く提案書」ではない。冒頭のストーリー、MVPスクリーンショット、競合比較の3点を追加するだけで、審査員の印象は大きく変わる。

### 5. その他の法務上の留意点

#### 5.1 宅建業法に関する記載

セクション1「法的に正しいフローを維持しながら」の記載は適切。sumitsugiが「マッチングの場」であり、賃貸借契約の締結は宅建業者が行うことを明示している点は法的リスクの軽減に寄与する。

ただし、この表現が**宅建業法への完全な適合を確約するものではない**点に留意。外部弁護士の確認が完了するまで、「法的に正しいフロー」という断定表現は「法的に適切なフローの設計を進めている」等の表現に変更することを推奨する。

#### 5.2 SDGs表現のリスク

SDGs #12への言及自体は問題ないが、具体的なCO2削減量や環境負荷の数値を記載していない点は、逆にリスクを低減している（根拠なき環境訴求は消費者庁のグリーンウォッシュ・ガイドラインに抵触する可能性がある）。現状の定性的な記載レベルで問題ない。
