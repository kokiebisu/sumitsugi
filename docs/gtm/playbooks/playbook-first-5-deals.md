# ビジネスプレイブック: 最初の5件をどう取るか

**作成日:** 2026-02-09
**GTM会議:** #1
**対象フェーズ:** 物件0-5件（プレローンチ〜初期トラクション）

---

## エグゼクティブサマリー

- 営業未経験のファウンダーが最初の5件を取るには、**友人紹介→コンシェルジュ伴走→管理会社ルート活用→成約事例の横展開**の4段階で進める
- 大原則は**「営業するな、相談しろ」** — 売り込みではなく、困りごとの相談として入る
- 1エリア（渋谷区等）で5件成約するまで、他エリアに手を出さない

---

## ターゲット

| 対象                       | プロフィール               | どこで見つけるか         | いつアプローチするか |
| -------------------------- | -------------------------- | ------------------------ | -------------------- |
| 前の住人（友人経由）       | 引越し予定の知人           | LINE、直接会話           | 退去2-3ヶ月前        |
| 前の住人（SNS経由）        | 「家具どうしよう」と悩む人 | X、Instagram             | 退去1-2ヶ月前        |
| 前の住人（引越し業者経由） | 見積もり訪問を受けた人     | 引越し業者の紹介         | 見積もり時           |
| 次の住人                   | 入居予定者                 | 管理会社の通常募集ルート | 内見〜申込時         |

## フェーズ別アクション

## Phase 0: 最初の「前の住人」を見つける（Week 1-2）

### チャネル: 友人紹介（一本集中）

**なぜこのチャネルか（ペルソナの声）:**

> 💤 ナオ: 「友達からのLINEなら、広告と違って無視しない」
> 🏠 ユキ: 「『サービス使ってください！』じゃなくて、『周りにいない？』って聞き方だから、プレッシャーがない」

**具体的アクション:**

| #   | アクション     | 手順                                                     | 所要時間 |
| --- | -------------- | -------------------------------------------------------- | -------- |
| 1   | 友人リスト作成 | 「今度引越す」「最近引越した」可能性のある知人を洗い出す | 30分     |
| 2   | LINEで声かけ   | 下記スクリプトを送る                                     | 1人5分   |
| 3   | 紹介依頼       | 「周りで引越す人いたら教えて」と追加でお願い             | ついでに |
| 4   | 初回ヒアリング | 興味を持った人にオンラインで説明                         | 30分/人  |

**スクリプト（LINEメッセージ）:**

```
久しぶり！ちょっと聞きたいんだけど、今度引越し予定とか、周りで引越す人いたりしない？

実は今、引越しの時に家具を次に住む人にそのまま引き継げるサービスを作ってて。処分代も浮くし、お金もらえることもあるんだけど、もし興味ある人いたら紹介してほしくて！
```

**興味を持った人への追加メッセージ（ケンジタイプ向け）:**

```
写真撮ってアップするだけで出品完了。所要時間15分くらい。
平均的な1LDKの家具セットだと、5-15万円くらいで引き継ぎ成立してる。
処分代（3-5万円）が浮く上に、プラスでお金ももらえる感じ。
```

**成功指標:** 2週間で3人以上に「興味ある」と言ってもらう

**想定反応と対処:**

- ✅ 「え、なにそれ？詳しく教えて」 → 30分のオンライン説明を設定
- ⚠️ 「面白そうだけど、今は引越し予定ない」 → 「周りにいたら教えてね」で紹介依頼
- ❌ 「うーん、よく分からない」 → 深追いしない。「またタイミング合ったらね」

## Phase 1: 出品〜管理会社承認まで伴走する（Week 2-4）

**なぜ全面伴走が必要か（ペルソナの声）:**

> 🔄 トモヤ: 「最初の1件目は絶対に成功させること。ここでコケると、友人ネットワークの信頼が全部消える」
> 🪑 マリ: 「ファウンダーが『私が一緒に説明しますよ』『資料は用意してあります』って全部サポートする」

**具体的アクション:**

| #   | ステップ             | ファウンダーのアクション                       | 所要時間     |
| --- | -------------------- | ---------------------------------------------- | ------------ |
| 1   | 物件訪問             | 前の住人の部屋を訪問。スマホで写真撮影を手伝う | 1-2時間      |
| 2   | 出品サポート         | 一緒にリスティングを作成。値付けアドバイス     | 1時間        |
| 3   | 管理会社資料準備     | PDF資料「残置物引き継ぎのご相談」を用意        | 事前準備済み |
| 4   | 管理会社連絡サポート | 前の住人→管理会社へ連絡（メールテンプレ提供）  | 前の住人10分 |
| 5   | 管理会社フォロー     | 必要に応じてファウンダーが管理会社に直接説明   | 30分         |
| 6   | 承認待ち             | 大家の承認を管理会社経由で取得                 | 1-2週間      |

**写真撮影のコツ（マリからのアドバイス）:**

- 自然光が入る時間帯に撮る（午前10時〜午後2時）
- スマホの広角レンズで部屋全体を撮る
- 家具の状態が分かるクローズアップも2-3枚
- 生活感のある「住んでる感」を残す（完璧に片付けすぎない）

**管理会社へのアプローチ（トロイの木馬戦略）:**

前の住人から管理会社への連絡テンプレート:

```
件名: 退去時の家具についてご相談

〇〇管理会社 ご担当者様

お世話になっております。〇〇号室の〇〇です。
来月末で退去を予定しておりますが、現在使用している家具について
ご相談させていただけないでしょうか。

家具の状態がまだ良好なため、次に入居される方に
引き継ぐことができればと考えております。

「sumitsugi」という家具引き継ぎサービスを利用して、
次の入居者様に引き継ぐ仕組みがあるようです。
詳細資料を添付いたしますので、ご検討いただけますと幸いです。

ご不明点がございましたら、サービス運営者から
直接ご説明させていただくことも可能です。

何卒よろしくお願いいたします。
```

**成功指標:** 管理会社の承認を1件取得する

**想定反応と対処:**

- ✅ 管理会社が前向き → 次の入居者募集時に「家具付き」として案内してもらう
- ⚠️ 管理会社が迷い中 → ファウンダーが直接説明を申し出る。PDF資料で補足
- ❌ 管理会社がNG → 大家に直接アプローチできないか確認。無理なら次の物件に切り替え

## Phase 2: 次の住人を集める（Week 4-8）

**なぜ独自集客が不要か（ペルソナの声）:**

> 🌱 ハル: 「SUUMOで『家具付き』って見えたら絶対クリックする。入居初日から生活できるじゃないですか」

**具体的アクション:**

| #   | アクション     | 手順                                                       | 所要時間 |
| --- | -------------- | ---------------------------------------------------------- | -------- |
| 1   | 管理会社に依頼 | 次の入居者募集時に「家具引き継ぎ可能」と記載を依頼         | 10分     |
| 2   | SUUMO備考欄    | 「前住人の家具引き継ぎ可能」の一文追加を管理会社経由で依頼 | 依頼のみ |
| 3   | 仲介会社通知   | 管理会社経由で仲介に「家具付き物件あり」と情報提供         | 依頼のみ |
| 4   | SNS仕込み開始  | Xで引越し・インテリア関連のアカウントをフォロー、交流開始  | 1日15分  |

**メッセージの核:**

> 「入居初日から生活できる」

**成功指標:** 次の住人候補を1人以上見つける

---

## Phase 3: 1件の成約を横展開する（Week 8-12）

**なぜ事例が全てか（ペルソナの声）:**

> 📸 アカネ: 「1件でも成功事例があれば最強のコンテンツになる。保存数すごいことになると思う」
> 🚚 タクミ: 「チラシに『◯件成約済み』って書いてあったら、信頼感が違う」

**具体的アクション:**

| #   | アクション           | 目的                                             | 所要時間  |
| --- | -------------------- | ------------------------------------------------ | --------- |
| 1   | ビフォーアフター写真 | SNSコンテンツ＋管理会社向け実績資料              | 30分      |
| 2   | 体験談インタビュー   | 前の住人＋次の住人の声を記録（匿名OK）           | 各30分    |
| 3   | 管理会社レポート     | 「御社の物件で引き継ぎが成立しました」報告       | 30分      |
| 4   | 成果SNS投稿          | X/Instagramで成約ストーリーを投稿                | 30分      |
| 5   | 紹介依頼             | 成約した前の住人に「周りで引越す人いたら教えて」 | 5分       |
| 6   | アカネさんへ連絡     | 写真付き事例を持ってインフルエンサーに紹介依頼   | 30分      |
| 7   | タクミさんチャネル   | チラシ/QRカードを作成し引越し業者に配布依頼      | 制作1時間 |

**SNS投稿テンプレート:**

```
【引き継ぎ成立レポート】

渋谷区1LDKの暮らしが、次の住人に引き継がれました。

前の住人: 5年間かけて揃えたミッドセンチュリーの家具。
次の住人: 新社会人。入居初日から「自分の部屋」に。

処分代5万円が浮いた上に、◯万円の引き継ぎ料。
「捨てるしかない」と思ってた家具が、誰かの新生活になった。

#sumitsugi #暮らしを紡ぐ #引越し #インテリア
```

**成功指標:** 事例コンテンツの反応（保存数、DM数）を計測

## フェーズ移行条件

| 移行                   | 条件                                    |
| ---------------------- | --------------------------------------- |
| Phase 0 → Phase 1      | 前の住人1人が「やりたい」と言った       |
| Phase 1 → Phase 2      | 管理会社の承認が1件取れた               |
| Phase 2 → Phase 3      | 1件の成約が成立した                     |
| Phase 3 → 次のフェーズ | 5件の成約 + 2つ以上の管理会社と関係構築 |

## 大原則

> **「営業するな、相談しろ」**
>
> 「こういうの作ってるんだけど、どう思う？」
> 「引越しで困ってること教えて」
>
> この姿勢なら、営業経験ゼロでもできる。
