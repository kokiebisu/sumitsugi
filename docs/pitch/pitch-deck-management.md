## スライド 3: sumitsugiとは

### スライドコンテンツ

```
sumitsugiの仕組み（30秒で分かる）

退去者の家具・インテリア
      ↓ そのまま残す
次の入居者が引き継ぐ
      ↓ 引越し費用を支払い

管理会社の役割:
  退去時に「sumitsugiどうですか？」と声がけ
  あとはsumitsugiがサポート
```

### プレゼンテーションスクリプト

「sumitsugiは、退去する住人の家具やインテリアを、次の入居者にそのまま引き継ぐプラットフォームです。

管理会社さんにお願いしたいのは、退去連絡があった時に『sumitsugiってサービスがあるんですが、家具を次の人に引き継げますよ』と声がけいただくだけ。

出品のサポート、マッチング、書類の自動生成——こうした作業はsumitsugiが行います。管理会社さんの既存の業務フローには、ほとんど変更ありません。」

### ビジュアル指示

- シンプルなフロー図（上→下）
- 「声がけるだけ」を強調
- 管理会社の負担が少ないことを視覚的に

## スライド 4: 管理会社の3つのメリット

### スライドコンテンツ

```
管理会社にとっての3つのメリット

1. 残置物トラブルがゼロ
   三者間の同意書で所有権移転が明確
   退去者との揉め事なし

2. 空室期間の短縮
   家具付き即入居で決まりやすい
   オーナーへの報告が楽に

3. 1件あたり¥11,000の収入
   追加清掃費 ¥8,000（既存業者で対応）
   紹介フィー ¥3,000（純利益）
```

### プレゼンテーションスクリプト

「管理会社さんにとっての具体的なメリットを3つ、お伝えします。

1つ目、**残置物トラブルがゼロ**。sumitsugiでは、前の住人・次の住人・大家の三者間で残置物同意書を締結します。所有権が次の住人に移転すること、退去時の処分責任が次の住人にあることが法的に明確になります。退去者と揉める必要はもうありません。

2つ目、**空室期間の短縮**。家具やインテリアが揃った状態で次の入居者を募集できます。『すぐ住める物件です』は強力な訴求です。空室が早く埋まれば、オーナーさんへの報告も楽になります。

3つ目、**収入**。家具の追加クリーニング費8,000円は、御社の既存のクリーニング業者が部屋の清掃と一緒に対応します。加えて紹介フィー3,000円が純利益として入ります。1件あたり合計11,000円です。」

### ビジュアル指示

- 3つの大きなブロック
- メリット1「残置物ゼロ」を最も目立たせる
- 「¥11,000」を緑色で強調

```
─────────────
紹介フィー   ¥3,000  → 管理会社（sumitsugi手数料から支出）
```

「お金の流れをご説明します。

管理会社さんへは、追加清掃費8,000円と紹介フィー3,000円の合計**1万1,000円**が入ります。紹介フィーはsumitsugiの手数料から支出するので、誰の負担にもなりません。

作業時間は約30分ですから、時給換算で6,000円以上。既存の業務に少し声がけを加えるだけで、新しい収入源になります。」

## スライド 6: 具体的な業務フロー

### スライドコンテンツ

```
管理会社の業務フロー（全6ステップ）

1. 退去連絡 → 「sumitsugiどうですか？」と案内
2. sumitsugiが出品をサポート（管理会社の作業なし）
3. マッチング成立 → 同意書を自動生成
4. 同意書テンプレに記入（5分）→ 三者で締結
5. 清掃時に家具クリーニングも実施
6. 通常通り入居手続き

管理会社の追加作業: ステップ1,4,5のみ
合計: 約30分
```

### プレゼンテーションスクリプト

「具体的な業務フローをご説明します。全6ステップですが、管理会社さんが動くのは3つだけです。

ステップ1、退去連絡があった時に『sumitsugiで家具を引き継げますよ』と案内。

ステップ2と3はsumitsugiが行います。出品サポートとマッチング。管理会社さんの作業はありません。

ステップ4、マッチングが成立したら、sumitsugiが自動生成した同意書テンプレートに記入。穴埋めで5分です。

ステップ5、通常の清掃時に、家具のクリーニングも既存の業者さんで一緒に実施。

ステップ6、入居手続きは通常通り。

つまり**追加作業は声がけ・同意書記入・清掃指示の3つだけ**。合計約30分です。」

- ステップ1,4,5を管理会社カラーで、2,3をsumitsugiカラーで色分け

### スライドコンテンツ

```

Q. 賃貸借契約に影響は？

   契約は不動産会社が従来通り締結。

Q. 大家への説明が面倒？
A. sumitsugiのPDFをメール転送するだけ。
   大家メリット: 空室短縮 + 残置物ゼロ + 協力金¥3,000

   と同意書に明記。リスクゼロ。

Q. 清掃業者が対応できる？
A. 既存業者が部屋清掃の延長で家具も対応。
   追加清掃費¥8,000で実費カバー。
```

### プレゼンテーションスクリプト

「よくある質問にお答えします。

『賃貸借契約に影響はないですか？』影響ゼロです。sumitsugiは家具の引き継ぎ、つまり動産の個人間売買のみ。賃貸借契約は従来通りです。

『大家への説明は？』sumitsugiが用意したPDFをメール転送するだけです。大家さんにとっても空室短縮・残置物トラブル解消・協力金とメリットがあるので、むしろ歓迎されます。

『家具が壊れたら管理会社の責任ですか？』いいえ。同意書に『現状有姿での引き渡し』『故障等の責任は大家・管理会社に問わない』と明記します。管理会社さんのリスクはゼロです。

『清掃業者が家具クリーニングに対応できますか？』部屋のクリーニングの延長として、家具の拭き掃除や消臭を一緒にやっていただく想定です。追加清掃費8,000円で実費をカバーします。」

- Q&A形式、シンプル
