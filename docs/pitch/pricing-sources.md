## 1. 残置物撤去費用

### 調査日: 2026-02-03

### 調査方法: Web検索、業者Webサイト

#### データソース

| 間取り             | 費用範囲                  | 出典                                                                                       |
| ------------------ | ------------------------- | ------------------------------------------------------------------------------------------ |
| 1LDK/2DK（約20㎥） | 20〜30万円                | [残置物撤去の処分費用はいくら？](https://www.shida-eco.com/media/remaining-item-cost/)     |
| 1LDK               | 7〜20万円（荷物量による） | [残置物撤去とは？費用はいくら？](https://m-ihinseiri.jp/article-service/zantibutsu-price/) |
| 賃貸マンション     | 平均40万円                | 国土交通省調査（複数業者平均）                                                             |

#### 価格算出方法

**標準価格:** 7,000〜15,000円/㎥

- 1LDK平均: 約20㎥
- 計算: 20㎥ × 10,000円/㎥ = 20万円

#### 影響要因

- 荷物の量
- 建物の立地・アクセス
- 特殊清掃の有無
- エレベーターの有無

#### 結論

**1LDKの残置物撤去費用: 20〜40万円**

- 保守的な見積もり: 20万円
- 平均的な見積もり: 30万円
- 高めの見積もり: 40万円

## 4. 引越し費用（sumitsugi価格）の設定根拠

### 調査日: 2026-02-03

### 調査方法: 家具レンタル・中古家具市場調査

#### 家具レンタルサービス（競合参考）

##### CLAS（クラス）

**出典:** [CLAS使ってみた](https://www.saku-info.net/entry/clas)

- 月額料金: 440円〜
- 12ヶ月レンタル: 定価の約56%
- 長期割引: 13ヶ月目〜20%オフ、25ヶ月目〜50%オフ

**例:** 1LDK家具セット（ソファ + テーブル + ベッド）

- 月額: 1〜2万円
- 12ヶ月合計: 12〜24万円

##### subsclife（サブスクライフ）

**出典:** [subsclifeの口コミ評判](https://e-reikinet.jp/subsclife/)

- 月額料金: CLASの約2倍（短期）
- 総額が定価を超えない設計
- 12ヶ月後に購入可能

#### 中古家具市場（参考）

- メルカリ: ソファ1〜3万円、ベッド2〜5万円、テーブル1〜2万円
- ジモティー: 無料〜1万円（引き取り必須）

#### sumitsugi価格設定の考え方

**前提:**

- 家具の所有権は次の住人に移転
- 前の住人は撤去費用を回避
- 次の住人は新品購入より安く入手

**価格範囲の算出:**

| 要素                   | 金額       |
| ---------------------- | ---------- |
| 家具の市場価値（中古） | 5〜10万円  |
| 撤去費用の回避価値     | 20〜40万円 |
| 次の住人の購入費用削減 | 10〜20万円 |

**適正価格帯:** 10〜20万円

- **最低価格:** 10万円（家具の市場価値）
- **標準価格:** 15万円（中央値）
- **最高価格:** 20万円（家具充実物件）

#### 結論

**sumitsugi引越し費用: 10〜20万円**

- ピッチデッキでは **15万円** を標準として使用
- 実際は物件・家具状態により 10〜20万円の範囲で変動
