## スライド 4: 解決策

### スライドコンテンツ

```
tsumugiの仕組み

1. リスティング
   ↓
2. マッチング
   ↓
3. 引き継ぎ

━━━━━━━━━━━━

あなた: +15万円
次の住人: 初期費用削減
大家: トラブルゼロ
```

### プレゼンテーションスクリプト

「tsumugiなら、暮らしを引き継げます。仕組みはシンプルです。

まず、あなたが家具付き物件としてリスティングします。

次に、次の住人が見つかり、引越し費用を支払います。

最後に、そのまま住み続けてもらう。

あなたは15万円を受け取る。次の住人は初期費用を抑えられる。大家は残置物トラブルがなくなる。

みんなが得をする、新しい引越しのカタチです。」

### ビジュアル指示
- フロー図（上から下へ、または左から右へ）
- 3ステップをシンプルに
- Win-Win-Winを強調

## スライド 5: 経済的メリット

### スライドコンテンツ

```
従来 vs tsumugi（例）

【従来】
撤去費用  -30万円
引越し業者 -8万円
━━━━━━━━
合計     -38万円

【tsumugi】
引越し費用 +15万円
引越し業者 -8万円
━━━━━━━━
合計     +7万円

差額: 30〜60万円

※物件・家具により異なります
```

### プレゼンテーションスクリプト

「具体的な数字で見てみましょう。例えば、1LDKの場合です。

従来の引越しでは、残置物撤去に20万円から40万円、引越し業者に8万円。合計28万円から48万円の出費です。

tsumugiを使うと、引越し費用として10万円から20万円を受け取り、引越し業者に8万円。つまり、2万円から12万円のプラスです。

差額は30万円から60万円。これだけあれば、新しい生活を始める資金になりますよね。

もちろん、金額は物件の立地や家具の状態によって異なりますが、大幅な削減効果があります。」

**[ここで電卓を使って一緒に計算してもOK]**

### ビジュアル指示
- Before/After比較表（左右2列）
- 赤色（従来）→ 緑色（tsumugi）
- 「45万円」を特大フォントで

## スライド 6: 安心の仕組み

### スライドコンテンツ

```
3つの安心

🔒 エスクロー決済
📄 残置物同意書
✓ 大家の承認
```

### プレゼンテーションスクリプト

「でも、『トラブルになったらどうしよう』と心配ですよね。tsumugiには3つの安心があります。

1つ目、エスクロー決済。引越し費用は、引き継ぎが完了するまで安全に預かります。世界標準のStripe Connectを採用しています。

2つ目、残置物同意書。法的にも安心です。前の住人、次の住人、大家の三者で締結し、所有権移転を明確にします。

3つ目、大家の承認。大家も納得の仕組みです。残置物トラブルや原状回復費用のリスクがなくなります。」

### ビジュアル指示
- 3つのアイコン（盾、契約書、チェックマーク）
- シンプル、クリーン
- アイコンを大きく

## 追加資料: プレゼンテーションのコツ

### 対面で話す場合（5-7分）

**導入（30秒）**
- 自己紹介
- 「今日は引越しの新しいカタチをご紹介します」

**ストーリー（1分）**
- スライド2: 自分の体験を語る
- 感情を込めて、ゆっくりと

**課題共有（1分）**
- スライド3: 「同じ経験ありませんか？」と問いかけ
- 相手のうなずきを確認

**解決策（2分）**
- スライド4-5: シンプルに説明、数字で納得させる
- 質問を促す

**安心感（1分）**
- スライド6: 不安を先回りして解消

**CTA（1分）**
- スライド7: 「まずは登録してみませんか？」
- ハードルを下げる

**Q&A（1-2分）**
- その場で出た質問に対応

### オンラインで話す場合（3-5分）

- スライドを共有
- スライド1-2-4-5-7の5枚に絞る
- 簡潔に、テンポよく
