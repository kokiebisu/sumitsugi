## スライド 1: タイトル

### スライドコンテンツ

```
sumitsugi（住み継ぎ）

あなたの暮らし、次の誰かへ。
```

### プレゼンテーションスクリプト

「本日は貴重なお時間をいただき、ありがとうございます。私は[名前]と申します。sumitsugi（住み継ぎ）という、暮らしを引き継ぐプラットフォームを作っています。」

### ビジュアル指示

- 背景: 温かみのある部屋の写真（自然光、暮らしの世界観が伝わるインテリア）
- フォント: 明朝体、大きめ
- カラー: コーラル (#FF5A5F) をアクセントに

## スライド 2: ファウンダーストーリー

### スライドコンテンツ

```
「3年かけて作った空間が、
　1日で消えた」

撤去費用: 30万円
```

### プレゼンテーションスクリプト

「3年前、引越しをしました。お気に入りのソファ、友人と囲んだダイニングテーブル、朝日が差す窓辺のグリーン。3年かけて作り上げた空間が、たった1日で全て消えました。

撤去費用30万円。心も、お財布も痛みました。

でも一番辛かったのは、お金じゃなくて、**この空間をそのまま誰かに使ってもらえたら**、と思ったのに、その方法がなかったことです。」

**[ここで間を取り、相手の反応を見る]**

### ビジュアル指示

- 背景: 美しく整ったインテリア → 空っぽの部屋（Before/After的な対比）
- 「3年」と「1日」の対比を大きく
- 感情に訴えるレイアウト

## スライド 3: 課題

### スライドコンテンツ

```
引越しで失うもの

✗ 作り上げた空間の世界観
✗ 撤去費用 20〜40万円
✗ 捨てる罪悪感
✗ 原状回復の要求

年間500億円の家具が廃棄
```

### プレゼンテーションスクリプト

「引越しの時、最初に失うのは何だと思いますか？

お金じゃないんです。**あなたが時間をかけて作り上げた暮らしの世界観**です。ソファだけじゃない。照明の位置、ラグの色合い、植物の配置——全部含めて、あなたの空間なんです。

それが全て消えて、さらに残置物の撤去に20万円から40万円。まだ使える家具を捨てる罪悪感。大家さんからは原状回復を求められる。

日本では年間500億円相当の家具が廃棄されています。その裏には、500億円分の**誰かの暮らし**があったはずです。」

**[ここで相手の共感を確認]**

### ビジュアル指示

- 1行目「作り上げた空間の世界観」を最も目立たせる
- 金額の課題は2番目の優先度
- 最下部の統計数字を強調

## スライド 4: ポジショニング

### スライドコンテンツ

```
暮らしの世界観は、家具だけじゃ作れない

レンタル家具  → パーツの一時貸し
ステージング  → 見せかけの空間演出
sumitsugi      → 本物の暮らしの引き継ぎ
               モノ＋世界観＋ストーリー
```

### プレゼンテーションスクリプト

「ここで、よくある質問にお答えします。『レンタル家具やホームステージングと何が違うの？』

レンタル家具は、パーツの一時貸しです。ソファ1つ、テーブル1つ。便利だけど、空間にはなりません。

ホームステージングは、売るために用意された見せかけの空間です。モデルルームと同じで、誰の暮らしでもない。

sumitsugiは違います。**あなたが実際に暮らした空間を、そのまま次の人に引き継ぐ。** モノだけじゃなくて、世界観もストーリーも一緒に。これは他のどのサービスにもできません。」

### ビジュアル指示

- 3段の比較表（上2つはグレーアウト、sumitsugiのみカラー）
- sumitsugiの行にコーラル色のハイライト
- 「本物の暮らし」を強調

## スライド 5: 解決策

### スライドコンテンツ

```
sumitsugiの仕組み

1. リスティング（世界観を伝える）
   ↓
2. 内見（あなたが暮らしを案内）
   ↓
3. 引き継ぎ（空間がそのまま残る）

━━━━━━━━━━━━

あなた: 暮らしを繋ぐ + 収入
次の住人: 完成された空間
大家: トラブルゼロ
```

### プレゼンテーションスクリプト

「sumitsugiなら、あなたの暮らしを引き継げます。仕組みはシンプルです。

まず、あなたの部屋をリスティングします。家具のスペックだけじゃなくて、**どんな暮らしをしていたか**を伝えます。

次に、興味を持った次の住人候補が来たら、**あなた自身が部屋を案内します。** 不動産屋の内見とは違って、『このソファで朝コーヒーを飲むのが最高で』とか、『この棚はこう使うと便利で』とか。暮らしのストーリーを直接伝えられます。

最後に、引き継ぎ。あなたが退去した後も、空間はそのまま残り続けます。

あなたは暮らしを繋いだ上に収入も得る。次の住人は完成された空間で新生活を始められる。大家は残置物トラブルがなくなる。

全員が得をする、新しい引越しのカタチです。」

### ビジュアル指示

- フロー図（上から下へ）
- ステップ2「あなたが案内」をハイライト（差別化ポイント）
- Win-Win-Winを三角形で表現

## スライド 6: 経済的メリット

### スライドコンテンツ

```
暮らしを繋いで、次の生活資金に（例）

【従来】
撤去費用  -30万円
引越し業者 -8万円
━━━━━━━━
合計     -38万円

【sumitsugi】
引越し費用 +15万円
引越し業者 -8万円
━━━━━━━━
合計     +7万円

差額: 30〜60万円

※物件・家具により異なります
```

### プレゼンテーションスクリプト

「世界観を引き継ぐだけじゃありません。経済的にも大きなメリットがあります。

例えば1LDKの場合。従来の引越しでは、残置物撤去に20万円から40万円、引越し業者に8万円。合計28万円から48万円の出費です。

sumitsugiを使うと、引越し費用として10万円から20万円を受け取り、引越し業者に8万円。つまり、2万円から12万円のプラスです。

差額は30万円から60万円。新しい場所での暮らしを始める資金になります。

もちろん金額は物件や家具の状態で変わりますが、**暮らしを繋いだ上にプラスになる**。これがsumitsugiの経済モデルです。」

### ビジュアル指示

- Before/After比較表（左右2列）
- 赤色（従来）→ 緑色（sumitsugi）
- 差額を特大フォントで

## スライド 7: 安心の仕組み

### スライドコンテンツ

```
3つの安心

🔒 2段階決済
   申込金 → 引き継ぎ確認後に残額
📄 残置物同意書
   三者間で締結
✓ 大家の承認
   大家納得の仕組み
```

### プレゼンテーションスクリプト

「でも、『トラブルになったらどうしよう』と心配ですよね。sumitsugiには3つの安心があります。

1つ目、2段階決済。次の住人はまず申込金2万円を支払い、引き継ぎが完了してから残額を支払います。あなたへの入金は引き継ぎ完了後に確定するので、安心して進められます。世界標準のStripe Connectを採用しています。

2つ目、残置物同意書。前の住人、次の住人、大家の三者で締結し、所有権移転を法的に明確にします。

3つ目、大家の承認。大家も納得の仕組みです。残置物トラブルや原状回復費用のリスクがなくなるので、むしろ大家にとってもメリットがあります。」

### ビジュアル指示

- 3つのアイコン（盾、契約書、チェックマーク）
- 「2段階決済」を新しい要素として目立たせる
- シンプル、クリーン

## スライド 9: FAQ（オプション）

### スライドコンテンツ

```
よくある質問

Q. 全部残さないとダメ？
A. 世界観の「主役」だけでOK
   思い入れのある小物は持っていけます

Q. 大家の許可は？
A. 必要です（サポートあり）

Q. 費用は？
A. 手数料12%のみ
   （15万円なら1.8万円）
```

### プレゼンテーションスクリプト

「よくある質問にお答えしますね。

『全部残さないとダメですか？』いいえ。暮らしの世界観を作っている**主役の家具**——例えばソファ、テーブル、照明——これだけ残してもらえれば大丈夫です。思い入れのある小物や個人的なアイテムは自由に持っていけます。抜けた場所は、次の住人が自分なりに埋めていきます。

『大家の許可は必要ですか？』はい、必要です。でも、sumitsugiが大家への説明をサポートしますので、ご安心ください。

『費用はかかりますか？』プラットフォーム手数料12%のみです。例えば、引越し費用15万円なら、手数料1.8万円、受取額は13.2万円です。」

**[他に質問があれば対応]**

### ビジュアル指示

- Q&A形式、シンプル
- 最初のQ（全部残す必要なし）を目立たせる
- 余白を多めに

## 追加資料: プレゼンテーションのコツ

### 対面で話す場合（5-7分）

**導入（30秒）**

- 自己紹介
- 「今日は引越しの新しいカタチをご紹介します」

**ストーリー（1分）**

- スライド2: 自分の体験を語る
- 「お金」より「空間が消える」感情を込めて

**課題共有（1分）**

- スライド3: 「同じ経験ありませんか？」と問いかけ
- 相手のうなずきを確認

**差別化（30秒）**

- スライド4: ポジショニング表をさっと見せる
- 「レンタル家具とは根本的に違います」

**解決策（1.5分）**

- スライド5: シンプルに説明
- **「あなたが暮らしを案内する」**ステップを強調

**経済メリット（1分）**

- スライド6: 数字で納得させる
- 質問を促す

**安心感（30秒）**

- スライド7: 不安を先回りして解消

**CTA（30秒）**

- スライド8: 「まずは登録してみませんか？」
- ハードルを下げる

**Q&A（1-2分）**

- その場で出た質問に対応

- スライドを共有
- スライド1-2-4-5-6-8の6枚に絞る
