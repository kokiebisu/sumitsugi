## スライド 3: 解決策 — 暮らしを引き継ぐ

### スライドコンテンツ

```
tsumugiの仕組み

前の住人 → リスティング → 内見案内 → 引き継ぎ → 収入
次の住人 → 物件探し → 内見体験 → 入居 → 完成された空間

━━━━━━━━━━━━━━
前の住人:  撤去費用 -30万円 → 引越し費用 +15万円
次の住人:  家具購入 -40万円 → 引越し費用 -15万円
━━━━━━━━━━━━━━
前の住人: +45万円改善  /  次の住人: +25万円節約
```

### プレゼンテーションスクリプト

「tsumugiは、前の住人の暮らしを次の住人にそのまま引き継ぐプラットフォームです。

仕組みは3ステップ。

1. 前の住人が自分の部屋をリスティングします。家具のスペックではなく、**どんな暮らしをしていたか**を伝えます。
2. 次の住人候補が来たら、**前の住人が直接部屋を案内します。** 不動産屋の内見ではなく、暮らしのツアーです。
3. マッチングしたら引き継ぎ。前の住人は引越し費用を受け取り、次の住人は完成された空間で新生活を始めます。

経済的なインパクトを見てください。

前の住人は、撤去費用マイナス30万円が、プラス15万円の収入に。**45万円の改善**です。
次の住人は、家具購入マイナス40万円が、引越し費用マイナス15万円に。**25万円の節約**です。

双方合わせて**70万円の価値**が1取引で生まれます。」

- 中央にフロー図（前の住人→tsumugi→次の住人）
- Before/After比較表を下部に

## スライド 8: 参入障壁 — ネットワーク効果とストーリー

### スライドコンテンツ

```
なぜ真似されにくいか

1. ネットワーク効果
   前の住人が増える → 物件が増える → 次の住人が増える
   → 大家・管理会社が協力する → さらに物件が増える

2. ストーリーの蓄積
   引き継ぎ回数 × 暮らしのストーリー = 代替不可能な資産
   「この空間で3代の住人が暮らした」

3. B2B連携（管理会社・大家）
   先行者利益: 初期の関係構築がそのまま参入障壁に

4. 暮らしのキュレーター経済圏（長期ビジョン）
   引き継ぎN回 → 累計Nクライアント → ストック型収入
   Airbnbスーパーホストの「定住版」
```

### プレゼンテーションスクリプト

「このビジネスが真似されにくい理由を4つお伝えします。

1つ目、**ネットワーク効果**。前の住人が増えれば物件が増え、次の住人が増える。大家や管理会社が協力すればさらに加速します。これは古典的なマーケットプレイスのフライホイールです。

2つ目、**ストーリーの蓄積**。tsumugiの物件には暮らしのストーリーが紐づいています。引き継ぎが重なるほど、『この空間で3代の住人が暮らした』という唯一無二の資産になる。これはコードをコピーしても再現できません。

3つ目、**B2B連携**。管理会社や大家との関係構築は時間がかかります。先に動いた分だけ優位です。

4つ目、長期ビジョンとして**暮らしのキュレーター経済圏**を構想しています。引き継ぎを繰り返す人が『暮らしのキュレーター』になり、ストック型の収入を得る。Airbnbのスーパーホストを定住版に進化させたモデルです。

**プラットフォーム上にストーリーが蓄積すればするほど、参入障壁が高くなります。**」

## スライド 9: リスクと対策

### スライドコンテンツ

```
主なリスクと対策

❶ 鶏と卵問題（供給不足）
  → Phase Aは手動マッチング + 紹介フィー¥3,000/件で管理会社を動かす
  → 最初の20件は自分で営業

❷ 法的リスク（宅建業法）
  → tsumugiはマッチングのみ。賃貸契約は宅建業者が締結
  → 弁護士レビュー済みの利用規約で対応

❸ 大家の抵抗
  → 大家協力金（引越し費用の1%）+ 残置物トラブルゼロの実績

❹ 収益が想定以下
  → 固定費¥250/月。赤字額は極めて限定的
  → 5ヶ月で初期投資（¥70,000）を回収可能
```

### プレゼンテーションスクリプト

「正直にリスクもお伝えします。

最大のリスクは**鶏と卵問題**。物件がなければ次の住人は来ない。次の住人がいなければ前の住人は出品しない。

対策として、Phase Aでは管理会社に1件あたり3,000円の紹介フィーを払い、協力を取り付けます。最初の20件は自分の足で営業します。

法的リスクについては、tsumugiはマッチングの場を提供するだけで、賃貸契約の締結は宅建業者が行います。メルカリが売買の場を提供するのと同じ構造です。利用規約は弁護士にレビュー依頼済みです。

大家の抵抗については、協力金という形でインセンティブを設計しました。さらに、残置物トラブルがなくなるメリットを定量的に説明します。

最後に、収益が想定を下回った場合。固定費が月250円なので、赤字額は極めて限定的です。月1件でも黒字。**資金が尽きる前に撤退を迫られるリスクがほぼゼロ**なのが、このビジネスの構造的な強みです。」

### ビジュアル指示

- リスクを左、対策を右に対比
- リスクは赤系、対策は緑系
- 固定費の低さを強調
- シンプル、読みやすく

### プレゼンテーションスクリプト

「お金の話ではありません。このビジネスは5万円で始められます。

私が本当に必要としているのは、**経験と繋がり**です。

## 想定Q&A

### Q1. 宅建業法に抵触しないの？

**A:** tsumugiはマッチングの場を提供するだけです。賃貸借契約の締結は宅建業者が行います。tsumugiが行うのは「物件情報の掲示」と「引き合わせ」のみ。メルカリが売買仲介ではなく「場の提供」であるのと同じ構造です。弁護士にも確認済みです。

### Q2. 大家が嫌がるのでは？

**A:** 大家にとってのメリットは3つ。(1) 残置物トラブルがなくなる、(2) 空室期間が短縮される（前の住人が次の住人を見つけてくる）、(3) 大家協力金（引越し費用の1%）が入る。実際に大家のペインは「残置物処理」が大きいので、それが解消されるだけで十分な動機になります。

### Q3. メルカリやジモティーで十分では？

**A:** 家具1点の移動と、暮らしの世界観の引き継ぎは本質的に違います。メルカリでソファを買っても「暮らし」にはなりません。照明の位置、ラグの色合い、植物の配置——空間の世界観は個別の家具では再現できません。tsumugiは「空間まるごと」を引き継ぐ唯一のサービスです。

### Q4. 最初のユーザーはどう獲得する？

**A:** Phase Aは3つのチャネル。(1) 管理会社に紹介フィー3,000円/成約を払い、退去予定の住人にtsumugiを紹介してもらう。(2) SNS（Instagram、X）で引越し予定の個人にリーチ。(3) 自分自身のネットワーク。最初の20件は手動で、自分がつきっきりでサポートします。

### Q5. 引越し費用の適正価格はどう決める？

**A:** 前の住人が自由に設定します。中古家具市場の相場（5-10万円）に、撤去費用の回避価値（20-40万円）と空間の世界観の価値を加味して、10-20万円の範囲に収まると想定しています。市場の価格発見メカニズムに任せつつ、運営側で「著しく高額な場合は介入する」ガイドラインを設けます。

### Q6. スケールの天井は？

**A:** 引越し市場は年間520万件で安定しています。成長の制約は市場規模ではなく、供給側（出品物件数）です。これは管理会社との提携で加速できます。さらに長期的には「暮らしのキュレーター」が供給を安定的に生み出す構造を目指しています。
