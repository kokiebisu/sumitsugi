## スライド 3: sumitsugiとは

### スライドコンテンツ

```
sumitsugiの仕組み（30秒で分かる）

退去者の家具・インテリア
      ↓ そのまま残る
次の入居者が引き継ぐ

御社の役割:
  「家具付きですぐ住める物件、ありますよ」
  と紹介するだけ

賃貸借契約は従来通り御社が仲介
家具の引き継ぎだけsumitsugiが管理
```

### プレゼンテーションスクリプト

「sumitsugiは、退去する住人の家具やインテリアを、次の入居者にそのまま引き継ぐプラットフォームです。

仲介会社さんにお願いしたいのは、お客さんに『家具付きですぐ住める物件、ありますよ』と紹介すること。これだけです。

賃貸借契約は従来通り御社が仲介。家具の引き継ぎ部分だけsumitsugiが管理します。**御社の業務フローは何も変わりません。**新しい営業ツールが1つ増えるだけです。」

### ビジュアル指示

- シンプルなフロー図
- 「御社の業務フローは変わらない」を強調
- 仲介会社の役割をミニマルに表現

## スライド 4: 仲介会社の3つのメリット

### スライドコンテンツ

```
仲介会社にとっての3つのメリット

1. 他社にない物件で差別化
   「家具付き、即入居OK」
   → SUUMO・HOME'Sにはない切り口
   → 御社を選ぶ理由ができる

2. 成約率が上がる
   初期費用が大幅ダウン（家具代30〜50万円が不要）
   → 内見で完成された空間を見せられる
   → 「ここに住みたい」が生まれやすい

3. 新しい客層が取れる
   外国人 → 家具付き最優先
   短期転勤 → 数ヶ月で引っ越すのに家具買いたくない
   若年層 → 初期費用を抑えたい
```

### プレゼンテーションスクリプト

「仲介会社さんにとっての具体的なメリットを3つ、お伝えします。

1つ目、**差別化**。『家具付きで、すぐ住めます』——この一言だけで、他社との差が生まれます。SUUMOやHOME'Sでは見つからない、御社だけの物件です。お客さんが御社を選ぶ明確な理由になります。

2つ目、**成約率**。内見で何もない空っぽの部屋を見せるのと、家具が揃った完成された空間を見せるのでは、お客さんの反応が全然違います。しかも初期費用から家具代30万〜50万円がなくなる。『ここに住みたい』が生まれやすくなります。

3つ目、**新しい客層**。外国人は家具付きが最優先条件。短期転勤者は数ヶ月で引っ越すのに家具を買いたくない。若年層は初期費用を抑えたい。こうした方々は、従来の空室物件では取りこぼしていました。sumitsugi物件なら応えられます。」

### ビジュアル指示

- 3つの大きなブロック
- メリット1「差別化」を最も大きく
- ターゲット客層をアイコンで

## スライド 5: 物件の紹介イメージ

### スライドコンテンツ

```
お客さんへの紹介トーク例

営業:「初期費用、気になりますよね。
      実は、家具付きですぐ住める物件があるんです」

客: 「え、そんなのあるんですか？」

営業:「前の住人さんが使っていたインテリアを
      そのまま引き継げる仕組みです。
      引越し費用は10〜20万円だけ。
      家具を揃える30〜50万円が丸々浮きます」

客: 「見てみたい！」

━━━━━━━━━━━━

ポイント: 内見時に前の住人が暮らしを直接案内
→ 不動産屋にはできない、暮らしのリアルが伝わる
```

### プレゼンテーションスクリプト

「実際に御社の営業さんがどう使うか、イメージしてみてください。

お客さんに『初期費用が気になる...』と言われた時。『実は、家具付きですぐ住める物件があるんです』と言えたら、どうなりますか？お客さんの目が変わりますよね。

『前の住人が使っていたインテリアをそのまま引き継げる仕組みです。引越し費用は10万〜20万円だけ。家具を揃える30万〜50万円が丸々浮きます。』

さらに、sumitsugiの内見では**前の住人が直接、暮らしを案内**します。『このソファで朝コーヒー飲むのが最高で』とか、『夏はこの窓を開けると風通しがいいですよ』とか。営業マンでは伝えられない、暮らしのリアルが伝わります。」

### ビジュアル指示

- 会話形式のレイアウト
- 営業トークのイメージが湧くデザイン
- 「30〜50万円が浮く」を大きく

## スライド 6: sumitsugiとの連携フロー

### スライドコンテンツ

```
仲介会社の業務フロー

1. sumitsugiからエリア内の物件リストを受け取る
   → 「家具付き即入居」物件をラインナップに追加

2. お客さんに紹介
   → 「家具付きですぐ住めます」で差別化

3. 内見調整（sumitsugiがサポート）
   → 前の住人が暮らしを案内

4. 賃貸借契約は従来通り御社が仲介
   → 業務フロー変更なし

5. 家具の引き継ぎはsumitsugiが管理
   → 同意書・決済・引き継ぎ確認

御社の追加作業: ほぼゼロ
```

### プレゼンテーションスクリプト

「連携フローはシンプルです。

まず、sumitsugiからエリア内の引き継ぎ可能物件リストをお渡しします。これを御社のラインナップに追加してください。

お客さんに紹介する時は、『家具付きで、すぐ住めます』と伝えるだけ。

内見の調整はsumitsugiがサポートします。前の住人が直接案内する特別な内見です。

賃貸借契約は従来通り御社が仲介。何も変わりません。

家具の引き継ぎに関する同意書、決済、引き継ぎ確認——こうした部分はsumitsugiが全て管理します。

**御社の追加作業はほぼゼロ。紹介できる物件が増えるだけです。**」

### ビジュアル指示

- 5ステップのフロー図
- 御社の作業とsumitsugiの作業を色分け
- 「追加作業ほぼゼロ」を大きく

sumitsugi物件なら、家具代ゼロ。引越し費用は10万〜20万円。初期費用トータルは大幅に下がります。入居後すぐに完成された空間で暮らせます。

こうした条件に特に刺さるのが、年間30万人の来日外国人、1〜3年の短期転勤者、初期費用がハードルの20代単身者。こうした方々が御社の新しい客層になります。」

## スライド 8: よくある質問

### スライドコンテンツ

```
よくある質問

Q. 宅建業法に抵触しない？
A. sumitsugiは家具の引き継ぎ（動産売買）のみ。
   賃貸借契約は宅建業者（御社）が従来通り仲介。

Q. 仲介手数料は変わる？
A. 変わりません。従来通りです。
   sumitsugiの収益は引越し費用の手数料から。

Q. 大家や管理会社が嫌がらない？
A. 大家: 空室短縮 + 協力金¥3,000
   管理会社: 残置物解消 + 1件¥11,000の収入
   むしろ歓迎されます。

Q. 物件数はどれくらい？
A. 立ち上げ期なので、エリア・時期で変動。
   まずはリストをご覧ください。
```

### プレゼンテーションスクリプト

「よくある質問にお答えします。

『宅建業法に抵触しませんか？』しません。sumitsugiが関与するのは家具の引き継ぎ——動産の個人間売買——のみです。賃貸借契約は御社が従来通り仲介します。法的な線引きは明確です。

『仲介手数料はどうなりますか？』変わりません。従来通りです。sumitsugiの収益は引越し費用に含まれる手数料からですので、御社の収益に影響はありません。

『大家や管理会社が嫌がりませんか？』大家さんには空室短縮と協力金のメリットがあります。管理会社さんには残置物トラブル解消と1件11,000円の収入があります。実際、むしろ歓迎されています。」

### ビジュアル指示

- Q&A形式、シンプル
- 「宅建業法」を最初に（最大の懸念を先に解消）
- 「仲介手数料は変わらない」を強調
