そして、引越し当日からすぐに住めます。

初期費用を抑えられる。すぐに使える。環境にも優しい。

あなたにも、地球にも、優しい選択です。」

- 3ステップをシンプルに

## スライド 5: 経済的メリット

### スライドコンテンツ

```
従来 vs tsumugi（例）

【従来】
家具購入   -40万円
引越し業者 -8万円
━━━━━━━━
合計      -48万円

【tsumugi】
引越し費用 -15万円
引越し業者 -8万円
━━━━━━━━
合計      -23万円

差額: 10〜30万円の節約

※物件・家具により異なります
```

### プレゼンテーションスクリプト

「具体的な数字で見てみましょう。例えば、1LDKの場合です。

従来の引越しでは、家具購入に30万円から50万円、引越し業者に8万円。合計38万円から58万円です。

tsumugiを使うと、引越し費用10万円から20万円、引越し業者8万円。合計18万円から28万円です。

差額は10万円から30万円の節約。これだけあれば、旅行に行けますよね。新しい家具を買い足すこともできます。

もちろん、金額は物件や家具の充実度によって異なりますが、大幅な節約効果があります。」

**[ここで電卓を使って一緒に計算してもOK]**

### ビジュアル指示
- Before/After比較表（左右2列）
- 赤色（従来）→ 緑色（tsumugi）
- 「25万円」を特大フォントで

## スライド 7: 安心の仕組み

### スライドコンテンツ

```
3つの安心

🔒 エスクロー決済
📄 残置物同意書
✓ 引き継ぎ確認
```

### プレゼンテーションスクリプト

「でも、『思ってたのと違ったらどうしよう』と心配ですよね。tsumugiには3つの安心があります。

1つ目、エスクロー決済。引越し費用は、引き継ぎが完了するまで安全に預かります。

2つ目、残置物同意書。法的にも安心です。所有権はあなたに移転します。

3つ目、引き継ぎ確認。入居後、家具の状態を確認してから『引き継ぎ完了』を押します。納得してから支払いが確定します。」

### ビジュアル指示
- 3つのアイコン（盾、契約書、チェックマーク）
- シンプル、クリーン
- アイコンを大きく

## 追加資料: プレゼンテーションのコツ

### 対面で話す場合（5-7分）

**導入（30秒）**
- 自己紹介
- 「新生活、ワクワクしますよね」

**ストーリー（1分）**
- スライド2: 新生活の期待と現実
- 共感を引き出す

**課題共有（1分）**
- スライド3: 「同じ悩みありませんか？」と問いかけ
- 相手のうなずきを確認

**解決策（2分）**
- スライド4-5: シンプルに説明、数字で納得させる
- 質問を促す

**実例（1分）**
- スライド6: 具体的な物件を見せる
- 想像させる

**安心感（1分）**
- スライド7: 不安を先回りして解消

**CTA（1分）**
- スライド8: 「まずは登録してみませんか？」
- ハードルを下げる

**Q&A（1-2分）**
- その場で出た質問に対応

### オンラインで話す場合（3-5分）

- スライドを共有
- スライド1-2-4-5-6-8の6枚に絞る
- 簡潔に、テンポよく
