## スライド 3: 課題

```
新生活の悩み

✗ 家具購入 30〜50万円
✗ 「暮らし」になるまで何年もかかる
✗ 既製品だけでは世界観が作れない
✗ 短期間で引越す予定なのに...

レンタル家具 ≠ 暮らしの空間
```

### プレゼンテーションスクリプト

「新生活の悩み、ありませんか？

でもお金を払えば解決するかというと、そうでもない。IKEAやニトリで家具を買っても、**居心地のいい暮らしの空間**になるまでには何年もかかります。照明の色、ラグのサイズ、棚の位置——全部を自分で試行錯誤する時間が必要です。

レンタル家具？パーツは揃いますが、空間にはなりません。

短期間で引越す予定なら、なおさら高い家具を買うのはためらいますよね。

そもそも、**本当に必要なのは家具じゃなくて、暮らしの空間そのもの**なんです。」

**[ここで相手の共感を確認]**

- 最下部「レンタル家具 ≠ 暮らしの空間」を強調
- シンプルなレイアウト

## スライド 4: ポジショニング

### スライドコンテンツ

```
暮らしの世界観は、家具だけじゃ作れない

レンタル家具  → パーツの一時貸し
ステージング  → 見せかけの空間演出
sumitsugi      → 本物の暮らしの引き継ぎ
               モノ＋世界観＋ストーリー
```

### プレゼンテーションスクリプト

「ここで整理しますね。似たサービスとの違いです。

レンタル家具は便利です。でも、ソファ1つ、テーブル1つ——パーツの寄せ集めで、空間にはなりません。月額1〜2万円で、12ヶ月借りると12万円から24万円。意外と高い上に、返す時は結局空っぽです。

ホームステージングは、不動産を売るために用意された見せかけの空間です。誰の暮らしでもない。

sumitsugiは違います。**誰かが実際に暮らした空間を、そのまま引き継ぐ。** 家具だけじゃなくて、照明の配置、ラグの敷き方、植物の置き場所——暮らしの世界観ごと受け取れます。本物の暮らしだからこそ、引越した日から居心地がいい。」

### ビジュアル指示

- 3段の比較表（上2つはグレーアウト、sumitsugiのみカラー）
- sumitsugiの行にコーラル色のハイライト
- 「本物の暮らし」を強調

## スライド 5: 解決策

### スライドコンテンツ

```
sumitsugiの仕組み

1. 物件を探す（暮らしの世界観で選ぶ）
   ↓
2. 内見（前の住人が暮らしを案内）
   ↓
3. 申込金¥20,000で予約
   ↓
4. 引き継ぎ → 残額支払い → すぐ住める

━━━━━━━━━━━━

完成された空間 ✓
初日から居心地がいい ✓
初期費用を大幅削減 ✓
```

### プレゼンテーションスクリプト

「sumitsugiなら、暮らしの世界観を引き継げます。

まず、物件を探します。普通の不動産サイトと違って、部屋のスペックだけじゃなくて**前の住人がどんな暮らしをしていたか**が分かります。

次に、内見。ここがsumitsugiの一番の特徴です。**前の住人が直接、暮らしを案内してくれます。** 『このソファで朝コーヒーを飲むのが最高で』『この棚はこう使うと便利で』——不動産屋にはできない、暮らしのストーリーを聞けます。

気に入ったら、申込金2万円で予約。いきなり全額じゃないので安心です。

引き継ぎが完了したら残額を支払い。**引越した日から、完成された空間で暮らせます。**」

### ビジュアル指示

- フロー図（上から下へ）
- ステップ2「前の住人が案内」をハイライト（差別化ポイント）
- ステップ3「申込金¥20,000」を目立たせる（低いハードル）
- 3つのメリットを強調

```

━━━━━━━━
合計      -48万円

【sumitsugi】
引越し費用 -15万円
引越し業者 -8万円
━━━━━━━━
合計      -23万円

差額: 10〜30万円の節約
申込金¥20,000から始められる

※物件・家具により異なります
```

### プレゼンテーションスクリプト

「経済的なメリットも大きいです。

例えば1LDKの場合。従来の引越しでは、家具購入に30万円から50万円、引越し業者に8万円。合計38万円から58万円です。しかもそれで手に入るのは、まだ『暮らし』になっていない家具の寄せ集めです。

sumitsugiを使うと、引越し費用10万円から20万円、引越し業者8万円。合計18万円から28万円。**しかも初日から完成された暮らしの空間で過ごせます。**

差額は10万円から30万円の節約。しかもまず**申込金2万円で予約できる**ので、いきなり大きな出費はありません。

安いだけじゃなくて、圧倒的に良い空間が手に入る。コスパの次元が違います。」

### ビジュアル指示

- Before/After比較表（左右2列）
- 赤色（従来: 「家具の寄せ集め」）→ 緑色（sumitsugi: 「完成された空間」）
- 「申込金¥20,000」を強調

## 追加資料: プレゼンテーションのコツ

### 対面で話す場合（5-7分）

**導入（30秒）**

- 自己紹介
- 「新生活、ワクワクしますよね」

**ストーリー（1分）**

- スライド2: 「ゼロからは大変」の共感
- 「暮らしになるまでの時間」を強調

**課題共有（1分）**

- スライド3: 「同じ悩みありませんか？」と問いかけ
- 相手のうなずきを確認

**差別化（30秒）**

- スライド4: ポジショニング表をさっと見せる
- 「レンタル家具とは全然違います」

**解決策（1.5分）**

- スライド5: フローを説明
- **「前の住人が暮らしを案内」**を強調

**経済メリット（1分）**

- スライド6: 数字で納得させる
- 「申込金2万円から」を添える

**実例（1分）**

- スライド7: 具体的な物件を見せる
- 前の住人のストーリーで想像させる

**安心感（30秒）**

- スライド8: 不安を先回りして解消

**CTA（30秒）**

- スライド9: 「まずは登録してみませんか？」
- ハードルを下げる

**Q&A（1-2分）**

- その場で出た質問に対応
