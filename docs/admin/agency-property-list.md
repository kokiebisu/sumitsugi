# エリア別物件リスト生成（仲介会社向け）

> Feature ID: F-617 | Phase: A (Manual) | Priority: P1

## 概要

仲介会社のエリアに合わせたsumitsugi物件リストを生成し、定期的に共有するための機能です。

Phase Aでは手動でスプレッドシート形式で共有します（将来的にはAPI化: F-606）。

## 使い方

### 特定エリアの物件リストを生成

```bash
bun scripts/generate-agency-property-list.ts 東京
```

出力: CSV形式（スプレッドシートに貼り付け可能）

### 全エリアの物件リストを生成

```bash
bun scripts/generate-agency-property-list.ts --all
```

### ファイルに保存

```bash
bun scripts/generate-agency-property-list.ts 東京 > tokyo-properties.csv
```

## 含まれる情報

| 項目       | 説明                              |
| ---------- | --------------------------------- |
| 物件名     | 物件のタイトル                    |
| エリア     | 物件の所在エリア                  |
| 間取り     | 1K、1LDK など                     |
| 家具一覧   | 引き継ぎ対象の家具リスト          |
| 引越し費用 | 次の住人の負担額（引き継ぎ費用）  |
| 入居可能日 | 入居可能開始日                    |
| 即入居可能 | ✓マークで即入居可能物件を強調表示 |

## 「即入居可能」の定義

入居可能日が **14日以内** の物件に自動的に「✓ 即入居可能」フラグが付きます。

## 共有フロー（Phase A）

1. **週次または物件追加時**に該当エリアのリストを生成
2. スプレッドシートにコピー＆ペースト
3. 仲介会社にメールで共有
4. 「即入居可能」物件を目立たせる（例: 行を黄色でハイライト）

## 対象物件

- ステータスが `public` の物件のみ
- `draft` ステータスの物件は含まれません

## 例: スプレッドシート形式

```
物件名                           | エリア | 間取り | 家具一覧                | 引越し費用 | 入居可能日      | 即入居可能
--------------------------------|--------|--------|------------------------|-----------|----------------|------------
アートと植物に囲まれた...        | 東京   | 1K     | ベッド、デスク、...     | 60,000    | 2026年3月1日〜  |
DJ/プロデューサーの...           | 東京   | 1LDK   | DJ機材、ベッド、...     | 60,000    | 2026年3月15日〜 |
浅草の静かな隠れ家ホテル         | 東京   | 1K     | ベッド、デスク、...     | 50,000    | 2026年5月15日〜 |
```
