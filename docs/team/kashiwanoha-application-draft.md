## 1. プロジェクト概要

### tsumugiとは

tsumugiは、**退去する住人の暮らしを次の住人へ引き継ぐプラットフォーム**です。

賃貸住宅の退去時に発生する家具・インテリアの廃棄問題に着目し、「引越し」を「引き継ぎ」に変えるサービスを提供します。前の住人が作り上げた空間を、家具・インテリアごと次の住人へ譲渡することで、廃棄物の削減と入居者の初期費用軽減を同時に実現します。

**タグライン:** 「暮らしを、紡ぐ。」

### サービスの仕組み

1. **前の住人**が退去予定の物件情報と引き継ぎ可能な家具を登録
2. **次の住人**が気に入った物件を閲覧し、内見を申し込み
3. 内見時に家具の状態を確認し、引き継ぎ条件を合意
4. プラットフォーム上で決済・合意書を締結
5. 管理会社の清掃・点検を経て、暮らしの引き継ぎが完了

tsumugiは「マッチングの場」を提供し、賃貸借契約の締結は宅建業者が行います。法的に正しいフローを維持しながら、入居者同士の新しいつながりを生み出します。

## 2. 解決する社会課題

### 家具廃棄問題の深刻さ

日本では毎年、引越しに伴い大量の家具・インテリアが廃棄されています。

- **年間約700万件**の引越しが発生（総務省統計）
- 退去時に家具の多くが粗大ごみとして処分される
- 大型家具（冷蔵庫、洗濯機、ベッドフレーム等）の廃棄は環境負荷が大きい
- 自治体の粗大ごみ処理コストも増大

### なぜこの問題が解決されていないのか

- 退去者と入居者は通常、接点がない
- 管理会社は原状回復を優先し、残置物は撤去対象
- 既存の中古家具市場（メルカリ等）では大型家具の配送コストが高く、現実的でない
- 引越しのタイミングが合わず、譲渡の機会が生まれにくい

### tsumugiのアプローチ：同じ物件だからこそできる引き継ぎ

tsumugiは「同じ物件の前後の住人」をマッチングすることで、配送不要の家具引き継ぎを実現します。家具はその場所に最適化されたサイズ・配置のまま、次の住人へ渡ります。

**SDG #12「つくる責任 つかう責任」への貢献:**

- 家具の廃棄量を削減（リユースの促進）
- 新品購入の抑制による資源消費の低減
- 循環型社会の実現に向けた新しい消費モデルの提案

| 新産業創造の観点       | tsumugiの貢献                                        |

| 管理会社のDX           | 残置物処理の効率化、入居者満足度の可視化             |

## 5. 柏の葉スマートシティとの親和性

### なぜ柏の葉なのか

柏の葉スマートシティは、tsumugiにとって理想的な実証フィールドです。

**1. 住民の入れ替わりが自然に発生する環境**

柏の葉エリアは、つくばエクスプレス沿線の発展に伴い、若いファミリー層や研究者・ビジネスパーソンの転入出が活発です。退去時の家具廃棄と入居時の家具購入という「二重のコスト」が日常的に発生しており、tsumugiの需要が自然に存在します。

**2. スマートシティの住民が求めるサステナブルな暮らし**

柏の葉スマートシティの住民は、環境共生やイノベーションに対する感度が高く、tsumugiの「暮らしの引き継ぎ」というコンセプトに共感いただきやすい層です。

**3. 三井不動産の管理物件での実証**

三井不動産が開発・管理する物件で実証実験を行えれば、管理会社連携フローの検証が一気に進みます。tsumugiは管理会社の作業負担を段階的に削減する仕組みを設計しており（Phase A: 資料提供で30分/件まで削減）、実地での検証が不可欠です。

**4. コミュニティ基盤の活用**

柏の葉には既にKOIL（柏の葉オープンイノベーションラボ）やUDCK（アーバンデザインセンター柏の葉）といったコミュニティ拠点があります。住民同士のつながりが既に存在するエリアでこそ、「暮らしの引き継ぎ」は文化として根付きやすいと考えています。

### 柏の葉での実装イメージ

```
Phase 1: 柏の葉エリア限定でベータ版を公開
         ↓
Phase 2: 三井不動産管理物件で実証実験（5-10件）
         ↓
Phase 3: 柏の葉全域に展開、他のスマートシティへ横展開
```

## 8. ビジネスモデル

### 収益構造

tsumugiの収益は、引き継ぎ成立時のプラットフォーム手数料です。

**引越し費用の分配（例：¥100,000の場合）:**

| 宛先                     | 金額                     | 性質                   |
| ------------------------ | ------------------------ | ---------------------- |
| 前の住人                 | ¥74,000                  | 家具・暮らしの対価     |
| tsumugi                  | ¥15,000（15%）           | プラットフォーム手数料 |
| 清掃業者（管理会社経由） | ¥8,000                   | 家具の追加クリーニング |
| 大家                     | ¥3,000（1%、最低¥3,000） | 協力金                 |

### 関係者全員にメリットがある設計

| ステークホルダー     | メリット                                           |
| -------------------- | -------------------------------------------------- |
| **前の住人**         | 家具の処分費用がゼロになり、さらに対価を受け取れる |
| **次の住人**         | 新品購入より安く、配送の手間なく家具が手に入る     |
| **大家・管理会社**   | 空室期間の短縮、協力金収入、入居者満足度の向上     |
| **環境**             | 家具廃棄量の削減、CO2排出の回避                    |
| **地域コミュニティ** | 住人同士のつながりが生まれ、地域の定着率が向上     |

### スケーラビリティ

- **Phase A（立ち上げ期）:** 月2-3成約、管理会社への紹介フィーあり
- **Phase B（成長期）:** 月5-8成約、管理会社連携の一部自動化
- **Phase C（成熟期）:** 月10件以上、紹介フィー廃止、管理会社のDXプラットフォームへ進化

### 市場規模

- 日本の賃貸住宅市場：約1,900万世帯
- 年間引越し件数：約700万件
- 家具付き引き継ぎの潜在需要：保守的に見ても年間数十万件規模
