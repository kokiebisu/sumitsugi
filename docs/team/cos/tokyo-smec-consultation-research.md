## エグゼクティブサマリー

東京都中小企業振興公社が提供する無料の経営相談・法律相談サービス。都内の中小企業・個人事業主・創業予定者が対象。sumitsugiはプレローンチフェーズで法務・経営課題を抱えており、**無料で専門家に相談できる貴重なリソース**として活用価値が高い。

---

## 1. サービス概要

### 提供される相談サービス

| 相談種別     | 内容                                   |
| ------------ | -------------------------------------- |
| **経営相談** | 事業計画、資金調達、マーケティング等   |
| **法律相談** | 契約書、利用規約、特商法、知的財産権等 |

### 実施拠点

| 拠点     | エリア                       |
| -------- | ---------------------------- |

| 城南支社 | 大田区（世田谷区周辺）       |
| 多摩支社 | 八王子市周辺                 |

## 2. 予約システムの仕様

### 予約可能期間・制限

| 項目             | 詳細                                      |
| ---------------- | ----------------------------------------- |
| **予約可能期間** | 60日前〜前日17時まで                      |
| **当日変更**     | 各相談窓口に電話で連絡                    |
| **予約上限**     | 法律相談1件 + 経営相談3件まで同時予約可能 |
| **初回利用**     | システム利用登録が必須                    |

### 利用フロー

1. 利用者登録（初回のみ）
2. 相談員プロフィール確認（各専門分野を事前確認可能）
3. 予約申込
4. 予約確認
5. 相談当日（必要資料を持参）

## 4. sumitsugiにとっての活用価値

### 4-1. 現在の課題とマッチング

| sumitsugiの課題                | 相談可能な専門家           | 優先度 |
| ------------------------------ | -------------------------- | ------ |
| プライバシーポリシー作成       | 法律相談（IT法務）         | **P0** |
| 特定商取引法に基づく表記       | 法律相談（消費者法）       | **P0** |
| 利用規約の最終確認             | 法律相談（契約法）         | **P1** |
| 引越し費用の法的整理           | 法律相談（契約法）         | **P1** |
| 管理会社営業戦略               | 経営相談（マーケティング） | P2     |
| 資金調達・補助金活用アドバイス | 経営相談（財務）           | P2     |

### 4-2. メリット

1. **コスト¥0** — 無料で専門家にアクセス可能
2. **公的信頼性** — 東京都の支援機関による専門家紹介
3. **複数回利用可能** — 法律1件+経営3件を同時予約可能
4. **事前準備可能** — 相談員プロフィールで専門分野を確認してから予約できる

### 4-3. デメリット・制約

1. **事前資料準備が必要** — 資料の事前レビューはなく、当日持参のみ
2. **助言のみ** — 「意思決定のための助言」であり、最終判断は自己責任
3. **専門分野の確認必須** — 相談員ごとに専門分野が異なるため、事前確認が重要

## 9. 結論

東京都中小企業振興公社のワンストップ総合相談は、sumitsugiの現在のブロッカー（法務関連ドキュメント未作成）を**無料で解決できる可能性がある極めて有用なリソース**である。

特にプライバシーポリシーと特商法表記は外部弁護士への有料相談を検討していたが、まず無料の公的支援を活用することで、コストを抑えつつ専門家の助言を得られる。

**CoS推奨: 即座に利用者登録を行い、法律相談（IT法務専門）を予約すること。ベータローンチに向けた法務ブロッカー解消の最優先アクションとする。**
