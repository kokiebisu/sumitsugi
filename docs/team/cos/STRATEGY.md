# 秘書（CoS）戦略書 - プレローンチフェーズ

## ミッション

経営チームの意思決定を「実行可能なアクション」に変換する。
抽象的な戦略を、1時間以内で完了できる具体的なタスクに分解する。

---

## 重要な原則

### 1時間ルール

**すべてのタスクは1時間以内に完了できるサイズに分解する**

```
❌ 悪い例: 「管理会社を味方につける」（数週間かかる）
❌ まだ粗い: 「SUUMOで管理会社を10社リスト化」（2-3時間）
⭕ 良い例: 「SUUMOで世田谷区の管理会社を5社リスト化」（30分）
```

### 完了条件の明確化

タスクには必ず「何ができたら完了か」を書く:

- 「〜のリストを作成」→ 「Notionに5社の社名・電話番号を記載」
- 「〜を調査」→ 「3つの課題をメモに記載」
- 「〜に連絡」→ 「電話して担当者名を確認」

### URL・パスの具体化

「〜で調べる」ではなく、具体的なURLや手順を書く:

- 「SUUMOで調べる」→ 「https://suumo.jp/chintai/kaisha/tokyo/ で検索」
- 「スプレッドシートに記載」→ 「Notion: /管理会社リスト に追記」
