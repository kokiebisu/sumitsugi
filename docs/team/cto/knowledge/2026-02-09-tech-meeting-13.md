# CTO Knowledge - 技術会議決定事項（2026-02-09、技術会議#13）

## 会議概要

技術制約ミーティング（CPO + CTO + CAIO）にて、プロダクトミーティング#14（全9テーマ座談会最終確認）の技術的フィージビリティ検証を実施。全8項目が既存アーキテクチャ内で対応可能と判定。新規T-N技術決定なし。

## 主要決定

### Google OAuth → Post-MVP（大株主承認済み）

**理由:**

- Better-auth Magic Linkが「パスワード不要」要件を既に解決
- ペルソナの本質的ニーズ（手軽さ）はMagic Linkで充足
- Google Cloud Console設定、OAuth consent screen審査、プライバシーポリシー更新の隠れコスト
- MVP規模ではログイン離脱率の統計的検証が不可能

**判断基準:** Post-MVPでログイン離脱率データを取得、20%超ならGoogle OAuth追加（工数0.5日）

### CAIO推奨データ設計追加（Phase 0に含める）

将来AI活用の「種まき」として、追加工数半日未満で以下を追加:

1. **tasteCategory**: propertiesテーブルにenum型カラム追加（将来AIマッチング用特徴量）
2. **userPreferences**: inquiriesテーブルにJSONBフィールド追加（将来AI学習データ蓄積）
3. **画像メタデータ**: R2アップロード時にメタデータ保存（将来画像認識用、追加コストゼロ）
