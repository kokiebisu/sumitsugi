# CTO Knowledge - 技術会議決定事項（2026-02-11、技術会議#14）

## 会議概要

技術制約ミーティング（CPO + CTO + CAIO + 大株主）にて、プロダクトミーティング#14・#15の技術引き継ぎ事項のフィージビリティ検証を実施。加えて大株主から画像アップロードアーキテクチャの改善指示あり。

## 主要決定

### T-9: 画像アップロード遅延化 + R2削除機能（大株主指示）

**問題:**

- 現状の出品フォームで画像選択時に即座にR2アップロードされる
- ダイアログキャンセル時に孤児ファイルが発生
- 画像変更・削除時にR2からファイルが削除されない

**決定:**

1. 遅延アップロード: ファイル選択時はローカルプレビューのみ、確認ボタンで初めてR2アップロード
2. `storage.ts`に`deleteImage`/`deleteImages`関数を追加（`DeleteObjectCommand`使用）
3. DELETE `/api/upload`エンドポイント新設
4. 物件編集時に旧画像 vs 新画像を比較し、除外された画像を自動削除

**工数:** 1日

### F-504: P0 → P1（Post-MVP）に変更

コンシェルジュ型MVP方針との整合。運営が手動プッシュで代替。自動化は手動運用データ収集後。

## 技術的学び

- 画像のライフサイクル管理（アップロード/削除）は早期に正しく設計すべき
- 「ユーザーが確定するまでサーバーリソースを消費しない」原則は他のリソース管理にも適用可能
- `DeleteObjectCommand`は既存S3クライアント設定で対応可能、追加の認証設定不要
