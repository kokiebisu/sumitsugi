## 技術観点での重要ポイント

### 優先実装機能

**内見負担軽減（ユキ向け）**

| 機能                       | 優先度 | 技術要件                           |
| -------------------------- | ------ | ---------------------------------- |
| FAQ機能                    | ★★★    | テンプレートDB、メッセージング連携 |
| 内見希望者プロフィール表示 | ★★★    | ユーザー認証、プロフィール管理     |
| 動画ツアー機能             | ★★     | 動画アップロード、ストリーミング   |
| メッセージング             | ★★     | リアルタイム通信、通知             |

**管理会社向け（佐藤さん向け）**

| 機能                   | 優先度 | 技術要件           |
| ---------------------- | ------ | ------------------ |
| 承認フロー（シンプル） | ★★★    | ワークフロー、通知 |
| オーナー説明資料生成   | ★★★    | PDF生成            |
| 責任分界点の明示       | ★★★    | UI/UX設計          |

**コーディネーター向け（マリ向け）**

| 機能                         | 優先度 | 技術要件         |
| ---------------------------- | ------ | ---------------- |
| コーディネーター・クレジット | ★★     | プロフィール連携 |
| プロがコーディネート・バッジ | ★★     | 認証システム     |

### システム設計考慮

1. **責任分界点の明確化**
   - 家具の問題 → tsumugi
   - 物件の問題 → 管理会社
   - システム上でも明確に分離

2. **5者連携フロー**
   - 前の住人 → 次の住人（tsumugi内）
   - 管理会社 → 大家（承認フロー）
   - 仲介会社（外部連携、将来）
