# 役員会議 #3 からの学び（CEO）

**日時:** 2026-02-10

## キーインサイト

### ビジネスコンテスト・アクセラレーターのスカウト

- 大株主が柏の葉イノベーションフェス「ハツメイノハ」を発見
- イベントスカウト対象にコンテスト・アクセラレーターカテゴリが不足していた
- 三井不動産レベルの企業主催コンテストは、接点構築の最短ルート

### スカウト対象の拡大

| カテゴリ（従来）       | 追加カテゴリ                     |
| ---------------------- | -------------------------------- |
| VC系、ピッチ系         | ビジネスアイデアコンテスト       |
| マーケ・コミュニティ系 | アクセラレーター・インキュベーター |
| 不動産テック系         | 不動産デベロッパー主催プログラム |
| 法務・規制系           | スマートシティ関連公募           |

### 三井不動産との接点の価値

- 日本最大級の不動産デベロッパー
- 柏の葉スマートシティを運営
- 管理物件でのtsumugi実証 = パートナーシップ構築の理想的な入り口
- KOIL STARTUP PROGRAMへの接続で最大500万円の補助金可能性

### 判断基準の更新

- **新ルール:** イベントスカウト時、「ビジネスコンテスト」「アクセラレーター」「スマートシティ公募」も対象に含める
- **新ルール:** 不動産デベロッパー主催のプログラムは最優先でスカウト
