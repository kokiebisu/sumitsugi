## 状況

入居者対応、退去立会い、オーナー報告、新規募集...毎日バタバタ。

「また仕事増えるの？」が正直な気持ち。でも、空室が長いとオーナーからプレッシャーがかかるのも事実。

---

## 佐藤さんの日常

```
【典型的な1日】

9:00  出社、メール確認（入居者からのクレーム3件）
10:00 退去立会い（原状回復のチェック）
12:00 昼休み（デスクで食べながら書類作成）
13:00 オーナーへの月次報告電話
14:00 新規入居者の契約手続き
15:00 設備トラブル対応（エアコン故障）
17:00 空室物件の募集条件見直し
18:00 残業（書類作成、翌日の準備）

→ 「新しいことをやる余裕がない」のが本音
```

## tsumugiに対する反応

### 最初に聞いた時（様子見）

> 「へえ、そういうサービスがあるんですね」

> 「で、うちは何をすればいいんですか？」

> 「手間かかります？正直、今でもいっぱいいっぱいなんですけど...」

### メリットを説明された時（興味と警戒）

> 「空室期間短くなるのはいいですね、オーナーさんも喜ぶし」

> 「でも、トラブルになった時にうちに来られても困るんですよね」

> 「責任の範囲はどうなってます？」

### 条件が整えば（消極的OK）

> 「オーナーさんがOKで、うちの手間が増えないなら、まあいいですよ」

> 「何かあった時の連絡先だけ明確にしておいてください」

## 懸念と解消策

| 佐藤さんの懸念                         | 解消策                                 |
| -------------------------------------- | -------------------------------------- |
| 「手間が増える」                       | 管理会社の作業は「承認ボタン押すだけ」 |
| 「トラブル時に苦情が来る」             | 責任分界点を明示、tsumugiがサポート    |
| 「オーナーへの説明が面倒」             | 説明資料を用意、テンプレ提供           |
| 「よく分からないサービス」             | 簡潔な説明資料（1枚もの）              |
| 「入居者から質問されても答えられない」 | FAQ・説明資料を提供                    |

## 佐藤さんを味方につけるポイント

### 効くアプローチ

| 効くアプローチ                         | 理由                   |
| -------------------------------------- | ---------------------- |
| 「承認ボタン押すだけです」             | 手間がかからない       |
| 「空室期間短くなります」               | オーナーへの実績になる |
| 「トラブルはtsumugiが対応します」      | 責任を負わなくていい   |
| 「オーナー説明用の資料あります」       | 自分で作らなくていい   |
| 「入居者さんから相談があると思います」 | 自分から動かなくていい |

### 効かないアプローチ

| 効かないアプローチ             | 理由               |
| ------------------------------ | ------------------ |
| 「いろいろ対応をお願いします」 | 手間が増える       |
| 「新しいサービスです」         | 新しい＝面倒       |
| 「何かあったらご連絡ください」 | 責任が曖昧         |
| 「口頭で説明してください」     | 自分の仕事が増える |
| 「御社から営業してください」   | 論外               |

## tsumugiでの役割

```
┌─────────────────────────────────────────┐
│       佐藤さん（管理会社）の役割        │
├─────────────────────────────────────────┤
│                                         │
│ 1. 承認依頼を受ける                     │
│    - ユキから「家具引き継ぎたい」と相談 │
│    - tsumugiから承認依頼が届く          │
│                                         │
│ 2. オーナーに確認する                   │
│    - 説明資料を使って田中オーナーに説明 │
│    - 「空室期間短くなりますよ」         │
│                                         │
│ 3. 承認/却下する                        │
│    - オーナーOKなら承認ボタンを押す     │
│    - 以上。それ以外の対応は不要         │
│                                         │
└─────────────────────────────────────────┘
```

### 作業量の目安

| 承認依頼の確認               | 1分       |
| オーナーへの説明（資料あり） | 5分       |
| 承認ボタンを押す             | 30秒      |
| **合計**                     | **約7分** |

## 責任分界点の明示

```
【管理会社の責任範囲】
✅ 賃貸契約に関すること（従来通り）
✅ 物件の管理・修繕（従来通り）
✅ オーナーへの報告（従来通り）

【tsumugiの責任範囲】
✅ 家具引き継ぎのマッチング
✅ 家具に関するトラブル対応
✅ 決済処理
✅ 前の住人・次の住人へのサポート

【明確な分離】
家具の問題 → tsumugi
物件の問題 → 管理会社
```
