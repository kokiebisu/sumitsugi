# 管理会社ペルソナ：高橋さん

> 「うちの物件に住んでくれる人が喜ぶなら、協力しますよ」

---

## 基本プロフィール

| 項目                   | 内容                                                     |
| ---------------------- | -------------------------------------------------------- |
| **名前**               | 高橋 裕也（Yuya Takahashi）                              |
| **年齢**               | 45歳                                                     |
| **職業**               | 不動産管理会社 代表（個人経営）                          |
| **会社規模**           | 小規模（管理戸数120戸、社員3名）                         |
| **担当エリア**         | 東京都世田谷区・杉並区                                   |
| **経歴**               | 大手管理会社に10年勤務後、独立して8年                    |

---

## 状況

大手管理会社での経験を活かし、少数の物件を丁寧に管理するスタイルで独立。

入居者やオーナーとの距離が近く、「顔が見える管理」を売りにしている。大手にはない柔軟さが強みだが、人手が足りないのが悩み。

「差別化できることがあれば何でもやりたい」が本音。大手管理会社との競争で、サービスの質でしか勝負できないと分かっている。

---

## 性格特性（柔軟・サービス志向）

| 特徴               | 詳細                                       |
| ------------------ | ------------------------------------------ |
| **柔軟**           | 新しいことにも「まずやってみよう」         |
| **入居者目線**     | 入居者の満足度が高ければオーナーも満足する |
| **差別化意識**     | 大手に勝つには「ここにしかない」が必要     |
| **人手不足の悩み** | やりたいことはあるが手が回らない           |
| **経営者視点**     | コストと効果のバランスを考える             |

## sumitsugiに対する反応

### 最初に聞いた時（興味津々）

> 「へえ、面白いですね。入居者さんからこういう要望、実はちょこちょこあるんですよ」

> 「前の人の家具そのまま使いたいって言われて、個別に調整したことありますよ。それがサービスになるのか」

> 「うちの管理物件で試してみたいですね」

### 実務的な確認（現実的）

> 「ただ、うちは3人でやってるんで、あんまり手間がかかるとキツいんですよね」

> 「オーナーさんへの説明は自分でできるけど、資料はもらえる？」

> 「トラブル対応の線引きだけはっきりしてほしいかな」

### 積極的に協力（パートナーとして）

> 「むしろ、うちの管理物件が『sumitsugi対応物件』として目立つなら、営業にも使えるじゃないですか」

> 「オーナーさんへの提案材料として使いたい。空室対策の一環として」

> 「入居者さんの満足度が上がれば、退去率も下がるし、いいことずくめですよ」

## 関心事と優先度

| 関心事               | 優先度 | 詳細                               |
| -------------------- | ------ | ---------------------------------- |
| 大手との差別化       | ★★★    | 小規模は差別化しないと生き残れない |
| 入居者の満足度向上   | ★★★    | 退去率低下・口コミ → オーナー獲得  |
| 手間は最小限にしたい | ★★     | 協力はしたいが人手が足りない       |
| オーナーへの提案材料 | ★★     | 新規オーナー獲得のネタになる       |
| 管理戸数を増やしたい | ★      | ゆっくり成長したい                 |

---

## 懸念と解消策

| 高橋さんの懸念                       | 解消策                                            |
| ------------------------------------ | ------------------------------------------------- |
| 「手間がかかりすぎないか」           | 作業量を具体的に提示（佐藤さん同様7分）           |
| 「トラブル時の責任範囲」             | 責任分界点の明示（家具→sumitsugi、物件→管理会社） |
| 「オーナーによっては渋る」           | 保守的オーナー向け説明資料を提供                  |
| 「自分のところだけ対応して大丈夫？」 | 管理会社単位での導入が可能と説明                  |
| 「社員に説明できるか」               | 管理会社スタッフ向けFAQを提供                     |

## 佐藤さんとの対比

| 比較軸                | 佐藤さん（消極型）          | 高橋さん（積極型）                 |
| --------------------- | --------------------------- | ---------------------------------- |
| **会社規模**          | 中小（500戸、多数の担当者） | 小規模（120戸、3名で運営）         |
| **sumitsugiへの態度** | 手間が増えないならOK        | 差別化に使えるなら積極協力         |
| **動機**              | 現状維持、手間を増やさない  | 大手との差別化、入居者満足度向上   |
| **オーナー対応**      | 言われたことを淡々とやる    | 自ら提案する、営業ツールとして活用 |
| **口癖**              | 「ボタン1つで終わるなら」   | 「うちの物件でまず試しましょう」   |

**議論での価値:**
佐藤さんが「手間かかるなら勘弁」と渋る場面で、高橋さんが「むしろこれは営業材料になる」と別の視点を出す。管理会社の多様なスタンスを表現できる。
