## 状況

仲介業界は「どこで借りても同じ」と思われがち。SUUMOやHOME'Sに載っている物件はどの仲介でも紹介できるので、差別化が難しい。

「この仲介会社に頼む理由」を作るために、SNSでの物件紹介や内見動画など独自の取り組みをしている。sumitsugiのような新しいサービスは「他の仲介にない提案ができる武器」として興味がある。

---

## 性格特性（提案型・差別化志向）

| 特徴           | 詳細                                       |
| -------------- | ------------------------------------------ |
| **提案型**     | 物件を紹介するだけでなく「暮らし方」を提案 |
| **差別化志向** | 「どこで借りても同じ」を壊したい           |
| **SNS活用**    | 物件を「映える」形で紹介するのが得意       |
| **顧客志向**   | 成約よりもリピート・紹介を重視             |
| **行動派**     | 面白そうなら先にやってみて、後から考える   |

## sumitsugiに対する反応

### 最初に聞いた時（即座に可能性を感じる）

> 「これ、めちゃくちゃいいじゃないですか！」

> 「普通の仲介は物件のスペックしか見せられないけど、これなら『暮らし』が見える」

> 「お客さんに『この部屋で実際にこういう暮らしをしている人がいます』って言えるの、強い」

### ビジネスチャンスとして（積極的）

> 「sumitsugi対応物件を優先的に紹介するプランとか作れません？」

> 「うちのSNSでsumitsugi物件を紹介したい。ビフォーアフターとか絶対バズる」

> 「内見の時に前の住人さんから話を聞けるって、お客さんすごく安心するんですよ」

### 実務面の提案（現場からの声）

> 「ただ、契約のタイミングだけ調整が必要かな。通常の賃貸契約と家具引き継ぎのタイミングが合わないとお客さんが混乱する」

> 「重要事項説明で家具の取り扱いについて触れる必要があるか、確認しておきたい」

> 「外国人のお客さんにも説明しやすいような英語の資料があるとベスト」

## 関心事と優先度

| 関心事                     | 優先度 | 詳細                                     |
| -------------------------- | ------ | ---------------------------------------- |
| 他の仲介との差別化         | ★★★    | 「この仲介でしかできない提案」が欲しい   |
| お客さんの満足度・リピート | ★★★    | 紹介・リピートが収益の柱                 |
| 成約率の向上               | ★★     | sumitsugi物件は成約率が高いと期待        |
| SNSでの集客ネタ            | ★★     | 「映える」物件紹介ができる               |
| 手間が増えすぎないこと     | ★      | ある程度の手間は差別化のコストと割り切る |

## 懸念と解消策

| 山田エージェントの懸念                   | 解消策                                      |
| ---------------------------------------- | ------------------------------------------- |
| 「契約タイミングの調整が複雑」           | sumitsugiと賃貸契約のフロー整理・ガイド提供 |
| 「重説で何を説明すべきか」               | 法務確認済みの説明テンプレートを提供        |
| 「お客さんが家具トラブルで仲介を責める」 | 責任分界点の明示、お客さん向け説明資料      |
| 「全ての物件で使えるわけではない」       | sumitsugi対応物件の条件を明確化             |
| 「社内の他の営業にも教えたい」           | 仲介会社向け研修資料・マニュアル            |

## 鈴木エージェントとの対比

| 比較軸                | 鈴木エージェント（淡々型） | 山田エージェント（提案型）         |
| --------------------- | -------------------------- | ---------------------------------- |
| **年齢**              | 27歳                       | 30歳                               |
| **スタンス**          | 成約になるなら普通に対応   | 積極的に武器として活用したい       |
| **動機**              | ノルマ達成                 | 差別化・リピーター獲得             |
| **sumitsugiへの態度** | 受動的（来たら対応する）   | 能動的（自分から提案に使う）       |
| **SNS活用**           | ほぼなし                   | Instagram・TikTokで物件紹介        |
| **口癖**              | 「普通に手続きしますよ」   | 「これ、お客さんに提案していい？」 |

**議論での価値:**
鈴木エージェントが「仲介の仕事は変わらない」と淡々とする場面で、山田エージェントが「むしろ提案の幅が広がる」とビジネスチャンスを語る。仲介業界での受容度の幅を表現できる。
