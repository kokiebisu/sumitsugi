## 状況

成約数がノルマ。毎月の数字に追われている。

お客さんが「tsumugiで見つけた物件を契約したい」と来たら、普通に対応する。新しいサービス経由でも成約は成約。特に困ることはない。

---

## tsumugiに対する反応

### 最初に聞いた時

> 「あー、そういうサービスがあるんですね」

> 「へえ、家具ごと引き継ぐって面白いですね」

### 実務的な反応

> 「お客さんが契約したいなら、普通に手続きしますよ」

> 「うちの仕事は変わらないんでしょ？契約業務は従来通り？」

> 「じゃあ特に問題ないですね」

## 関心事と優先度

| 関心事               | 優先度 | tsumugiとの関係                     |
| -------------------- | ------ | ----------------------------------- |
| 成約数を増やしたい   | ★★★    | tsumugi経由の客も成約になる         |
| 手間を増やしたくない | ★★★    | 契約業務は従来通り、変わらない      |
| トラブルを避けたい   | ★★     | 家具の問題はtsumugi、契約は仲介会社 |
| 差別化したい         | ★      | 将来的に「tsumugi対応物件」はあり？ |

## tsumugiとの関係

```
┌─────────────────────────────────────────────────────────────┐
│                    役割分担（明確な分離）                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【tsumugiの役割】                                          │
│   ・暮らしの発見（物件+家具）                               │
│   ・前の住人と次の住人のマッチング                          │
│   ・家具引き継ぎの決済                                      │
│   ・家具に関するトラブル対応                                │
│                                                             │
│  【仲介会社の役割】（従来通り）                             │
│   ・賃貸契約の仲介                                          │
│   ・重要事項説明                                            │
│   ・契約書作成                                              │
│   ・鍵の引き渡し                                            │
│                                                             │
│  → 競合ではなく補完関係                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## ユーザーフローにおける位置付け

```
【ハル（次の住人）のジャーニー】

① tsumugiで「暮らし」を発見
        ↓
② ユキ（前の住人）が内見対応
        ↓
③ 気に入った！契約したい
        ↓
④ 仲介会社（鈴木エージェント）に連絡  ← ここで登場
   「この物件を契約したいのですが」
        ↓
⑤ 通常の賃貸契約手続き
   （重説、契約書、初期費用など）
        ↓
⑥ 契約成立
        ↓
⑦ tsumugiで家具引き継ぎ決済
        ↓
⑧ 入居・引き継ぎ完了
```
