## 活用方法

### プロダクト会議で

```
「この機能、ユキさんにとってどう？」
「ソウタさんみたいなドライな人でも使いたくなる？」
「リュウさんはこの画面、日本語だけで理解できる？」
「ノリコさんはアプリの操作で迷わない？」
「ケンジさんの急ぎケースでもフローは間に合う？」
```

### マーケティングで

```
「ユキさんに響くメッセージは？」
「リュウさんはどこで情報収集する？（Facebook、Reddit）」
「トモヤさんのリピーターストーリーをマーケティングに活用できない？」
```

### 開発で

```
「このフローはケンジさんの3週間で間に合う？」
「ミナさんの部分引き継ぎ、UIどうする？」
「佐藤さんは『ボタン1つで完了』じゃないと使わない」
「リュウさん向けに、やさしい日本語モードは必要？」
```

## 重要な洞察

### ユキ（前の住人・一般型）

- 「愛着ある暮らしを引き継ぎたい」という感情的動機が強い
- 内見の負担軽減が重要（FAQ機能、動画ツアー、本気の人だけ来る仕組み）
- 「この人に引き継ぎたい」と思える相手を選びたい

### レイ（前の住人・クリエイター型）

- 部屋を「作品」として捉える、引越しは「新しいキャンバスへ」
- SNS発信力が高い、バイラル効果が期待できる
- 「作品の価値を分かる人に引き継ぎたい」
- tsumugiのブランディング上、重要なペルソナ

### マリ（インテリアコーディネーター）

- 「高い」イメージで依頼が来にくい悩み
- 作品を残したい・次の人に引き継ぎたいという動機
- tsumugiで「プロの空間を手軽に体験」を実現
- B2B展開（管理会社・大家との連携）の種

### ケンジ（前の住人・急ぎ型）

- 会社都合の転勤、来月末までに全て完了が必要
- 丁寧さより速さ。「安くてもいいから確実に引き取ってほしい」
- ユキとの対照で「スピード出品フロー」「急募フラグ」の議論が生まれる
- 転勤・駐在は定常的な需要源

### トモヤ（前の住人・二度目型）

- tsumugiを買い手・売り手の両方で経験した唯一のペルソナ
- 「前に使った時ここが不便だった」と具体的なフィードバックを出せる
- 「引き継ぎの循環」モデルの体現者
- リピーターのLTV（顧客生涯価値）の高さを示す

### ハル（次の住人・一般型）

- 「センスに自信がない」「入居初日から住みたい」
- tsumugiが物件探しの起点（SUUMOではない）
- 前の住人から直接話を聞けることが安心材料
- 「プロがコーディネートした部屋」に高い価値を感じる

### ソウタ（次の住人・転勤リピーター型）

- 合理的・ドライ。「コスパ」「効率」で判断
- 「どうせ2年で出る」→ 退去時もtsumugiで出品したい（リピーター）
- レイとの対立軸（「作品の価値」vs「安ければいい」）
- 感情論に興味なし、数字とスペックで決める

### ミナ（次の住人・アレンジ型）

- 「全部じゃなくて一部だけ引き継ぎたい」→ 部分引き継ぎの需要を示す
- 同棲開始で二人の趣味をすり合わせる必要がある
- ユキとの対立軸（「全部引き継いで」vs「選ばせて」）
- 家具個別選択UIの検討を促す

### ノリコ（次の住人・ダウンサイザー型）

- 52歳、子供独立後の「第二の人生」のための部屋づくり
- 質重視、予算には余裕あり → 高単価取引の可能性
- デジタルに慎重 → UIの分かりやすさを検証するリトマス試験紙
- マリ（プロ）のコーディネート物件に特に惹かれる

### リュウ（次の住人・外国人型）

- 台湾出身ITエンジニア、来日2年目
- 「日本語だけだと分からない部分がある」→ 多言語・やさしい日本語の議論
- 家具を揃えるハードルが日本人の比でない（言語×文化×システム）
- 在日外国人300万人超という巨大な潜在市場を示す
- 外国人に分かりやすいUIは、日本人にも分かりやすい（ユニバーサルデザイン効果）

### 田中オーナー（大家）

- 懐疑的、新しいことはリスク
- 「管理会社がOKなら、まあいいか」
- 書面重視、実績重視

### 佐藤さん（管理会社）

- 「手間がかからないなら協力してもいい」
- 承認ボタン押すだけ、説明資料があればOK
- 大家を説得するキーパーソン

### 鈴木エージェント（仲介会社）

- 「成約になるなら普通に対応する」
- tsumugiとは競合ではなく補完関係
- 将来的な連携は Phase 2 以降
