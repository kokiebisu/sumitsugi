# 前の住人ペルソナ（二度目型）：トモヤ

> 「前にsumitsugiで引き継いだ側だったんだけど、今度は自分が出品する番」

---

## 基本プロフィール

| 項目                   | 内容                                         |
| ---------------------- | -------------------------------------------- |
| **名前**               | 小林 トモヤ（Tomoya Kobayashi）              |
| **年齢**               | 30歳                                         |
| **職業**               | スタートアップ勤務（プロダクトマネージャー） |
| **居住地**             | 東京都渋谷区（1LDK、築6年、家賃13万円）      |
| **家族構成**           | 一人暮らし → 結婚のため引越し                |
| **居住年数**           | 2年（sumitsugiで引き継いで入居）             |
| **デジタルリテラシー** | 非常に高い（プロダクト開発者）               |

---

## 状況

2年前にsumitsugiで前の住人から家具を引き継いで入居した。そのまま快適に暮らしてきたが、結婚が決まり二人で住む新居へ引越し。

今度は自分が「前の住人」として、この家具を次の人に引き継ぎたい。**sumitsugiを買い手・売り手の両方で経験した唯一のペルソナ。**

---

## ユキ（一般型）との違い

| 観点              | ユキ（一般型）        | トモヤ（二度目型）                 |
| ----------------- | --------------------- | ---------------------------------- |
| 家具との関係      | 自分で3年かけて揃えた | **sumitsugiで引き継いだもの**      |
| sumitsugiの理解度 | 初めて使う            | **買い手として使った経験あり**     |
| 出品の動機        | 愛着を引き継ぎたい    | **「引き継ぎの循環」を回したい**   |
| サービスへの期待  | 分からないことが多い  | **改善してほしい点が具体的にある** |
| 価格感            | 少しでもお金になれば  | **自分が払った額を基準に考える**   |

---

## 動機（なぜsumitsugiを再び使う？）

### 体験的動機（最重要）

- **2年前に自分がsumitsugiで助かった経験がある**
- 「あの時、前の住人が出品してくれたから快適に暮らせた」
- 今度は自分がその恩を返す番だと思っている
- **「引き継ぎの循環」の一部になりたい**

### 経済的動機

- 2年前に引き継ぎ費用として8万円払った
- 今度は自分も同じくらい回収したい
- 「8万で引き継いで、8万で引き継ぐ。実質レンタルみたいなもの」

### 合理的動機

- sumitsugiの使い方を知っているので出品が楽
- 買い手の気持ちが分かるので、良い出品ができる

## トモヤが知っている「改善点」

**買い手として使った時に感じた不便・不満:**

| 当時感じたこと                                 | 改善案（トモヤの視点）             |
| ---------------------------------------------- | ---------------------------------- |
| 「写真だけだと実際のサイズ感が分からなかった」 | 家具の寸法を必須項目にしてほしい   |
| 「前の住人とのメッセージが遅かった」           | レスポンス目安の表示、通知の改善   |
| 「引き継ぎ当日の段取りが分からなかった」       | 引き継ぎ当日チェックリストの提供   |
| 「管理会社への説明が面倒だった」               | 管理会社向け説明テンプレートの充実 |
| 「FAQが足りなかった」                          | もっと具体的なQ&Aを用意してほしい  |

## 不安・障壁

| 不安                                             | 解消策（sumitsugiが提供すべき）         |
| ------------------------------------------------ | --------------------------------------- |
| 「自分で買った家具じゃないけど、出品していい？」 | sumitsugiで引き継いだ家具の再出品ガイド |

| 「前回と同じ価格で出していい？」                 | 経年劣化を考慮した価格ガイド            |
| 「前の前の住人の許可は要る？」                   | 所有権の移転に関する明確なルール        |

## sumitsugiでの体験フロー

```
┌─────────────────────────────────────────────────────────────┐
│                トモヤのカスタマージャーニー                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【2年前：買い手として】                                    │
│  sumitsugiで物件発見 → 内見 → 引き継ぎ → 快適に暮らす       │
│                                                             │
│  【今回：売り手として】                                    │
│  ① 出品（買い手経験を活かした丁寧な出品）                  │
│     - 寸法を全て記載（前回なくて困った）                   │
│     - 使用感を正直に書く                                   │
│     - 「sumitsugiで引き継いだ家具です」と明記               │
│                                                             │
│  ② 問い合わせ対応（自分が聞きたかったことを先回り）       │
│     - FAQを充実させる                                      │
│     - レスポンスは早めに                                   │
│                                                             │
│  ③ 内見対応（買い手目線で案内）                            │
│     - 「ここ、実際住むとこう使うと便利ですよ」             │
│     - 引き継ぎ当日の流れも説明                             │
│                                                             │
│  ④ 引き継ぎ完了、新居へ                                    │
│     - 「引き継ぎの循環」が完成                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 成功の定義

- 引き継ぎの循環を自分で体現できた
- 買い手の時の不満を解消した出品ができた
- 適正価格で引き継げた（支払った額と同程度）
- 次の住人が「いい部屋ですね」と喜んでくれた
