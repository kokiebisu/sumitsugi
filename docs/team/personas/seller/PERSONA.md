## 状況

彼氏との同棲が決まり、来月末で退去予定。

3年かけて揃えた北欧風のインテリアに愛着がある。新居は彼の家具があるため、自分の家具は持っていけない。

---

## 動機（なぜtsumugiを使う？）

### 感情的動機

- **愛着ある暮らしを引き継ぎたい**
- この部屋の雰囲気を気に入ってくれる人に渡したい
- ただ捨てるのは忍びない

### 経済的動機

- 粗大ゴミで処分すると2〜3万円かかる
- 少しでもお金になれば引越し費用の足しになる

### 合理的動機

- メルカリは面倒（発送、梱包、購入者対応）
- 「部屋ごと」引き継げるなら手間が少ない

| 「トラブルになったら面倒」                       | 利用規約、サポート体制                           |

## 内見負担の軽減（重要）

ユキにとって「内見が面倒」は大きな障壁。以下の仕組みで軽減する：

### ユキの本音

> 「『とりあえず見たいだけ』の人に何回も対応するのがしんどい。
> でも、ちゃんと興味持ってくれてる人には、この部屋の良さを伝えたい。」

> 「**『この人に引き継ぎたい』って思える人**に来てほしい。
> 部屋の雰囲気を分かってくれる人。」

### 段階的フィルタリング

```
Step 1: 写真・説明文で興味を持つ
        ↓ （多数）

Step 2: 動画ツアー（任意）で部屋の雰囲気を確認
        ↓ （ふるい落とし）

Step 3: FAQ・メッセージで疑問解消
        ↓ （本気度確認）

Step 4: 実内見（本気の人だけ）
        → 1〜2回で決まる
```

### 必要な機能

| 機能                             | ユキにとっての価値                     | 優先度 |
| -------------------------------- | -------------------------------------- | ------ |
| **FAQ機能**                      | 同じ質問に何度も答えなくていい         | ★★★    |
| **内見希望者のプロフィール表示** | どんな人か事前に分かる、安心           | ★★★    |
| **動画ツアー（任意）**           | 「とりあえず見たい」層をフィルタリング | ★★     |
| **メッセージでの事前やりとり**   | 本気度・相性を確認できる               | ★★     |

### ユキの声

> 「動画撮るのは別にいい。むしろ自分の部屋を綺麗に撮りたい。
> でも『必須です』って言われると重いから、やりたい人だけでいい。」

> 「同じ質問に何回も答えるのは疲れる。
> **よくある質問をあらかじめ書いておける**といいな。」

> 「内見前にプロフィールとかメッセージで相手がどんな人か分かると安心。
> 『この部屋の雰囲気好きです』とか言ってくれたら、『ぜひ来てください！』ってなる。」

## tsumugiでの役割

```
┌─────────────────────────────────────────┐
│          ユキがやること                 │
├─────────────────────────────────────────┤
│ 1. 暮らしを出品する                     │
│    - 物件情報（最低限）                 │
│    - 家具リスト・写真                   │
│    - 部屋の雰囲気・暮らし方             │
│                                         │
│ 2. 内見対応する（住んでいるから）       │
│    - 内見希望者とスケジュール調整       │
│    - 部屋を案内、暮らし方を伝える       │
│                                         │
│ 3. 家具を引き継ぐ                       │
│    - 引き継ぎ条件の合意                 │
│    - 決済（tsumugi経由）                │
│    - 退去時に引き渡し                   │
└─────────────────────────────────────────┘
```

## 成功の定義

- 愛着ある家具が、気に入ってくれる人に渡った
- 処分費用がかからず、むしろお金がもらえた
- 退去がスムーズに完了した
- 次の住人が「いい部屋ですね」と喜んでくれた
