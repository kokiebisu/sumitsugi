## 状況

会社都合でシンガポール駐在が決定。出発は来月末。引越し準備、ビザ手続き、業務引き継ぎ...やることが山積み。

家具はそれなりに良いものを揃えたが、海外に持っていけない。処分する時間も惜しい。「誰かにまとめて引き取ってほしい」が本音。

## 動機（なぜsumitsugiを使う？）

### 時間的動機（最重要）

- **来月末までに退去完了しなければならない**
- 粗大ゴミの予約は2週間待ち、間に合わない可能性
- メルカリで1個ずつ売る時間はない
- 「まとめて引き取ってくれるサービス」を探している

### 経済的動機

- 処分費用を払うのは馬鹿らしい
- でも**高く売ることより、確実に引き取ってもらう方が大事**
- 「タダでもいいから持っていってほしい」くらいの気持ち

### 合理的動機

- 部屋ごと引き継げるなら手間が最小限
- 1回の取引で全部完了するのが理想
- 仕事が忙しいので、やりとりは最小限にしたい

## 不安・障壁

| 不安                                     | 解消策（sumitsugiが提供すべき）              |
| ---------------------------------------- | -------------------------------------------- |
| 「来月末に間に合う？」                   | **スピード出品・マッチングの仕組み**         |
| 「次の住人が決まらなかったらどうする？」 | 代替処分プランの提示、期限管理               |
| 「内見対応の時間が取れない」             | 動画ツアーでの代替、週末1回限定              |
| 「やりとりが長引くのは困る」             | テンプレート対応、最小限のコミュニケーション |
| 「大家の承認に時間がかかったら？」       | 承認フローの迅速化、並行手続き               |

## sumitsugiでの体験フロー

```
┌─────────────────────────────────────────────────────────────┐
│                ケンジのカスタマージャーニー                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① 急ぎで出品（最短フロー）                                │
│     - 写真をまとめて撮影（15分）                           │
│     - 最低限の情報だけ入力                                 │
│     - 「急募」フラグを設定                                 │
│                                                             │
│  ② 問い合わせ対応（最小限）                                │
│     - テンプレート返信で対応                               │
│     - 「写真の通りです」「週末内見可」                     │
│                                                             │
│  ③ 内見（1回で決めてほしい）                               │
│     - 土曜午前中のみ                                       │
│     - 「気に入ったらその場で決めてほしい」                 │
│                                                             │
│  ④ 即決済・引き継ぎ日確定                                  │
│     - 退去日に合わせて引き渡し                             │
│     - 手続きは全てオンライン完結                           │
│                                                             │
│  ⑤ 退去完了、シンガポールへ                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 成功の定義

- 来月末までに家具の引き継ぎが完了した
- 処分費用がかからなかった
- 仕事に支障が出ないレベルの手間で済んだ
- 退去がスムーズに完了した
