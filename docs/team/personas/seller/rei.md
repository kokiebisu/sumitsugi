## ユキ（一般型）との違い

| 観点         | ユキ（一般型）       | レイ（クリエイター型）               |
| ------------ | -------------------- | ------------------------------------ |
| 動機         | もったいない、愛着   | **作品を世に出す、次のキャンバスへ** |
| 部屋の捉え方 | 「私の暮らし」       | **「私の作品」**                     |
| 引越しの意味 | 新生活のため         | **創作サイクルの一部**               |
| 価格感       | 処分費用より得すれば | **作品の価値に見合う対価**           |

---

## 状況

この部屋は2年かけて作り上げた「作品」。

壁の色、照明の角度、家具の配置、植物の位置...すべてが計算されている。

でも、完成した作品に住み続けるのはクリエイターとして停滞。**新しいキャンバス（部屋）で、また一から創作を始めたい。**

この作品は、理解してくれる人に引き継ぎたい。ただの「中古家具」として売るのは違う。

---

## 動機（なぜsumitsugiを使う？）

| 動機                         | 詳細                                       |
| ---------------------------- | ------------------------------------------ |
| **作品を世に出したい**       | 完成した空間を「作品」として誰かに届けたい |
| **新しいキャンバスが欲しい** | 次の創作に向かうための引越し               |
| **理解者に引き継ぎたい**     | この空間の価値を分かる人に住んでほしい     |
| **クリエイターとしての実績** | 「空間作品」のポートフォリオの一つ         |

---

## 不安・障壁

| 不安                               | 解消策（sumitsugiが提供すべき）            |
| ---------------------------------- | ------------------------------------------ |
| 「作品の価値を分かってもらえる？」 | 作品としての見せ方（ポートフォリオ風出品） |
| 「安く買い叩かれたくない」         | 価格交渉なしのオプション、価値の説明欄     |
| 「誰でもいいわけじゃない」         | 購入希望者のプロフィール・メッセージ確認   |
| 「内見で荒らされたくない」         | 本気度の高い人だけに絞る仕組み             |

## sumitsugiでの役割

```
┌─────────────────────────────────────────┐
│          レイがやること                 │
├─────────────────────────────────────────┤
│                                         │
│ 1. 作品として出品する                   │
│    - 空間のコンセプト・ストーリー       │
│    - プロ品質の写真・動画               │
│    - 世界観の説明                       │
│                                         │
│ 2. SNSで発信する                        │
│    - 「作品としての部屋、引き継ぎます」 │
│    - フォロワーへの告知                 │
│    - sumitsugiの認知拡大に貢献            │
│                                         │
│ 3. 理解者を選ぶ                         │
│    - 内見希望者のプロフィール確認       │
│    - 「この人に引き継ぎたい」を選べる   │
│                                         │
└─────────────────────────────────────────┘
```

---

## sumitsugiにとっての価値

| 価値                   | 詳細                                 |
| ---------------------- | ------------------------------------ |
| **ブランディング**     | 「暮らしを引き継ぐ」の最も美しい体現 |
| **バイラル効果**       | SNSでの発信力、メディア露出          |
| **プレミアム層の開拓** | 高単価取引の可能性                   |
| **差別化**             | メルカリ/ジモティーとの明確な違い    |
| **コンテンツ**         | レイの出品自体が広告になる           |

---

## 成功の定義

- 作品の価値を理解してくれる人に引き継げた
- 作品に見合う対価を得られた
- SNSで「素敵な取り組み」と反響があった
- 新しいキャンバス（次の部屋）で創作を始められた
- 「空間デザイナーとしての実績」が増えた
