## 現状の悩み

```
【インテリアコーディネーターの現実】

・「高い」イメージで依頼が来にくい
・SNSで発信しても「素敵！」で終わり、依頼につながらない
・作った空間は写真でしか残らない
・クライアントが引っ越すと、作品が消える
・もっと多くの人にプロの空間を体験してほしい
```

| 動機                       | 詳細                                                   |
| -------------------------- | ------------------------------------------------------ |

| **新しい収益機会**         | 従来の「依頼を受ける」だけでない収益モデル             |
| **「高い」イメージの解消** | tsumugi経由なら手軽に体験してもらえる                  |
| **ポートフォリオの拡充**   | 「実際に住める作品」としての実績                       |
| **認知拡大**               | tsumugiユーザーへの露出                                |

## tsumugiとの関わり方

### パターン1：クライアント経由（メイン）

```
マリがコーディネートしたクライアントが引っ越す時
        ↓
「tsumugiで出品しませんか？」と提案
        ↓
クライアントが出品、マリは「コーディネーター」としてクレジット
        ↓
次の住人は「プロがコーディネートした部屋」を引き継げる
        ↓
マリの実績・認知が拡大
```

### パターン2：自分の部屋を作品として

```
マリ自身が住む部屋を「作品兼ショールーム」として
        ↓
定期的に引っ越し、作品をtsumugiで出品
        ↓
「インテリアコーディネーターの部屋に住む」体験を提供
        ↓
次の部屋でまた新しい作品を作る
```

### パターン3：空室コーディネート（将来）

```
大家・管理会社から依頼を受けて空室をコーディネート
        ↓
「コーディネート済み物件」としてtsumugiに掲載
        ↓
入居者はプロの空間をそのまま引き継げる
        ↓
大家は空室期間短縮、マリは新しい収益源
```

## マリの声

> 「インテリアコーディネーターって、実は頼みやすいんですよ。でも『高そう』って思われて、相談すら来ない」

> 「私が作った空間、クライアントが引っ越したら写真しか残らないの。それが寂しくて」

> 「**tsumugiなら、私の作品が次の人に引き継がれる**。それってすごく嬉しい」

> 「『プロがコーディネートした部屋に住む』って、本来は高いサービス。でもtsumugiなら家具代だけで体験できる」

> 「これ、私の新しい仕事の形になるかも」

## ハル（次の住人）にとっての価値

```
【従来】
インテリアコーディネーターに依頼 → 15〜30万円
+ 家具購入 → 20〜50万円
= 合計 35〜80万円

【tsumugi経由】
プロがコーディネートした部屋を引き継ぐ → 10〜20万円（家具代のみ）
= 「プロの仕事」を1/3以下で体験できる
```

**ハルの反応：**

> 「え、この部屋プロがコーディネートしたの？それでこの値段？」
> 「インテリアコーディネーターって高いイメージだったけど、これなら手が届く」
