## 状況

3回目の転勤で大阪から東京へ。前回の引越しで家具を全部処分して後悔した（処分費用8万円）。

「また一から揃えるの面倒だし、2年後にはまた引っ越すかもしれない」。合理的に考えて、誰かの家具を引き継ぐのがベストだと判断。

## 動機（なぜsumitsugiを使う？）

### 経済的動機

- 家具を一から揃えると20万円、処分にまた8万円 → **往復で28万円の無駄**
- 2年しか住まないのに新品を買うのは非合理的
- 引き継ぎなら出費を最小化できる

### 合理的動機

- **引越しのたびに「買う→捨てる」のサイクルが馬鹿らしい**
- sumitsugiなら「引き継ぐ→引き継ぐ」のサイクルに変えられる
- 入居時だけでなく**退去時もsumitsugiで出品**すれば、処分費用ゼロ

### 感情的動機（薄いが存在）

- 正直、インテリアへのこだわりは薄い
- でも「それなりに整った部屋」には住みたい
- 自分で選ぶセンスがないわけじゃないが、**時間をかけたくない**

## sumitsugiでの体験フロー

```
┌─────────────────────────────────────────────────────────────┐
│                ソウタのカスタマージャーニー                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① sumitsugiで条件検索（エリア・家賃・価格でフィルター）     │
│     - テイストより「価格」「立地」「状態」重視             │
│                                                             │
│  ② 条件に合う物件を2〜3件ピックアップ                     │
│     - 写真・動画で確認、詳細は読まない                     │
│                                                             │
│  ③ 一番条件がいい物件に即申し込み                          │
│     - 内見は「必要なら行く」程度                           │
│     - メッセージは事務的・最小限                           │
│                                                             │
│  ④ 契約・引き継ぎ・入居                                    │
│     - スピード重視、手続きは淡々と                         │
│                                                             │
│  ⑤ 2年後、自分もsumitsugiで出品（リピーター）               │
│     - 「次の人にそのまま引き継ぐ」                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 成功の定義

- 家具の購入・処分コストを最小化できた
- 引越しの手間が最小限だった
- 退去時もsumitsugiで引き継げた（**往復で使えた**）
- 「買う→捨てる」のサイクルから脱却できた
