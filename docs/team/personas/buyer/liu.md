## 状況

来日2年目。最初は会社の社宅に住んでいたが、来年妻が来日するため広い部屋に引越し。

社宅は家具付きだったので、自分の家具はほぼゼロ。日本で家具を揃えようにも「どこで買えばいいか分からない」「配送の仕組みが分からない」「組み立て説明書が日本語」...ハードルが多い。

## 動機（なぜtsumugiを使う？）

### 言語・文化的動機（最重要）

- **日本で家具を一から揃えるハードルが高すぎる**
- ニトリ・IKEAに行っても、店員とのコミュニケーションが不安
- 配送手配、組み立て、処分...全て日本語での手続き
- 「部屋ごと引き継げるなら、その全てをスキップできる」

### 経済的動機

- 日本の家具は台湾より高い印象
- 引き継ぎなら新品より安く、すぐ使える
- 妻が来日した時にまた引越す可能性もある → 長期使用の家具は不要

### 感情的動機

- 日本での暮らしを早く安定させたい
- 「日本人が住んでいた部屋をそのまま引き継ぐ」のは、日本の暮らしに溶け込む感じがする
- 妻に「いい部屋だよ」と見せたい

| 「内見の時、日本語で全部理解できるか不安」   | 簡単な日本語での説明、写真・動画の充実     |
| 「トラブルになったら日本語で対処できない」   | 多言語サポート窓口                         |

```
┌─────────────────────────────────────────────────────────────┐
│                  リュウのカスタマージャーニー                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① 同僚（日本人）からtsumugiを教えてもらう                 │
│     - 「家具探してるなら、こういうサービスあるよ」         │
│     - 英語対応があるか確認                                 │
│                                                             │
│  ② tsumugiで物件を探す                                     │
│     - エリア・家賃・写真で判断（テキストより視覚重視）     │
│     - 写真が多い・動画がある物件を好む                     │
│                                                             │
│  ③ 前の住人にメッセージ                                    │
│     - テンプレートを活用（日本語に自信がない部分）         │
│     - 「英語OK」の前の住人だと安心                         │
│                                                             │
│  ④ 内見                                                    │
│     - 実物を確認、分からないことは質問                     │
│     - 「ゴミの出し方」「近所のスーパー」も聞きたい         │
│                                                             │
│  ⑤ 賃貸契約（ここが最大のハードル）                        │
│     - 仲介会社との手続き、保証会社の手配                   │
│     - tsumugiが直接サポートする範囲外だが、案内は必要       │
│                                                             │
│  ⑥ 入居・引き継ぎ完了                                      │
│     - 家具の問題なく新生活スタート                         │
│     - 「日本の暮らし」に一歩近づいた実感                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- 言語の壁を感じずに家具を引き継げた

- 前の住人から日本の暮らしの知恵も教えてもらえた
- 妻に「いい部屋だね」と言ってもらえた
- 日本での暮らしが安定した実感を持てた
