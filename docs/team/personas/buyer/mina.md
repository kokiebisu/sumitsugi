## 状況

彼氏との同棲が決まり、新居を探し中。二人とも「おしゃれな部屋に住みたい」が、テイストが微妙に違う。

彼氏はミニマル好き、ミナはナチュラル×ヴィンテージ好き。「全部そのまま引き継ぐのは二人の部屋にならない」けど、「ベースがあると助かる」。

---

## 動機（なぜtsumugiを使う？）

### 経済的動機

- 同棲開始は出費が多い（引越し費用、初期費用、家電...）
- 家具を**全部**新品で揃えると50万円以上
- 「ベースになる家具があれば、差し替えたい分だけ新品を買える」

### 感情的動機

- **二人の新生活を「自分たちらしく」始めたい**
- 前の住人のテイストが100%自分たちの好みとは限らない
- でも「いいな」と思う部分は取り入れたい

### 合理的動機

- 一から全部選ぶのは大変（選択肢が多すぎて決まらない）
- 「この部屋にはこの家具」という実績があるのは参考になる
- 気に入らないものだけ入れ替えればいい

## 不安・障壁

| 不安                                           | 解消策（tsumugiが提供すべき）                |
| ---------------------------------------------- | -------------------------------------------- |
| 「全部セットじゃないとダメ？」                 | 個別選択・部分引き継ぎオプション             |
| 「要らない家具はどうなるの？」                 | 不要品の処分サポート、選択制の明確化         |
| 「彼氏と意見が合わなかったら？」               | 家具リストの共有・相談機能                   |
| 「前の住人が『全部引き継いで』って言ったら？」 | 部分引き継ぎの選択権が買い手にあることを明示 |
| 「自分で持ち込む家具と合わない可能性」         | 写真で事前シミュレーション                   |

## tsumugiでの体験フロー

```
┌─────────────────────────────────────────────────────────────┐
│                  ミナのカスタマージャーニー                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① tsumugiで部屋を探す（テイスト重視で検索）              │
│     - 「ナチュラル」「ヴィンテージ」タグで絞り込み         │
│                                                             │
│  ② 気になる物件の家具リストを確認                          │
│     - 「このソファいい！」「このラグは好みじゃない」       │
│     - 彼氏に共有して相談                                   │
│                                                             │
│  ③ 内見で実物確認                                          │
│     - 二人で訪問、「これは要る」「これは要らない」を確認   │
│     - ユキに「一部だけ引き継ぎたい」と相談                 │
│                                                             │
│  ④ 引き継ぐ家具を選択して決済                              │
│     - 選んだ家具だけの金額を支払い                         │
│                                                             │
│  ⑤ 入居後、自分たちの家具を追加                            │
│     - 引き継いだ家具 + 新品 = 二人らしい部屋の完成         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 成功の定義

- 気に入った家具だけを選んで引き継げた
- 二人のテイストが反映された部屋になった
- 全部新品で揃えるより費用を抑えられた
- 前の住人の「いいところ」を活かしつつ、自分たちらしさも出せた
