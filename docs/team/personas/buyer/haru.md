## 状況

4月から東京本社配属が決定。初めての東京、初めての一人暮らし。

会社の家賃補助があるので少し良い部屋に住めるが、家具を揃える予算が限られている。「どんな部屋にしよう」と考えるのは楽しいけど、センスに自信がない。

---

## 動機（なぜsumitsugiを使う？）

### 経済的動機

- 家具を一から揃えると**20〜50万円**かかる
- 引越し費用もあるので節約したい
- どうせ数年で転勤するかも、高い家具は買いたくない

### 感情的動機

- **この部屋の雰囲気をそのまま引き継ぎたい**
- 入居初日から「住める状態」にしたい
- 友達を呼んで「いい部屋だね」と言われたい

### 合理的動機

- IKEAで選ぶセンスに自信がない
- 家具選びに時間をかけたくない
- 実際に住んでいる人から話が聞ける安心感

## 不安・障壁

| 不安                                     | 解消策（sumitsugiが提供すべき）             |
| ---------------------------------------- | ------------------------------------------- |
| 「中古品って衛生的に大丈夫？」           | 前の住人のプロフィール、清掃状態の写真      |
| 「写真と実物が違ったらどうしよう」       | 内見で実物確認できる仕組み                  |
| 「前の住人と直接やりとりするの気まずい」 | メッセージテンプレート、サポート            |
| 「入居日までに本当に引き継ぎ完了する？」 | タイムライン管理、進捗確認                  |
| 「気に入らなかったら断れる？」           | 内見後キャンセルOKの明示                    |
| 「賃貸契約はどうすればいい？」           | 契約フローの案内（管理会社/仲介会社へ誘導） |

## sumitsugiでの体験フロー

```
┌─────────────────────────────────────────────────────────────┐
│                    ハルのカスタマージャーニー                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ① sumitsugiで「暮らし」を探す                                │
│     - エリア、家賃、雰囲気で検索                            │
│     - 「北欧風」「ミニマル」などのテイストで絞り込み         │
│                                                             │
│  ② 気になる「暮らし」を見つける                             │
│     - 部屋の写真、家具リスト、前の住人のコメントを確認      │
│     - 「この部屋いいな」と思う                              │
│                                                             │
│  ③ 内見を予約する                                           │
│     - sumitsugiで前の住人（ユキ）にメッセージ                 │
│     - 日程調整                                              │
│                                                             │
│  ④ 内見する（前の住人が案内）                               │
│     - 実際の部屋と家具を確認                                │
│     - 「この部屋の暮らし方」を直接聞ける                    │
│     - 「朝日が気持ちいいですよ」「この棚便利です」          │
│                                                             │
│  ⑤ 気に入ったら賃貸契約へ                                   │
│     - sumitsugiの外：管理会社/仲介会社と契約手続き            │
│                                                             │
│  ⑥ 契約成立後、家具引き継ぎ決済                             │
│     - sumitsugiで引越し費用（家具代）を支払い                 │
│                                                             │
│  ⑦ 入居・引き継ぎ完了                                       │
│     - 初日からおしゃれな部屋で新生活スタート                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 成功の定義

- 入居初日からおしゃれな部屋で生活開始
- 家具代が大幅に節約できた（20万円→5万円など）
- 友達を呼んで「いい部屋だね」と言われた
- 前の住人から「この部屋の使い方」を教えてもらえた
- 引越しのストレスが少なかった
