# 大家ペルソナ：田中オーナー

> 「そんな勝手なことされても困るよ」

---

| 項目                   | 内容                                   |
| ---------------------- | -------------------------------------- |
| **名前**               | 田中 誠一（Seiichi Tanaka）            |
| **年齢**               | 58歳                                   |
| **職業**               | 会社員（管理職）、副業で不動産投資     |
| **居住地**             | 神奈川県横浜市                         |

## 状況

10年前から不動産投資を始めた。本業が忙しいので、管理は全て管理会社に任せている。

入居者のことはあまり把握していないが、空室が長引くと気になる。基本的に「今まで通り」が一番安心だと思っている。

---

## 性格特性（懐疑的）

| 特徴             | 詳細                                     |
| ---------------- | ---------------------------------------- |
| **保守的**       | 「今まで通り」が一番安心                 |
| **リスク回避**   | 新しいことはトラブルの元と考える         |
| **管理会社依存** | 自分で判断したくない、管理会社に任せたい |
| **実績重視**     | 「他にやってる人いるの？」が口癖         |
| **書面主義**     | 口約束は信用しない                       |

## sumitsugiに対する反応

### 最初に聞いた時（懐疑的）

> 「は？家具を残す？何それ、聞いたことないんだけど」

> 「そんな勝手なことされても困るよ」

> 「管理会社通してくれる？直接言われても分からないから」

### 説明を聞いても（まだ警戒）

> 「いや、でもトラブルになったら誰が責任取るの？」

> 「今までそんなことやったことないし...」

> 「他の物件でやってる人いるの？実績は？」

### 条件付きで検討（管理会社がOKなら）

> 「管理会社がOKって言うなら、まあ...」

> 「書面で残してくれるならいいけど」

> 「何かあったらすぐ連絡してよ」

## 懸念と解消策

| 田中オーナーの懸念               | 解消策                         |
| -------------------------------- | ------------------------------ |
| 「聞いたことない、怪しい」       | 事例・実績を見せる（将来的に） |
| 「トラブルになったら誰の責任？」 | 責任範囲を書面で明確化         |
| 「自分で判断したくない」         | **管理会社を先に味方につける** |
| 「勝手にやられると困る」         | 事前承認フローで安心感         |
| 「原状回復はどうなる？」         | 従来通りの原状回復義務を明示   |

## 攻略戦略

### 基本方針

```
田中オーナーを直接説得するより、
【管理会社経由】でアプローチする方が効果的。

管理会社が「大丈夫ですよ」と言えば、
田中オーナーも「じゃあいいか」となる。
```

### アプローチの順序

```
Step 1: ユキが管理会社に相談
        ↓
Step 2: 管理会社が田中オーナーに説明
        「入居者からこういう相談がありまして...」
        「空室期間短縮にもなりますし」
        ↓
Step 3: 田中オーナーが条件付きでOK
        「管理会社さんがいいなら...書面で残してね」
        ↓
Step 4: 承認完了
```

### 田中オーナーを動かすキーワード

| 効くキーワード                 | 効かないキーワード       |
| ------------------------------ | ------------------------ |
| 「管理会社も確認済みです」     | 「新しいサービスです」   |
| 「書面でお渡しします」         | 「口頭で大丈夫です」     |
| 「空室期間が短くなります」     | 「流行ってます」         |
| 「従来通りの契約です」         | 「今までと違うやり方で」 |
| 「他の物件でも実績があります」 | 「初めての試みです」     |

## ユキが使える説明テンプレート

### 管理会社経由の場合（推奨）

```
【ユキ → 管理会社への相談】

「退去にあたり、ご相談があります。

私が使っていた家具を、次の入居者の方に
引き継ぎたいと考えています。

sumitsugiというサービスを使うのですが、
・次の入居者が決まってから退去するので、空室期間が短くなります
・家具の引き継ぎだけで、賃貸契約は通常通りです
・オーナー様のご承認をいただいてから進めます

オーナー様にご確認いただけますでしょうか？」
```

### 大家に直接の場合（管理会社がいない場合）

```
【ユキ → 田中オーナーへの説明】

「退去にあたり、ご相談があります。

私が使っていた家具を、次の入居者の方に
引き継ぎたいと考えています。

・次の入居者が決まってから退去するので、空室期間が短くなります
・家具の引き継ぎだけで、賃貸契約や原状回復は従来通りです
・書面でご承認いただいてから進めます
・何かあればすぐご連絡します

ご検討いただけますでしょうか？」
```
