# 大家ペルソナ：中村オーナー

> 「入居率上がるなら全然いいよ。むしろ家賃上げられない？」

---

## 基本プロフィール

| 項目                   | 内容                                                   |
| ---------------------- | ------------------------------------------------------ |
| **名前**               | 中村 大輝（Daiki Nakamura）                            |
| **年齢**               | 35歳                                                   |
| **職業**               | IT企業勤務（プロダクトマネージャー）                   |
| **居住地**             | 東京都渋谷区                                           |
| **所有物件**           | 都内に1LDK〜2LDKを2戸（うち1戸は住宅ローン活用）       |
| **管理形態**           | 1戸は自主管理、1戸は管理会社委託                       |
| **デジタルリテラシー** | 高（アプリ・SaaS積極利用、スプレッドシートで収支管理） |

---

## 状況

3年前に不動産投資を開始。YouTubeや不動産投資コミュニティで勉強し、「利回り」「空室リスク」を数字で把握している。

本業がIT系なので、新しいサービスやテクノロジーへの抵抗感はゼロ。むしろ「差別化になるなら歓迎」というスタンス。ただし、感覚ではなくデータで判断する。

---

## 性格特性（合理的・前向き）

| 特徴           | 詳細                                         |
| -------------- | -------------------------------------------- |
| **合理的**     | 数字とデータで判断する。感情論は響かない     |
| **前向き**     | 新しいことは差別化のチャンスと捉える         |
| **自分で判断** | 管理会社任せにせず、自分でも情報収集する     |
| **収益重視**   | 空室率・利回り・家賃の最適化を常に考えている |
| **効率重視**   | アプリやツールで管理を効率化したい           |

## sumitsugiに対する反応

### 最初に聞いた時（前向き）

> 「お、面白いじゃん。Airbnbの賃貸版みたいな感じ？」

> 「入居者の満足度が上がるなら空室リスクも下がるでしょ」

> 「データってどのくらい見れるの？閲覧数とかマッチング率とか」

### 具体的な質問（数字で考える）

> 「空室期間が平均何日短縮されるの？」

> 「家賃にプレミアム乗せられる可能性はある？」

> 「家具付きってことは原状回復の範囲はどう変わる？契約書のテンプレある？」

### 条件がクリアなら（即決）

> 「契約上の問題がなくて、入居率上がるなら全然OK」

> 「自主管理の方の物件でまず試してみるよ」

> 「うまくいったらもう1戸の管理会社にも話してみる」

## 関心事と優先度

| 関心事               | 優先度 | 詳細                                 |
| -------------------- | ------ | ------------------------------------ |
| 空室期間を短くしたい | ★★★    | 収益に直結。1日でも短くしたい        |
| 物件の差別化をしたい | ★★★    | 競合物件との差別化が常に課題         |
| 収益を最大化したい   | ★★     | 家賃アップや付加価値の可能性に興味   |
| トラブルは避けたい   | ★★     | 気にはするが、リスクゼロは無理と理解 |
| データで判断したい   | ★★     | 効果測定できないものには投資しない   |

## 懸念と解消策

| 中村オーナーの懸念               | 解消策                               |
| -------------------------------- | ------------------------------------ |
| 「データで効果を見たい」         | ダッシュボード・レポート機能（将来） |
| 「契約書はどうなる？」           | 特約条項のテンプレートを提供         |
| 「原状回復の責任範囲は？」       | 家具と物件の責任分界点を明確化       |
| 「管理会社側の理解が追いつくか」 | 管理会社向け説明資料を提供           |
| 「自主管理物件で先に試したい」   | スモールスタートをサポート           |

## 田中オーナーとの対比

| 比較軸                | 田中オーナー（保守型）     | 中村オーナー（積極型）     |
| --------------------- | -------------------------- | -------------------------- |
| **年齢**              | 58歳                       | 35歳                       |
| **判断基準**          | 実績・前例があるか         | データ・ROIで判断          |
| **新サービス**        | リスク、怪しい             | 差別化のチャンス           |
| **管理スタイル**      | 全て管理会社任せ           | 自分でも情報収集・判断する |
| **sumitsugiへの態度** | 管理会社がOKなら...        | 自分から試してみる         |
| **口癖**              | 「他にやってる人いるの？」 | 「データ見せて」           |

**議論での価値:**
田中オーナーが「怪しい」と渋る場面で、中村オーナーが「合理的に見ればメリットしかない」と反論することで、大家層の多様な意見が可視化される。
