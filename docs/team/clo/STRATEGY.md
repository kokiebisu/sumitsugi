# CLO 戦略書 - プレローンチフェーズ

## ミッション

法的リスクを早期に発見し、外部弁護士への相談を効率化する。
「知らなかった」で済まされないリスクを防ぐ。

**重要:** 最終的な法務判断は外部弁護士が行う。CLO（AI）の役割はリスク指摘と論点整理。

---

## 責任分担

| 担当       | 役割                                   |
| ---------- | -------------------------------------- |
| CLO（AI）  | リスク指摘、論点整理、ドラフトレビュー |
| 外部弁護士 | 最終判断、法的責任、正式な法的助言     |
| CEO        | 法務タスクの進行管理、弁護士との窓口   |
| 大株主     | 最終的な経営判断                       |

---

## プレローンチ期の優先事項

### 1. 無料法律相談の準備

**最優先質問（3問に絞る）:**

1. Stripe Connectを使う場合、資金移動業の登録は必要か？
2. 家具引き継ぎの仲介は宅建業法の適用対象か？
3. このビジネスモデルで致命的な法的リスクはあるか？

**相談先候補:**

- 東京都中小企業振興公社（無料、要予約）
- 弁護士ドットコム（オンライン、一部無料）
- 法テラス（収入要件あり）

**準備物:**

- 法務質問リスト: `docs/plans/legal-review-questions.md`
- 決済フロー図: `docs/plans/2026-01-31-payment-system-design.md`

### 2. 利用規約のレビュー

**CEOが叩きを作成後、CLOがレビュー**

**チェックポイント:**

- [ ] エスクロー機能の説明は明確か
- [ ] キャンセルポリシーは消費者契約法に抵触しないか
- [ ] 免責条項は過度に広すぎないか
- [ ] 個人情報の取り扱いは適切か
- [ ] 紛争解決条項は有効か

**レビュー後のアクション:**
→ 指摘事項をまとめて外部弁護士に確認

---

### 3. リスクマトリクス

| リスク                 | 影響度 | 発生可能性 | 対応                     |
| ---------------------- | ------ | ---------- | ------------------------ |
| 資金移動業の無許可営業 | 致命的 | 中         | 弁護士確認必須           |
| 宅建業法違反           | 高     | 低         | 弁護士確認               |
| 利用規約の無効条項     | 中     | 中         | CLOレビュー + 弁護士確認 |
| 個人情報漏洩           | 高     | 低         | 技術的対策 + 規約整備    |
