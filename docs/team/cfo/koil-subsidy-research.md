## エグゼクティブサマリー

柏の葉スマートシティにおけるスタートアップ支援エコシステムを調査した結果、tsumugiが最大**¥5,000,000（500万円）**の補助金を受けられる可能性がある2つの主要パスウェイを特定した。いずれも金銭的コストはほぼゼロで、ROIは極めて高い。

## 1. プログラム概要

### 1-1. KOIL STARTUP PROGRAM（KSP）

| 項目       | 内容                                  |
| ---------- | ------------------------------------- |
| **主催**   | 三井不動産 × 柏市                     |
| **運営**   | TEP（TXアントレプレナーパートナーズ） |
| **対象**   | シード・アーリー期スタートアップ      |
| **開始年** | 2022年                                |
| **採択数** | 毎年最大3社                           |
| **費用**   | 無料                                  |

**概要:** 柏の葉スマートシティを舞台に、社会課題解決に取り組むスタートアップの事業成長を加速するアクセラレーションプログラム。集中セミナー + 個別メンタリング + 実証フィールド提供の三本柱。

### 1-2. 柏市スタートアップ事業化応援補助金

| 項目         | 内容                                             |
| ------------ | ------------------------------------------------ |
| **交付元**   | 柏市（経済産業部産業政策・スタートアップ推進課） |
| **補助上限** | **¥5,000,000（500万円）**                        |
| **補助率**   | 対象経費の4/5（80%）                             |
| **採択数**   | 最大2件/年                                       |
| **対象者**   | KSP修了者 or AEA柏の葉賞受賞者                   |

### 1-3. ハツメイノハ（柏の葉イノベーションフェス ビジネスアイデアコンテスト）

| 項目               | 内容                                     |
| ------------------ | ---------------------------------------- |
| **主催**           | 三井不動産 × テレビ東京                  |
| **賞金**           | 優勝 ¥1,000,000（100万円）               |
| **特典**           | 柏の葉スマートシティでのビジネス実装支援 |
| **2026ファイナル** | 2026年3月28日                            |

## 4. tsumugiの適格性分析

### 4-1. 強み（採択可能性を高める要因）

1. **テーマ適合性:** 退去時の家具廃棄問題は「環境共生」「脱炭素」に直結。循環型経済は社会的インパクトが大きい
2. **実証フィールド適合性:** 柏の葉スマートシティは実住居エリアであり、前の住人・次の住人・大家の全ステークホルダーが存在。理想的なPoBフィールド
3. **三井不動産との親和性:** 三井不動産は日本最大級の不動産デベロッパー。tsumugiの管理物件連携は三井不動産のバリューチェーンに組み込める
4. **技術活用:** AI・プラットフォーム技術を活用したC2Cマッチングは「新産業創造」に合致
5. **低コスト運営実績:** 6ヶ月予算¥50,000-70,000で開発を進める堅実さは、補助金の有効活用能力を示す

### 4-2. 弱み・リスク

1. **法人格:** 現時点で法人未登記の場合、「法人登記予定のある個人」として応募する必要がある
2. **重点テーマとのフィット:** 6重点テーマの中心ではない（ただし「テーマ外も可」）
3. **競争率:** 毎年最大3社採択に対し、応募数は不明だが競争あり
4. **プロダクト完成度:** MVPフェーズであり、トラクションは限定的

### 4-3. CFO評価

| 評価項目         | スコア（5段階） | コメント                                                       |
| ---------------- | --------------- | -------------------------------------------------------------- |
| 獲得可能性       | **3.5/5**       | テーマ適合・三井不動産親和性は高い。法人格・トラクションが課題 |
| 支援金額の影響度 | **5/5**         | 現在の予算規模の70-100倍。事業フェーズを一変させる             |
| 投入コスト       | **5/5**         | 金銭コスト¥0、時間投資のみ                                     |
| ROI              | **5/5**         | コストゼロに対し最大¥8.4Mのリターンポテンシャル                |
| 戦略的価値       | **5/5**         | 三井不動産との関係構築は金額以上の価値                         |
| **総合推奨度**   | **4.7/5**       | **強く推奨**                                                   |

## 9. 結論

**KOIL STARTUP PROGRAMおよび柏市事業化応援補助金は、tsumugiにとって「コスト¥0で最大¥8.4Mの支援を受けられる」極めて有望な機会である。**

特に事業化応援補助金（最大¥5M）は、現在の予算規模の100倍に相当し、プレローンチからフルタイム開発体制への転換を可能にする。さらに、三井不動産との関係構築は金額以上の戦略的価値を持つ。

**CFO推奨: ハツメイノハ応募を即時確認し、KSP 2026への応募を最優先タスクとして位置づけること。**
