# CFO Knowledge - 2026-02-09 予算改訂

## 議題: Claude Code代金の初期予算への追加

### 経緯

大株主から指摘: 6ヶ月予算¥50,000-70,000にClaude Code代金が含まれていなかった。

### 判断

Claude Code Max ($200/月 ≒ ¥30,000/月) は開発インフラそのものであり、初期費用として計上すべき。
ただし、全期間Max $200は過剰。フェーズに応じた段階最適化を導入。

### 改訂内容

**旧予算:** ¥50,000-70,000（6ヶ月）
**新予算:** ¥147,000-167,000（6ヶ月）

**Claude Codeコスト最適化:**

- 集中開発期（2ヶ月）: Max $200/月 = ¥60,000
- 安定開発期（2ヶ月）: Max $100/月 = ¥30,000
- メンテナンス期（2ヶ月）: Pro $20/月 = ¥6,000
- 合計: ¥96,000（全期間Maxの場合¥180,000から47%削減）

### 学び

1. **開発ツールのサブスクリプション費用は見落としやすい** - 「当たり前に使っているもの」こそ予算計上を忘れる
2. **固定費の変動費化** - 必要な時に必要なプランを使う発想。SaaSの柔軟性を活かす
3. **予算策定時チェックリスト** - 「現在使っているツール・サービスの棚卸し」を必ず実施すること
4. **ROI視点** - Claude Code ¥96,000 vs エンジニア外注 ¥3,000,000-6,000,000（6ヶ月）。30倍以上の資本効率

### 投資回収見込み修正

- 月間固定費平均: 約¥25,000-28,000
- 1取引あたり純収益: ¥15,600
- 損益分岐: 月2件の取引
- 初期投資回収: 約6ヶ月（旧: 4-5ヶ月）
