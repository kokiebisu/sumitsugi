# tsumugi - プロジェクト概要

## コンセプト

「tsumugi」は、クリエイターの暮らしを引き継ぐプラットフォームです。単なる物件のサブリースではなく、家具・インテリアと一緒に「ライフスタイル」そのものを譲渡することを目指しています。

- クリエイターが作り上げた空間を、次のクリエイターへ
- 家具・インテリアは購入という形で引き継ぎ
- 短期〜中期（1〜6ヶ月）の想定期間で暮らしをシェア

## 用語ガイドライン

### UI表記の統一

- ❌ **ホスト** → ✅ **クリエイター**
  - 理由：このプラットフォームは単なる「貸し手」ではなく、空間を作り上げた「創造者」を重視
  - 適用箇所：すべてのUI、ドキュメント、コード内コメント
  - 注意：データ構造のフィールド名（`host`）は変更しない

- ❌ **インテリア利用料（初回のみ）** → ✅ **インテリア購入料**
  - 理由：家具・インテリアを「購入」する仕組みを明確化
  - 適用箇所：料金表示、説明文

- ❌ **ホスティング歴** → ✅ **活動歴**
  - データ構造：`yearsHosting`（フィールド名は維持）

- ❌ **スーパーホスト** → ✅ **スーパークリエイター**

## デザイン原則

### ビジュアル

- Airbnb風のクリーンなUI
- 写真を大きく使い、空間の魅力を伝える
- コーラル色（#FF5A5F系）をアクセントカラーとして使用

### スタイル

- ボヘミアン（bohemian）
- インダストリアル（industrial）
- ミニマル（minimal）
- ヴィンテージ（vintage）
- モダン（modern）
- スカンジナビアン（scandinavian）

### 間隔・スペーシング

- アメニティアイコン（pill layout）：`gap-1.5`（6px）
- クリエイターおすすめタグ：視覚的に囲む（`border border-coral/20`）

## データ構造の重要な注意点

### Propertyインターフェース

- `host` フィールド名はそのまま（変更しない）
- `yearsHosting` フィールド名もそのまま
- `whyChoseThis` は配列で、`{ reason: string; image?: string }` 形式

### 初期費用の計算

初期費用合計 = インテリア購入料 + 敷金 + 礼金 + 保証会社利用料 + クリーニング代

**注意：月額家賃・管理費は含まれません**
