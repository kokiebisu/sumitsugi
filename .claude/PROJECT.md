# tsumugi - プロジェクト概要

## コンセプト

「tsumugi」は、前の住人の暮らしを引き継ぐプラットフォームです。単なる物件のサブリースではなく、家具・インテリアと一緒に「ライフスタイル」そのものを譲渡することを目指しています。

- 前の住人が作り上げた空間を、次の住人へ
- 家具・インテリアは購入という形で引き継ぎ

## デザイン原則

### ビジュアル

- Airbnb風のクリーンなUI
- 写真を大きく使い、空間の魅力を伝える
- コーラル色（#FF5A5F系）をアクセントカラーとして使用

### 間隔・スペーシング

- アメニティアイコン（pill layout）：`gap-1.5`（6px）

## データ構造の重要な注意点

### Propertyインターフェース

- `host` フィールド名はそのまま（変更しない）
- `yearsHosting` フィールド名もそのまま

## ナビゲーション

### ヘッダー構成

- ロゴ：tsumugi
- 右側：
  - 「暮らしを譲る」リンク（デスクトップのみ表示）
  - ハンバーガーメニュー
    - 言語選択
    - ヘルプセンター
    - 暮らしを譲る
    - 友人を紹介
    - サポート
    - ログインまたは登録

## 技術スタック

- Next.js 14+ (App Router)
- TypeScript
- Tailwind CSS
- Lucide React（アイコン）
- shadcn/ui（UIコンポーネント）
