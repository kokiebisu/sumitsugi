# tsumugi - ビジネスロジック・オペレーション

## ビジネスモデル概要

### 基本的な仕組み

tsumugiは、クリエイターが作り上げた暮らしを次のクリエイターへ引き継ぐプラットフォームです。

**取引の流れ：**

1. クリエイター（譲渡側）が物件情報を登録
2. 次のクリエイター（引き継ぎ側）が物件を閲覧・内見
3. 引き継ぎ相談・契約
4. インテリア購入料の支払い
5. 引き継ぎ実施
6. 契約期間（1〜6ヶ月）の居住
7. 次の人へ引き継ぐ or 退去

## 料金体系

### 初期費用

引き継ぎ時に必要な初期費用は以下の合計：

```
初期費用合計 = インテリア購入料 + 敷金 + 礼金 + 保証会社利用料 + クリーニング代
```

**重要：月額家賃・管理費は含まれません**

#### 各項目の説明

1. **インテリア購入料**（`interiorFee`）
   - 家具・インテリアを「購入」する費用
   - 前のクリエイターが作り上げた空間を引き継ぐ対価
   - 譲渡側クリエイターへ支払われる
   - 支払い方法：銀行振込 or 分割払い

2. **敷金**（`deposit`）
   - 物件の敷金（退去時に返還される可能性あり）
   - 大家・管理会社へ支払う

3. **礼金**（`keyMoney`）
   - 物件の礼金（返還されない）
   - 大家・管理会社へ支払う

4. **保証会社利用料**（`guaranteeFee`）
   - 賃貸保証会社の利用料
   - 保証会社へ支払う

5. **クリーニング代**（`cleaningFee`）
   - 退去時のクリーニング費用（前払い）
   - クリーニング業者 or 管理会社へ支払う

### 月額費用

毎月支払う費用：

1. **月額家賃**（`monthlyRent`）
   - 大家・管理会社へ支払う基本家賃

2. **管理費・共益費**（`managementFee`）
   - マンション・アパートの管理費
   - 大家・管理会社へ支払う

## 物件のステータス管理

### ステータスの種類

```typescript
status: "draft" | "public";
```

- **draft**: 下書き状態。まだ公開されておらず、一覧には表示されない
- **public**: 公開状態。物件一覧に表示され、誰でも閲覧可能

### ステータス遷移

```
新規作成 → draft → (クリエイターが公開) → public
                  ← (非公開に戻す) ←
```

## 引き継ぎフロー

### 1. 物件登録（クリエイター側）

クリエイターが以下の情報を登録：

- 基本情報（タイトル、サマリー、写真）
- 暮らしのストーリー
- 家具・インテリアの詳細
- 物件詳細（間取り、面積、設備など）
- エリア情報
- 引き継ぎ条件
- FAQ

### 2. 物件閲覧・内見

引き継ぎ希望者が：

- 物件一覧から気になる物件を探す
- 詳細ページで情報を確認
- 「引き継ぎを相談する」から問い合わせ
- 内見日程を調整

### 3. 引き継ぎ相談

- クリエイター同士で直接コミュニケーション
- 引き継ぎ条件の確認
- インテリア購入料の交渉（必要に応じて）
- 引き継ぎスケジュールの確定

### 4. 契約・支払い

- 引き継ぎ契約書の締結
- インテリア購入料の支払い
- 敷金・礼金・その他初期費用の支払い
- 賃貸借契約の名義変更 or 新規契約

### 5. 引き継ぎ実施

- 鍵の受け渡し
- 家具・インテリアの使い方説明
- 近隣情報の共有
- 植物の世話方法など、個別事項の引き継ぎ

### 6. 居住期間

- 契約期間（1〜6ヶ月）の居住
- 月額家賃・管理費の支払い
- クリエイター自身の暮らしを楽しむ

### 7. 次の引き継ぎ or 退去

- 次の人へ引き継ぐ場合：同じフローを繰り返す
- 退去する場合：家具を持ち出す or 処分

## データの入力ルール

### 必須項目

すべての物件で必須：

- `id`: 物件ID（ユニーク）
- `title`: 物件タイトル
- `summary`: サマリー（1〜2文）
- `images`: 写真（最低1枚）
- `furnitureDescription`: 家具・インテリアの説明
- `estimatedDuration`: 契約期間（例：「2〜4ヶ月」）
- `status`: ステータス（draft or public）
- `story`: 暮らしのストーリー
- `conditions`: 引き継ぎ条件
- `monthlyRent`: 月額家賃
- `interiorFee`: インテリア購入料
- `area`: エリア（例：「中目黒・代官山」）

### オプション項目

- `style`: インテリアスタイル
- `basicAmenities`: 基本設備（配列）
- `condition`: 家具の状態（excellent | good | used）
- `amenities`: こだわりの機材・家具（配列）
- `fees`: 料金詳細（オブジェクト）
- `host`: クリエイター情報（オブジェクト）
- `propertyDetails`: 物件詳細（オブジェクト）
- `locationInfo`: エリア情報（オブジェクト）
- `handoverDetails`: 引き継ぎ詳細（オブジェクト）
- `faq`: よくある質問（配列）

### 写真のガイドライン

1. **メイン写真（1枚目）**
   - 部屋全体が見える引きの写真
   - 明るく、雰囲気が伝わるもの

2. **詳細写真（2〜5枚目）**
   - こだわりのインテリア・家具
   - 特徴的な空間
   - 窓からの景色
   - 収納スペースなど

3. **推奨枚数**
   - 最低3枚、理想は5枚

4. **画像形式**
   - WebP推奨（軽量化のため）
   - JPEGも可

### クリエイター情報のガイドライン

#### whyChoseThis（この部屋を選んだ理由）

- 3つのポイントを記載
- 各ポイントに写真を添えることを推奨
- 構造：`{ reason: string; image?: string }`

**例：**

```typescript
whyChoseThis: [
  {
    reason:
      "目黒川が見える窓からの景色に一目惚れ。春は桜を部屋から眺められます",
    image: "/images/view.jpg",
  },
  {
    reason: "天井が高くて、大きなアート作品を飾れる",
    image: "/images/ceiling.jpg",
  },
  {
    reason: "駅から近く、文化的なスポットに歩いて行ける立地",
    image: "/images/area.jpg",
  },
];
```

#### messageToNext（次の人へのメッセージ）

- クリエイターから次の人へのパーソナルなメッセージ
- 100〜200文字程度
- この部屋への想い、次の人へのアドバイスなど

#### socialLinks（SNSリンク）

サポートするSNS：

- Instagram: `@username` 形式
- Twitter/X: `@username` 形式
- YouTube: `@channelname` 形式
- TikTok: `@username` 形式
- Website: ドメイン名のみ（例：`example.com`）

**注意：URL生成はフロントエンドで自動処理**

## 契約期間について

### 期間の考え方

- **短期**（1〜3ヶ月）：旅行、一時的なプロジェクトなど
- **中期**（3〜6ヶ月）：海外滞在、地方移住の試験期間など
- **柔軟な対応**：期間は相談可能

### 期間を明記する理由

1. クリエイターが戻ってくる予定がある
2. 次の引き継ぎ先を見つけやすくする
3. 短期〜中期の暮らし方を提案

## トラブル対応

### よくあるトラブルと対処法

#### 1. インテリア購入料の金額交渉

- 原則：クリエイターが設定した金額を尊重
- 交渉可能な範囲：±10%程度
- 著しく高額 or 低額の場合：運営が介入

#### 2. 家具・インテリアの破損

- 引き継ぎ時に状態を写真で記録
- 軽微な破損：次の引き継ぎ料金から減額
- 重大な破損：保険or実費で弁償

#### 3. 引き継ぎのキャンセル

- **クリエイター側都合**：インテリア購入料の全額返金
- **引き継ぎ側都合**：キャンセル料（金額の20%）
- 内見前のキャンセル：無料

#### 4. 賃貸契約上のトラブル

- 大家・管理会社との調整は引き継ぎ側の責任
- 名義変更が難しい場合：tsumugiが仲介サポート

## 法律・コンプライアンス

### 宅建業法への対応

- tsumugiは物件の「仲介」ではなく「引き継ぎマッチング」を提供
- 賃貸借契約は大家・管理会社と直接締結
- インテリア購入は個人間売買

### 個人情報保護

- クリエイターの個人情報は最小限のみ表示
- 連絡先の交換は相談後
- プライバシーポリシーの整備（今後）

### 消費者保護

- 適正な価格設定のガイドライン
- クーリングオフ制度の検討
- トラブル時のサポート体制
